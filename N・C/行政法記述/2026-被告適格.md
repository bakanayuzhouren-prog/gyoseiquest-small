## てらしぃ確認の芯

- **行訴の記述は被告を書かされる**
- **弁護士会、土地区画整理組合は被告になる**（国・公共団体に所属しない行政庁＝11条2項）
- **行手**
  - 処分等の求め → **行政機関に**
  - 行政指導の求め・中止等の求めも **行政機関に**
- 訴訟の「被告」と、行手の「申出の相手」を混ぜない

## 骨格（行訴11条）

処分・裁決をした行政庁が **国又は公共団体に所属する** → その **国又は公共団体** を被告（1項。処分なら処分庁の所属、裁決なら裁決庁の所属）

**所属しない** → その **行政庁自身** を被告（2項）
- 定番: **弁護士会**（懲戒処分など）
- 定番: **土地区画整理組合**（換地処分など）

被告とすべき国・公共団体・行政庁がない → 事務の帰属する国又は公共団体（3項）

訴状には処分庁・裁決庁の記載（4項）。庁は裁判上の一切の行為をする権限（6項）。教示は「被告となるべき者及び出訴期間」を書面で（46条＝既存Q10）

## 抗告訴訟は11条が乗る（38条1項）

取消以外の抗告（無効等確認・不作為違法確認・**義務付け**・**差止め**）は **11条準用** → 被告の切り方は取消と同じ。
仮の義務付け・仮の差止めは本案の被告のまま申立て。

## 実質的当事者訴訟（4条）

抗告ではない。法律関係の **相手方**（国・公共団体）を被告。11条は準用されない（41条に11条なし）。

| 例 | 被告 |
|----|------|
| 国家公務員の地位確認・給料 | **国**（Q20） |
| 在外邦人・衆議院の地位確認 | **国**（Q20-2） |
| 地方公務員なら | **当該地方公共団体** |
| 形式的当事者 | 法令が定めた当事者の一方 |

## 住民訴訟（自治242条の2・民衆訴訟）

監査先行（**監査委員**へ）。元職個人を直接被告にしない（Q31）。

政教分離・表現の自由も、取消訴訟ではなく**財務会計**で入る。

| | 愛媛玉串料 | 孔子廟 | 大阪ヘイト |
|--|------------|--------|------------|
| なにを叩くか | **支出**（玉串料） | **怠る事実**（賃料を取らない） | **支出**（審査会報酬等）・4号 |
| 憲法 | 20条3項違憲 | 20条3項違憲 | 21条1項合憲（棄却） |

| 号 | 請求 | 被告 |
|----|------|------|
| 1号 | 行為の差止め | **当該執行機関又は職員** |
| 2号 | 処分の取消し・無効確認 | 11条準用 → **地方公共団体** |
| 3号 | 怠る事実の違法確認 | **当該執行機関又は職員** |
| 4号 | 職員・相手方への損賠等を求めよ | **現職の執行機関（長）**（平成14年改正後は義務付け型） |

出訴期間は監査結果等の**通知の日から30日**（242条の2第2項。60日黙過ならその翌日から30日）。監査請求は行為の日から1年。怠る事実に1年はかからない。

## 機関訴訟

法律に定める場合・者に限り（行訴42条）。取消を求めるものは11条準用。それ以外は当事者訴訟規定（43条）。

国の関与（自治251条の5）: 審査の申出の相手方となった **国の行政庁** を被告。その庁がない取消しは **国**。高裁（Q34）。

## そのほか（記述で被告が出る）

| 類型 | 被告 |
|------|------|
| 争点訴訟（45条。収用→所有権） | **起業者**（私法上の相手。Q19） |
| 国賠 | **国又は公共団体**（公務員個人は原則×） |
| 選挙の効力（民衆・公選法） | 当該選挙を管理する **選挙管理委員会**（要六法。当選の効力は当選人側） |
| 行服の審査請求 | 訴訟ではない。**審査庁**へ |

## 行手の「求め」（被告ではない）

てらしぃは全部 **行政機関に** とまとめる（行訴の国・公共団体被告と混ぜない）。

条文の書き分け（六法どおり）:

| | 条 | 申出先 |
|--|----|--------|
| 中止等の求め | 36条の2 | 行政指導をした **行政機関**（既存Q5） |
| 処分等の求めのうち処分 | 36条の3 | 処分権限の **行政庁** |
| 処分等の求めのうち指導（行政指導の求め） | 36条の3 | 指導権限の **行政機関** |

答案で条文どおり書くなら、処分は行政庁・指導は行政機関。てらしぃの「機関」は「国を被告にするな／庁・機関へ申出せ」の対比。
