## 孔子廟違憲判決

- 最大判令3.2.24（那覇市・都市公園内の孔子廟、使用料の全額免除）
- **憲法20条3項**の宗教的活動に当たる → **違憲**
- 判断枠組みは空知太型の**総合考慮**（施設の性格／免除の経緯／無償提供の態様／一般人の評価）。社会通念で限度超え
- 観光・歴史・文化の意義があっても、一般人から見て特定宗教への特別の便益・援助と評価されてもやむを得ない
- 津・愛媛＝目的効果。空知太・孔子廟＝総合考慮。物差しを入れ替えない
- アプリ: ⑤質問する（既存Hanrei2を厚くした）。住民訴訟では**怠る事実**（賃料を取らない）。愛媛・大阪ヘイトの支出型と混ぜない

## いのちの砦訴訟

- 通称は「いのちの**とりで**裁判」。2013〜15年の生活扶助基準引下げ
- 最三小判令7.6.27。**デフレ調整**は判断過程・手続に過誤欠落 → 厚労大臣の裁量逸脱濫用 → 保護変更決定は**違法**（取消し）
- **ゆがみ調整**は多数意見で適法。**国賠は認めず**
- 裁判所は25条の「健康で文化的な最低限度」そのものの当否を直接は切らず、**判断過程審査**
- ひっかけ: 生存権の直接違憲／国賠まで認めた／引下げ全部が違法
- 多角: デフレ＝違法／ゆがみ＝適法／国賠なし／25条を直接切らない

## 旧警備業法違憲判決

- 最大判令8.2.18。旧警備業法3条1号・14条（令和元年改正前）。被保佐人であることを警備員の欠格とした部分
- **事実** 交通**誘導員**が保佐開始で欠格 → 雇用終了・**解雇**。仕事ができていなかったわけではない。能力があるのに一律排除
- **憲法22条1項**（**狭義**の職業選択の自由）・**14条1項**（平等）に違反
- 審査は薬局距離の入口（比較考量・裁量の広狭）だけ。規制目的**二分論は述べられていない**
- 合憲にするには、重要な公共の利益のために**必要かつ合理的**。裁量は広くない
- **代替手段** 平成14年の**7号**（心身の障害により適正に行えない者＝個別審査）。保佐の能力と警備の能力は一致しない
- 昭和57年・平成14年改正時は直ちに違憲ではない。**遅くとも2017年3月**（本件退職時）までには違憲（後発的）
- **国賠は認めず**。明白なのに長期に怠ったとはいえない。170余の欠格を一括見直し中で、**国会は漫然と仕事をしていない**
- 関連: **楽天ダイレクト**（態様規制・合憲）。二分論を使わない点は同じ。制限の性質で結論が分かれる
- ひっかけ: 二分論で切る／最初から違憲／国賠まで認めた／前科欠格／楽天と同じ結論
- アプリ: ⑤質問する

## 楽天ダイレクト事件（旧警備業法の関連）

- 要指導医薬品の**対面**販売義務（薬機法36条の6第1項・3項）が22条1項違反か。ネットで売りたい地位の確認（実質的当事者訴訟）
- **合憲**（上告棄却）。規制目的**二分論は述べない**（旧警備業法と同じ）
- 職に就けない話ではない。市場は全体の**1％未満**・期間限定 → **職業活動の内容・態様**。制限の程度も大きくない
- **代替** 電話・メールは対面に劣る（理解の確認）。ネットでは足りない
- 旧警備業法との切れ: 楽天＝態様・合憲／警備＝狭義＋14条・違憲

## 金沢市市庁舎前広場事件

- 最三小判令5.2.21。庁舎前広場での政治的示威（特定政策への反対・賛成）を管理規則で禁じた適用は**憲法21条1項に違反しない**
- 庁舎で示威があると、市が特定の立場を利している外観 → 政治的中立への疑義 → 公務の円滑に支障
- 他の公の施設は使えるので制限は限定的。広場は庁舎と**一体**で、パブリックフォーラムに変容しない
- **泉佐野（公の施設は原則貸す）と棚が違う**。庁舎の一部か、市民会館か
- 多角: 21条違反？→この適用はNO。広場は庁舎と一体。パブリックフォーラムに変容しない
- 宇賀反対意見あり
- アプリ: ⑤質問する（新規）

## 泉佐野市市民会館事件

- 単なる蓋然性・反対派が来そう、では足りない。思想で門前払いするな

## 大阪市ヘイトスピーチ条令事件

- 最三小判令4.2.15（民集76巻2号190頁）。事件名は**公金支出無効確認等請求**
- 入口は憲法の取消訴訟ではない。**住民訴訟**（自治242条の2第1項**4号**）
- **その前に住民監査請求**（監査委員に対し）
- 被告は**現職の執行機関（市長）**。元市長を直接被告にしない
- 違法だと主張した財務会計は、条例実施のための**公金の支出**（ヘイトスピーチ審査会の委員報酬・調査の郵便料金）
- ルート: 条例が21条違反で無効 → 審査会の設置・報酬支出は法令上の根拠を欠き違法。法令の違憲が個別の財務会計の違法を基礎付ける限り、住民訴訟で合憲性を争える（警察法改正無効・最大判昭37.3.7と同型）
- 憲法の結論: 条例2条・5〜10条は**21条1項に違反しない** → 支出も根拠あり → **棄却**
- 措置は事後の拡散防止・氏名公表。制裁なし。氏名特定の法的強制力なし
- 愛媛玉串料と同じ**支出型**。孔子廟は**怠る事実**（賃料を取らない）。混ぜない
- アプリ: ⑤質問する。Q31の切るポイントにも入れた

## 在外邦人選挙訴訟

- 最大判平17.9.14。在外国民の選挙権制限は、やむを得ない事由がない限り許されない。選挙区選挙を認めない立法は**違憲**。例外的に**国賠**
- 訴訟は実質的当事者の**地位確認**（選挙人名簿でも在外名簿でも選挙できるはず）
- 国民審査と同型の違法確認で切らない
- アプリ: ⑤質問する／行政法記述Q20系

## 在外邦人国民審査

- 最大判令4.5.25。在外国民に国民審査を全く認めない国民審査法は**法令違憲**
- **地位確認は通らない**（法に在外の記載がない）→ **違法確認**（次回審査で行使させないことが違法）が認容
- 立法不作為は国賠法上違法。賠償認容（選挙訴訟の国賠と並べて「参政権パッケージ」）
- アプリ: ⑤質問する／Q20-3
