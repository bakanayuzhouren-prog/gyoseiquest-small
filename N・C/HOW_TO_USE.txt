========================================
強化ルール（信義則回で確定・この調子で増やす）
========================================

1. てらしぃが YouTube を見て、論点を渡す（または URL＋要点）
   - エージェントは動画全文の自動取り込み・転載をしない
2. 動画内の試験知識は「一部だけで終わり」にしない
   - 向きの違い・信義則の有無・捨てひっかけまでメモに残す
3. てらしぃが短く整理した芯（①②…）があれば、それをメモの正とする
4. N・C/<科目>/ に 1テーマ1メモ（テンプレ: _TEMPLATE.md）
5. 佐藤NOTEと突合 → 同一芯は1問に併合／違う一点は別問
6. content/textbook/app/ へ Q1型反映（答案 38〜45字）
7. INDEX.md に追記し、npm run bundle:db-textbooks
