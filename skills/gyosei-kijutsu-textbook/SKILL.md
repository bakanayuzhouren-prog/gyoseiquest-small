# Gyosei 記述・DB教科書

`content/textbook/app/` と君の教科書（記述）を触るときは、このスキルを必ず読む。

## てらしぃ確定：記述式の形式（再発防止）

行政書士試験の記述は **40字程度**で答える問題である。

- 問に対し、答案に載せる **論点をだいたい3つ** 書くと、つなげて **40字程度** になる。
- **解答例（答案の芯）に講義全文・NOTE解説の長文を載せてはならない。** それは「答案」ではなく解説であり、本試験形式から外れる。
- 禁止例: 120条の条文引用全文＋13条の説明＋126条の説明を段落で並べた300字超の「解答例」。
- 正解イメージ: キーワード3点を1文に圧縮した **空白除き38〜45字**（末尾に `（〇〇字）`）。

### 標準カード構成（Q1型・必須）

```markdown
## Qn. 題名〔条文〕

**出題の型**
（長い事例。トラップ・別論点・不要事実を織り交ぜる）。
（末尾で一点だけ聞く）。…40字程度で記述しなさい。

**答案の芯**
（NOTEポイントの答案1文。空白除き必ず38〜45字）（〇〇字）

**切るポイント**
（トラップの切り方）
```

**問は長くする（てらしぃ確定）**

- 佐藤NOTE・近年の本試験記述を参考に、長めの事情＋トラップを仕掛ける。
- しっかり読めば解けること（末尾の問いが答案の一点を明示）。
- 短文事例だけの問は不可。

**独立論点は別Q（同一制度でも）**

- NOTEが別に答案を求めている論点は、同じ保佐人でも **2問以上**（`Q1-1` / `Q1-2`）。トラップ（聞かない不要事実）だけを同じ問に残す。
- 例: 13条（不動産○／自転車×）と126条（取消期間）は別Q。126の問に自転車を「聞かない事実」として置いてよいが、13条の答案を126に混ぜない。

実例（Q1-1・13条）:

- 問: 保佐・同意なき不動産売買と自転車購入を長く書き、末尾は「自転車は取り消せるか、甲土地と対比して」。
- 解答例: 不動産売買は同意を要する行為だが、自転車購入はこれに当たらないので取り消せない。（40字前後）
- 根拠: 土地＝13条1項3号。自転車＝各号非該当＋13条1項ただし書（9条ただし書の日常生活）。未成年者5条と取り違えない。

実例（Q1-2・126条・期間）:

- 問: 保佐・同意なき不動産売買・追認の話・Bの善意・詐術なし、などを長く書いたうえで、「Xが**甲土地**の売買を取り消すとき、いつから起算していつまでに」だけ聞く。
- 解答例: Xは追認をすることができる時から、５年又は、行為の時から２０年間以内に取消権を行使すればよい。（要38〜45字に調整）

実例（Q2・NOTEポイントを拾う）:

- 問: 黙秘の事情を長く書き、末尾は「黙秘でも詐術にあたるのはどのような場合か」。
- 悪い解答例: 行為能力者であることを信じさせるために詐術を用いたときは、その行為を取り消すことができない。（条文結論だけでNOTEのポイント欠落）
- 良い解答例: 行為能力者であることを信じさせるため、他の言動とあいまって、相手方を誤信させ、または誤信を強めたとき（要38〜45字）

**NOTE／なかチャンネルのポイントは必ず拾う。** 「書けるように」「どのような場合か書け」で示されたフレーズ・キーワードを答案の芯に入れる。なかチャンネル由来は `N・C/` にメモし、佐藤NOTEと併合／分離する（AGENTS.md）。

**字数表示:** 答案の芯の末尾に空白を除いた字数を `（〇〇字）` で付ける。**空白除き38〜45字必須。**

## 答案の芯の扱い

- 佐藤NOTEに **明示の40字答案／「書けるように」の答案文** があるときは、その答案文を優先する（講義の前置きは捨てる）。
- なかチャンネル由来はてらしぃが渡したキーワードを答案化し、原文の講義転載は禁止。
- NOTEが講義だけのときは、NOTEの結論キーワードから **38〜45字に圧縮**して答案化する。講義段落の全文コピーは禁止。
- 基礎知識（○×）は記述40字ルールの対象外。○×＋短い根拠でよい。

## 問の形式

- 本試験に寄せる: 事例のあと「…40字程度で記述しなさい。」
- 誘導は①②③程度までに留め、答案が40字に収まる聞き方にする。

## e-Gov／ネット正誤チェック（問・解答例・条文）

画像生成・X投稿・「完成」報告の**前**に、対象Qごとに行う。推測で条文を直さない。

### 正本の優先

1. **e-Gov 法令検索**の現行条文（施行日・改正を見る）。民法 https://laws.e-gov.go.jp/law/129AC0000000089 ／ 行政手続法 https://laws.e-gov.go.jp/law/405AC0000000088
2. 判例が答案の芯なら、裁判所の判旨の定番フレーズ（全文転載禁止）。e-Govにないものは「判例」と切るポイントに書く。
3. 佐藤NOTEに明示の40字答案があるときはその文を優先。ただし **e-Govと矛盾したらてらしぃへ先に報告**（勝手にNOTEを捨てない）。
4. 予備校ブログ・まとめサイトは補助。e-Gov／判例と食い違ったらネット側を捨てる。

### 見る項目

- **主体**: 誰が・誰に（保佐人＝120条の「同意をすることができる者」等）
- **要件と効果**: 号・項、ただし書、原則／例外
- **つなぎ**: 「又は」と「かつ」を条文どおり
- **期間・起算**: いつから・何年。複数起算があるときは混ぜて否定しない（126条: 5年＝追認できる時から、20年＝行為の時から）
- **用語の借り物**: 似た制度のラベルを貼っていないか（保佐の日常＝**9条ただし書**を13条1項ただし書で除外。未成年者**5条**3項と混同しない）
- **問と答案の一点**: 末尾の問いと答案の芯が同じ一点か。別答案になるなら別Q
- **アプリ内**: `STATUTES`／既存learn／切るポイントと矛盾がないか

### 手順

1. 対象Qの見出し条番号を列挙する。
2. e-Govで各条の本文を開き、答案のキーワードが条文に乗るか突き合わせる。
3. 判例芯なら公開判旨（または定評ある要約）で「慎重と合理性」等の脱落がないか見る。NOTEが短く切っている場合は答案はNOTE、切るポイントに判例の足りない語を残す。
4. ネット解説は上記と矛盾しないかだけ見る（コピペしない）。
5. 結果をてらしぃへ短く報告する: 条番号／e-Gov確認日／OK or 要修正／根拠1行。
6. 未確認は断定せず残す。

### 報告テンプレ

```text
対象: 民法記述 Qn / 行政法記述 Qn
e-Gov: （法令名）○条（確認日: YYYY-MM-DD）
問: OK / 要修正（理由）
答案の芯: OK / 要修正（理由）
切るポイント: OK / 要修正（理由）
ネット補助: （URLまたは「未使用」）。e-Govと矛盾なし / 矛盾あり（採用しない）
```

画像の誤情報チェック（`prompts/_image-legal-check.md`）は、**この条文チェックを通した答案**を正として図と突き合わせる。
