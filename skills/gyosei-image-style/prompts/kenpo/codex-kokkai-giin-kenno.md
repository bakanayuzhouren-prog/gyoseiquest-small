## 法律の芯（崩すな）

照合: 衆議院掲載の日本国憲法（第四十一条〜第六十四条、第七十三条、第八十四条〜第九十条、第九十六条）。既存学習: LEC公開２・問6、憲法カード（弾劾64条・国政調査62条）。

**国会の権能（左・10）**

| 図の文言 | 根拠 | 確認 |
|---|---|---|
| 法律の制定 | 59条 | 両議院で可決したとき法律となる |
| 条約の承認 | 73条3号 | 条約締結は内閣。事前または事後に**国会の承認** |
| 憲法改正の発議 | 96条1項 | 各議院の総議員3分の2以上の賛成で、**国会が**発議 |
| 租税の法定 | 84条 | あらたに租税を課し又は変更するには法律又は法律の定める条件 |
| 国費支出・国の債務負担の議決 | 85条 | 国会の議決に基くことを必要とする |
| 予備費支出の事後承諾 | 87条2項 | 予備費の支出は、事後に国会の承諾。1項の「予備費を設ける議決」とは別 |
| 皇室経費の議決 | 88条 | 皇室の費用は予算に計上して国会の議決 |
| 決算の審査 | 90条 | 決算と検査報告を国会に提出。試験では決算の審査として整理 |
| 内閣総理大臣の指名 | 67条 | 国会の議決で指名 |
| 弾劾裁判所の設置 | 64条 | **国会は**弾劾裁判所を設ける |

**議院の権能（右・8）**

| 図の文言 | 根拠 | 確認 |
|---|---|---|
| 議院規則の制定 | 58条2項 | 各々、会議その他の手続及び内部の規律に関する規則 |
| 議員の資格争訟の裁判 | 55条 | 両議院は、各々その議員の資格に関する争訟を裁判する |
| 議員の懲罰 | 58条2項 | 院内の秩序をみだした議員を懲罰することができる |
| 国政調査権 | 62条 | 両議院は、**各々**国政に関する調査を行う |
| 議員の逮捕の許諾・釈放要求 | 50条 | 会期中は法律の定める場合を除き逮捕されない。会期前逮捕は**その議院の要求**で釈放。許諾は「法律の定める場合」の試験用整理 |
| 秘密会の議決 | 57条1項ただし書 | 会議は公開。出席議員の3分の2以上で秘密会を開くことができる |
| 議長その他の役員の選任 | 58条1項 | 両議院は、各々その議長その他の役員を選任する |
| 国務大臣の出席要求 | 63条 | 答弁又は説明のため出席を求められたときは出席しなければならない |

**添付から文言を整理した理由**

- 「予備費の議決」は、87条1項（予備費を**設ける**国会の議決）と2項（支出の**事後承諾**）が混ざる。問6の棚は予備費＝国会側。制作案どおり **予備費支出の事後承諾〔87条2項〕** にする。1項の設置議決はこの18項目には載せない。
- 「会議の公開の停止」は条文の用語ではない。57条1項ただし書は **秘密会を開く** 議決。**秘密会の議決** とする。
- この18項目は添付の整理であり、権能の完全な網羅ではない。図にも「この一覧は権能の全部ではない」とは大きく書かず、プロンプトでは網羅表示を禁止する。

**書かない／描かない**

- 「国会の権能は必ず両院一致」。59条2項の再可決、67条の衆議院優越などがある。
- 左右を一対一で結ぶ線。右に空欄や架空項目を足して10行に揃える。
- 模試の紙面・正誤・出版社。ブランド名。
- 予算の議決（86条）など、添付18項目以外の追加。
