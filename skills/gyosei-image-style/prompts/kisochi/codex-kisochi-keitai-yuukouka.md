# 青少年の特定携帯電話を売るとき、閲覧制限は必ず？

- 状態: 未生成
- 関連: LEC市販模試 第2回 問57。国が有害と決めるかの図から分離。青少年インターネット環境整備法16条。有効化措置は、青少年有害情報の閲覧を制限するため、端末に組み込まれたプログラムの機能を制限する措置。携帯電話インターネット接続役務提供事業者等は、特定携帯電話端末等を販売するとき、契約の相手方または使用者が青少年なら、有効化措置を講じなければならない。保護者が希望しない旨を申し出たときは、この限りでない。有効化措置の必要性が低いものとして総務省令・経済産業省令で定める端末は除く。
