# PFIと指定管理者、何が違う？

- 状態: 未生成
- 関連: LEC市販第2回 問47。PFIは民間の資金、経営能力、技術的能力で公共施設を整備し運営する。指定管理者は公の施設の管理。運営権は所有を残し、料金は事業者の収入。水道施設運営権は、2018年12月12日公布の改正法（平成30年法律第92号）で入った。現行の水道法24条の4は、国土交通大臣の許可。運営権者が指定管理者を兼ねることはありうる。同じ制度ではない。
- 関連: LEC公開1 問48。水道のコンセッションは、所有を地方公共団体に残し、渡すのは運営権。機関委任事務の図とは別。
