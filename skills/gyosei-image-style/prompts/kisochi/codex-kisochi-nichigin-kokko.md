# 日銀は、地方の金銭も扱わなければならない？

- 状態: 生成済み
- 関連: TAC第3回 問50。日本銀行法35条1項は、日本銀行が法令で定めるところにより国庫金を取り扱わなければならない、と定める。同条2項は、その取扱いに必要な業務を行うことができる、と定める。地方公共団体の金銭を取り扱わなければならない、とは書いていない。都道府県の公金は、金融機関を指定して取り扱わせる。地方自治法235条1項。市町村は、指定して取り扱わせることができる。同条2項。資本金1億円と政府出資5500万円は別図の論点。硬貨と銀行券の図も別。上書きしない。
