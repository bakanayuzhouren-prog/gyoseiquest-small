# 排他的経済水域は、何海里？

- 関連: TAC第3回 問48。頁は妥当なもの。正解は1。海洋法に関する国際連合条約57条。排他的経済水域は、領海の外側で、基線から200海里を超えない。条約は1982年採択、1994年発効。日本は批准している。アメリカは批准していない。廃棄物の投棄防止はロンドン条約。水鳥の生息地はラムサール条約。海上における人命の安全はSOLAS条約。1914年の条約は発効せず、その後の条約は1933年に発効した。東北地方太平洋側の海溝は日本海溝。マリアナ海溝はマリアナ諸島の東側。
