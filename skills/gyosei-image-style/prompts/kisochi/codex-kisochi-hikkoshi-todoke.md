# 引っ越すとき、何を届ける？

- 状態: 未生成
- 関連: TAC第2回 問54。住民基本台帳法22条・23条・24条。通常カード「転出届は転出をする日までがあらかじめ」。
- 保存先: assets/images/deepdive/learn/kisochi/hikkoshi-todoke.png
- 画像キー: learn/kisochi/hikkoshi-todoke
- 見せ方: 引っ越しの順のチャート。表は置かない。同じ文を下に繰り返さない。
- 配役: てらしぃ指定で、届ける本人はちゃちゃロット。案内役をもう1体足さない。緑の講師スーツのまま。

法律の芯（図に印字する文）:

- 他の市町村へ出る前は、転出届。あらかじめ。市町村長へ。記載は氏名、転出先、転出の予定年月日。24条。
- 着いたあとは、転入届。転入をした日から14日以内。新しい市町村長へ。22条。
- 同じ市町村の中の引越しは、転居届。転居をした日から14日以内。あらかじめではない。23条。
- 転出を、転出した後14日以内、と書かない。
