# 転入のあと？転出の前？

根拠は住民基本台帳法。転入は転入の日から14日以内。22条の届出事項は、氏名、住所、転入をした年月日、従前の住所、世帯主である旨または世帯主の氏名と続柄で尽きない。転入前の住民票コード（6号）と、国外から転入した者などの政令事項（7号）がある。図の転入欄は、この問で問われた事項に限る。同じ市町村の中の転居は、転居をした日から14日以内。あらかじめではない。氏名、住所、転居をした年月日、従前の住所、世帯主である旨または世帯主の氏名と続柄。23条。転出は、あらかじめ、氏名、転出先、転出の予定年月日。24条。出てから14日以内ではない。転出届に、従前の住所を届け出る規定はない。従前の住所が必要と問われたのは転入届である。
