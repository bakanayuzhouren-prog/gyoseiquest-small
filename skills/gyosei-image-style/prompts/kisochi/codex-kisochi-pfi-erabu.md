# PFIの事業者は、だれが選ぶ？

- 状態: 未生成
- 関連: LEC市販第2回 問47。公共施設等の管理者等が、実施方針を定めることができる。5条。公表したあと、適切と認める事業を選定することができる。7条。選定したときは、管理者等が民間事業者を公募の方法等で選定する。8条。法人でない者は、募集に応じることができない。9条。これは選定の主体とは別。管理者等は大臣だけではない。2条3項。公共施設等には道路、港湾、水道、庁舎、医療施設、船舶、人工衛星も入る。2条1項。運営権は物権とみなす。敷地の所有は除く。24条。登録令は平成23年政令第356号。
