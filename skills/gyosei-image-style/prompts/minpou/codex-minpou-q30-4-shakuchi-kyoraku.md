# 問30肢4 借地上の建物の競落

- 状態: 生成済み。てらしぃがこの画像の修正を言うまで上書きしない
- 関連: LEC公開1 問30の肢4。ほかの模試に同じ借地競落の問はない。

- 画像キー: learn/minnpou/q30-4-shakuchi-kyoraku
- 論点: 借地上の建物の競落人は、敷地賃借権の譲受けについて地主の承諾または裁判所の承諾に代わる許可が必要（民法612条、借地借家法20条）

```text

Answer band: 地主の承諾、または裁判所の承諾に代わる許可。許可の申立ては、代金を払った後2か月以内（民法612条、借地借家法20条）
```
