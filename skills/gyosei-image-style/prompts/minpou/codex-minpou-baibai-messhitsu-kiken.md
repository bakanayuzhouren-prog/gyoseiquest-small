# 渡す前に家が壊れた。買主は、何ができる？

- 状態: 未生成

- 保存先: assets/images/deepdive/learn/minnpou/baibai-messhitsu-kiken.png

- 論点: 損害賠償のできる・できないは売主の帰責だけで決まる。買主の帰責の有無では変わらない。解除と支払拒絶は、買主の帰責で変わる

参考表の○は「代金を払え」ではない。代金債務が危険負担では消えない、という意味。図の語は「残る」。青丸の×（双方に帰責事由がないときの損害賠償）は415条1項ただし書どおり。○に変えない。
