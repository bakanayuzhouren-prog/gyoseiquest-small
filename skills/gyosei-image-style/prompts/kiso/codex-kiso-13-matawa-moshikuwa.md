# Codex用 — 又は vs 若しくは

対比2語。左＝又は、右＝若しくは。及び／並びには載せない。

- 保存先: `assets/images/deepdive/learn/kiso/matawa-moshikuwa.png`
- 画像キー: `learn/kiso/matawa-moshikuwa`

## 法律の芯（崩すな）

- **又は**＝選択の**大きい括り**（一番外側の「または」）。
- **若しくは**＝その内側の**小さい選択**。
- 選択（どれか）の話。併合（及び／並びに）と混ぜない。

**書かない**: 若しくは＝大きい括り。又は＝内側。どちらでもよい。
