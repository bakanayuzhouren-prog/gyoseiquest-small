# Codex用 — 再議は、いつ義務？

異議があるときの再議は十日以内にできる。義務になる再議と、再選挙は別の箱にする。

## 法律の芯（崩すな）

- 地方自治法176条1項。議決に異議があるときは、この法律に特別の定めがあるものを除き、議決の日から十日以内に、理由を示して再議に付することができる。条例の制定若しくは改廃、又は予算に関する議決は、送付を受けた日から十日以内である。できるのであって、義務ではない。
- 176条4項。議決又は選挙が、権限を超え、又は法令若しくは会議規則に違反すると認めるときは、理由を示して、再議に付し、又は再選挙を行わせなければならない。議決は再議、選挙は再選挙である。この項に、十日以内とは書いていない。
- 177条1項。義務に属する経費、非常の災害による応急若しくは復旧の施設のために必要な経費、又は感染症予防のために必要な経費を、議会が削除し又は減額したときは、その経費及びこれに伴う収入について、理由を示して再議に付さなければならない。再選挙ではない。この項にも、十日以内とは書いていない。
- 出席議員の三分の二、二十一日の審査申立て、不信任とみなすこと、専決処分は、この図に入れない。
