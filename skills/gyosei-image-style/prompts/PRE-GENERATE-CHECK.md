## 法律

- [ ] 答え帯・暗記が **答案の芯** と矛盾しない
- [ ] 条文番号が正しい（145≠423、126の5年／20年起算の取り違えなし）
- [ ] 主体・向き（誰が誰に）が入れ替わっていない
- [ ] 「又は／かつ」「原則／例外」が条文どおり
- [ ] タイトルが誤誘導でない（「要る2つ」＝両方必要、「占有だけで足りる」等）
- [ ] 図に「切る／切れない／本人に切る」がない（スタイリッシュな法律日本語）

## 型（あぷし）

- [ ] 左見出しは「論点」（Q&A。YES／NO／短答のみ。**GOとYESを混在させない**）
- [ ] 右見出しは「ひっかけ」（「問が聞くこと」「（聞かない）」禁止）
- [ ] 人物下は `役割（何をしたいか）`（「だれが」禁止）
- [ ] 説明中に（〇条）がある
- [ ] 案内役はちゃちゃロットだけ。フクロウ・クマ・タヌキ・猫を置くな（てらしぃの明示なし）
- [ ] ちゃちゃロットは **緑の講師スーツ（白シャツ・ズボン・靴）を必ず着ている**。裸・肌色むき出しの胴体・パンツなし・下着だけは不合格
- [ ] ちゃちゃロットは **1体だけ**。白抜き切り抜きの二重貼り・名札「ちゃちゃロット」禁止。答え帯・暗記文に足や指し棒を重ねない
