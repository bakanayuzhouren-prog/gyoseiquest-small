# Codex用 — 下級裁の裁判官は内閣が任命（総理ではない）

対比2語。左＝内閣、右＝内閣総理大臣（ひっかけ側の論点）。名簿は中央。

- 保存先: `assets/images/deepdive/learn/kenpou/kakyu-saibankan-ninmei.png`
- 画像キー: `learn/kenpou/kakyu-saibankan-ninmei`

## 法律の芯（崩すな）

- 憲法80条1項: 下級裁判所の裁判官は、最高裁判所の指名した者の名簿によって、**内閣**でこれを任命する。
- 任期10年、再任可。定年は法律（裁判所法50条）。
- 国務大臣の任命は**内閣総理大臣**（68条1項）。ここだけ総理。
- 最高裁長官は内閣が指名し、天皇が任命（6条2項）。
- 最高裁のその他の裁判官は内閣が任命（79条1項）。

**書かない**: 下級裁は内閣総理大臣が任命。下級裁は最高裁が任命。下級裁は天皇が任命。
