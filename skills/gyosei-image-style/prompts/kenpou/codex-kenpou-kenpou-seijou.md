# Codex用 — 天皇が公布するもの（けんぽうせいじょう）

対比。左＝公布するもの、右＝公布しないもの。条文は公布（交付と書かない）。

## 法律の芯（崩すな）

- 憲法7条1号: 憲法改正、法律、政令及び条約を**公布**すること。
- 語呂: けん＝憲法改正、ぽう＝法律、せい＝政令、じょう＝条約。
- 予算・省令・最高裁判所規則は公布しない。予算は内閣が告示する。
- 内閣の助言と承認に基づく国事行為（3条・7条）。

**書かない**: 交付。予算も公布。省令も公布。けん＝法律。
