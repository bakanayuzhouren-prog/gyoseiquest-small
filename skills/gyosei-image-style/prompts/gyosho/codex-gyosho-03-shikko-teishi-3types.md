# Codex用 — 行訴法（03）執行停止の3類型（効力／執行／手続続行）

- 保存先: `assets/images/deepdive/gyosho/shikko-teishi-3types.png`
- 画像キー: `gyosho/shikko-teishi-3types`
- 条文: 行訴25条2項ただし書（効力停止の補充性）

## 法律の芯（崩すな）

| 類型 | イメージ | 具体例 |
|---|---|---|
| **処分の効力の停止** | 処分そのものがなかった状態に近づける（最も強い） | 営業許可の取消処分 → 許可が生きていた状態に戻す／免職 → 公務員の地位が続く状態 |
| **処分の執行の停止** | 処分は残るが、強制執行・実力行使を止める | 代執行の戒告後の実行を止める／強制徴収の差押えを止める |
| **手続の続行の停止** | 一連の手続の次ステップを止める | 収用裁決後の明渡し手続の続行を止める／免許取消→次の手続進行を止める |

**補充性（25条2項ただし書）**  
効力の停止は、**執行の停止**または**手続続行の停止**で目的を達せられるときは**できない**（最後の手段）。

**申立てのみ** 裁判所の**職権**では執行停止もその取消しもできない（25・26）。口頭弁論は不要だが、あらかじめ**当事者の意見をきく**（25条6項）。

**書かない**: 効力停止＝常に第一選択／職権で止められる／3類型は同じ強さ。
