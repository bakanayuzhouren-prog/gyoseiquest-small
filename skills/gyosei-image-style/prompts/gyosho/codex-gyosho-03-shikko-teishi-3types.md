# Codex用 — 行訴法（03）執行停止の3類型（効力／執行／手続続行）

- 保存先: `assets/images/deepdive/gyosho/shikko-teishi-3types.png`
- 画像キー: `gyosho/shikko-teishi-3types`
- 条文: 行訴25条2項ただし書（効力停止の補充性）

## 法律の芯（崩すな）

行は**求める順**（弱いほうから）。効力を先頭に置くな。

| 類型 | 止めるもの |
|---|---|
| **処分の執行の停止** | 処分は残る。強制執行・実力行使を止める |
| **手続の続行の停止** | 次の手続の進行を止める |
| **処分の効力の停止**（最後） | 処分がなかった状態に近づける。最も強い |

**補充性（25条2項ただし書）**  
効力の停止は、**執行の停止又は手続の続行の停止によって目的を達することができる場合には、することができない**。  
判断軸は「**執行又は手続続行で目的を達することができるか**」。達することができる → 効力の停止はできない。  
「効力の停止で足りるか」と書くのは軸が逆。

**申立てのみ** 裁判所の職権では執行停止もその取消しもできない（25・26）。口頭弁論は不要だが、あらかじめ**当事者の意見をきく**（25条6項）。

**書かない**: 効力停止＝第一選択／職権で止められる／3類型は同じ強さ／判断軸を「効力の停止で足りるか」にする。
