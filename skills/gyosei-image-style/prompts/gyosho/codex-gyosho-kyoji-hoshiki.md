# Codex用 — 教示の方式（書面／口頭／第三者）

略称は **行審法**（行政不服審査法）。図に「行服法」「行服」と書くな。

## 法律の芯（崩すな）

- 書面で処分したときの相手方への教示は、書面でしなければならない（行審法82条1項本文、行訴法46条1項本文）。口頭で教示しただけでは足りない。
- 口頭で処分したときは、教示義務がない（各ただし書）。
- 行審法82条2項の求めによる教示は、原則として口頭でも足りる。書面による教示を求めたときだけ、書面でしなければならない（3項）。
- 行訴法に第三者の求めはない。
- 教示を求める期間の定めは条文にない。教示に書く期間は、不服申立期間または出訴期間である。混ぜるな。
- 執行停止ができる旨は必要的教示の項目にない。
- 図中の略称は **行審法** と **行訴法** だけ。

**書かない**: 行服法。行服。口頭処分でも書面教示が必須。第三者への教示も常に書面。行訴でも第三者が求めれば義務。求めは出訴期間内に限る（条文にないので断定するな）。
