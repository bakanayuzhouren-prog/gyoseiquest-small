# Codex用 — 仮に守るなら、執行停止？民事の仮処分？

公権力の行使を仮に守る場面は、行訴法の執行停止・仮の義務付け・仮の差止めを使い、民事保全法の仮処分は使わない（44条）。公権力の行使にあたらない関係は、民事保全法の仮処分ができる。住民訴訟は別条で仮処分ができない。

## PRE-GENERATE-CHECK（行訴法25条・37条の5・44条・45条、地方自治法242条の2第10項）

e-Gov と照合。2026-10-15。

**44条** 行政庁の処分その他公権力の行使に当たる行為については、民事保全法の仮処分をすることができない。

**25条** 取消訴訟の仮の救済は執行停止。執行停止は民事保全法の仮処分ではない。

**37条の5** 義務付けの訴えには仮の義務付け、差止めの訴えには仮の差止め。

**45条** 争点訴訟は、私法上の法律関係に関する訴訟で、処分の存否または効力の有無が争点になる。45条は44条を準用しない。処分そのものの効力を仮処分で失わせる請求は44条に当たる。本案の私法上の請求（明渡し等）には民事保全法の仮処分ができる。

**できる側** 実質的当事者訴訟（地位の確認、給与の給付、損失補償の請求）。行政主体が私人と対等な立場でする売買・賃貸借・国有財産の払下げ契約。

**242条の2第10項** 住民訴訟の対象である財務会計上の違法な行為または怠る事実には、民事保全法の仮処分をすることができない。執行停止があるから禁じるのではない。

**書かない** 執行停止を仮処分と呼ぶ。取消訴訟から義務付け・差止めへ進む矢印。三つの訴えを一つの手続の順に並べる。仮差押え。形式的当事者訴訟の細目。損害要件の入替え。問題文・肢の転載。ブランド名。案内役。底部の3カード。同じ文の繰り返し。

**上段の形** 帯「処分その他公権力の行使（44条）」から、三本を並列に出す。矢印は各訴えから、その訴えの仮の救済へだけ。三本のあいだには矢印を引かない。三本の先は、一つの出口「民事保全法の仮処分はできない」にまとめる。

- 取消訴訟 → 執行停止（25条）
- 義務付けの訴え → 仮の義務付け（37条の5）
- 差止めの訴え → 仮の差止め（37条の5）
