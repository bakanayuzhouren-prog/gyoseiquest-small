# Codex用 — 仮処分で、止められる？

民事保全法の仮処分が禁じられるのは、行政庁の処分その他公権力の行使に当たる行為である（行訴法44条）。執行停止（25条）、仮の義務付け、仮の差止め（37条の5）は、その禁止の中身ではない。公権力の行使に当たらない法律関係は、民事保全法の仮処分ができる。

**44条** 行政庁の処分その他公権力の行使に当たる行為については、民事保全法の仮処分をすることができない。

**25条・37条の5** 取消訴訟の仮の救済は執行停止。義務付けの訴えには仮の義務付け、差止めの訴えには仮の差止め。これらは使える救済であり、「できない」欄に置かない。執行停止は、民事保全法の仮処分ではない。

**できない（民事保全法の仮処分だけ）**

- 処分・裁決そのもの。
- 実質的当事者訴訟でも、形式的当事者訴訟でも、処分の効力を仮に動かす請求。

**できる（民事保全法の仮処分）**

- 実質的当事者訴訟の、地位の確認、給与の給付、損失補償の請求。被告は法律関係の相手方。
- 行政が私人と対等にする売買、賃貸借、国有財産の払下げ。
- 争点訴訟の本案である私法上の請求（明渡し等）。45条は44条を準用しない。処分の効力を失わせる仮処分は、44条に当たる。
- 形式的当事者訴訟のうち、補償の額を当事者として争う請求。

**住民訴訟** 財務会計上の行為と怠る事実は、地方自治法242条の2第10項で仮処分ができない。行訴法44条ではない。

**書かない** 執行停止を「できない」欄に置くこと。執行停止を仮処分と呼ぶこと。仮差押え。取消から義務付け・差止めへ進む矢印。案内役。底部の3カード。同じ文の繰り返し。ブランド名。
