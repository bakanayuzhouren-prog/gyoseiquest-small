## 法律の芯（崩すな）

### A. 事情裁決（45条3項）

| | 内容 |
|---|---|
| 前提 | 審査請求に**理由あり**（**違法又は不当**） |
| 条件 | 取消・撤廃→**公の利益に著しい障害**→諸事情→**公共の福祉に適合しない** |
| **主文** | **①違法又は不当であることを宣言** ＋ **②棄却** |
| × | **却下**／主文で**適法**／理由中だけ／**違法のみ**／不作為・再調査 |

### B. 4条（審査請求をすべき行政庁）※旧教材6条

| 号 | 請求先 |
|---|---|
| 柱書 | **条例**で請求先を定め得る |
| **1号** | 庁の長等が**処分庁** → **自己**（宮内庁長官・金融庁長官等） |
| **2号** | 宮内庁長官・**庁の長**が**上級** → **その長** |
| **3号** | **主任大臣**が上級 → **大臣** |
| **4号** | その他 → **最上級行政庁** |

### C. 上級は自ら処分できない（46条2項・49条3項）

| 審査庁 | 措置 |
|---|---|
| **上級行政庁** | **命ずる** |
| **処分庁** | **自ら処分** |

### D. 15条承継

| | 手続 |
|---|---|
| 相続・合併・分割 | **当然承継**＋**3項書面届出** |
| 権利譲受 | **6項 審査庁許可** |
| 4項 | 死亡者宛通知→承継者**到達**→承継者に**効力** |
| 5項 | 相続人2人以上→**1人通知＝全員みなし** |

**書かない**: 相続も許可／譲受は届出だけ／不作為に事情裁決／庁の長処分に大臣へ。
