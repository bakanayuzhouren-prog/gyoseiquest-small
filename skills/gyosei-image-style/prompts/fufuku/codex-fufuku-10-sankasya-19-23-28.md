## 法律の芯（崩すな）

### A. 不作為も参加人（13条）— **審理員の許可**

| | 内容 |
|---|---|
| 13条1項 | 利害関係人は**審理員の許可**で参加 |
| 対象 | 「処分又は**不作為に係る処分**」— 不作為も同じ |
| 13条2項 | 審理員が参加を**求める**ことも可 |
| **×** | **審査庁の許可**（→15条6項**譲受**の地位承継） |
| 75条 | 審査会段階の**補佐人**＝審査会の許可（別レイヤー） |

### B. 19条記載

| | 処分2項 | 不作為3項 |
|---|---|---|
| 核心 | **知った年月日** | **申請内容・年月日** |
| 趣旨理由 | ○ | **×** |
| 教示 | ○ | **×** |
| 共通 | 氏名住所、請求年月日 | 同左 |

### C. 23〜24条補正 vs 行手法7条

| | 行服23〜24条 | 行手法7条 |
|---|---|---|
| 対象 | **審査請求書**（19条違反） | **申請**の形式不備 |
| 義務 | **補正命令**（相当期間） | **速やかに**補正求め**又は**拒否 |
| 例外 | **24条2項** 不適法で補正不能**明らか**→命令不要で却下 | — |
| 未補正 | **24条1項** 審理を経ず却下可 | 拒否等 |

### D. 28条 vs 行手法

| | 行服28条 | 行手法 |
|---|---|---|
| 文言 | 相互協力＋計画進行を**図らなければならない** | 同条**なし** |
| 性質 | **義務** | 11条2項審査促進＝**努めるものとする**（努力） |
| 主体 | 審理関係人＋審理員 | — |

**書かない**: 参加人＝審査庁許可／不作為に知った日／28条＝努力／23条＝努力。
