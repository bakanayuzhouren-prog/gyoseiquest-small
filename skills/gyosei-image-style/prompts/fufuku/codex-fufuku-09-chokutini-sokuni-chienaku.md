## 法律の芯（崩すな）

行服法は**速やかにが最多**。**遅滞なくは4箇所**。**直ちに**は条文上**3箇所**（＋57条教示**内容**に「直ちに審査請求できる旨」）。

### 直ちに（義務語句）

| # | 条文 | 内容 |
|---|---|---|
| 1 | **21条2項** | 処分庁経由の審査請求→審査庁へ**直ちに**送付 |
| 2 | **29条1項** | 審理員指名→写しを処分庁等へ**直ちに**送付 |
| 3 | **69条3項** | 事後承認得られず→総務大臣**直ちに**罷免 |

※ **57条**は義務語句は**遅滞なく**、教示内容に「**直ちに**審査請求できる旨」を書く（直ちに4つ目と数えるなら**内容**として注記）。

### 遅滞なく

| # | 条文 | 内容 |
|---|---|---|
| 1 | **37条2項** | 意見聴取後→審理期日・終結予定時期を**遅滞なく**決定通知 |
| 2 | **42条1項** | 審理終結→審理員意見書を**遅滞なく**作成 |
| 3 | **44条** | 答申等後→**遅滞なく**裁決 |
| 4 | **57条** | 再調査3か月経過→**遅滞なく**直ちに審査請求できる旨を**書面教示** |

※ **28条**は「計画的進行」の**努力**（遅滞なくではない）。

### 速やかに（代表・試験頻出）

| 条文 | 内容 |
|---|---|
| 22条1〜4項 | 誤教示→送付+通知 |
| 25条2項等 | 執行停止の決定 |
| 41条3項 | 終結通知（意見書提出予定時期） |
| 42条2項 | 意見書→審査庁へ**提出**（作成は遅滞なく・提出は速やかに） |
| 55条1項 | 教示漏れ→審査請求書を処分庁へ |
| 83条3項 | 教示なし→不服申立書送付 |
| 52条 | 物件返還 等 |

**42条の切り分け**: 作成＝**遅滞なく**／提出＝**速やかに**（セット問題）。

**書かない**: 直ちに＞速やかに＞遅滞なく（基礎法学順）を行服法全体に適用／28条＝遅滞なく。
