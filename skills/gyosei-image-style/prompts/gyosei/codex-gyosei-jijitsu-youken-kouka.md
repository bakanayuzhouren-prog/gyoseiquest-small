# Codex用 — 裁量は？要件、効果は？

## 法律の芯（崩すな）

- 事実認定は、何が起きたかを確定する作業である。原則として行政庁の裁量はない。裁判所が自ら認定する。
- 要件裁量は、確定した事実が法律の要件に当たるかの判断である。在留期間の更新を適当と認めるに足りる相当の理由があるかは、法務大臣の裁量である（最大判昭53.10.4）。裁判所は、法務大臣と同じ立場でやり直さない。
- 効果裁量は、要件を満たしたあと、どの処分にするかの選択である。懲戒事由があるときの戒告、減給、停職、免職の選択は、懲戒権者の裁量である（最判昭52.12.20）。裁判所は、自ら軽い処分を割り出して軽重を比べない。著しく妥当を欠くときに限り違法である。
- 要件裁量があるから、事実認定にも裁量が広く及ぶ、は誤り。

**書かない:** 殴ったことが懲戒事由に当たること自体を、在留更新の相当の理由と同じ要件裁量として描く。最判平23.6.7（理由の提示）。職権取消し、撤回、不可変更力。
