## 既存知識との差分

### 追加ではなく補強で足りるもの

- 行政代執行法、国賠、聴聞・弁明、職権証拠調べは既存比較表があるため、まずは「君の教科書！」で苦手者に再提示する。
- 心裡留保、時効、相殺、詐害行為取消は既存カードとTACカードがあるため、誤答履歴から再編成する。
- 商法・会社法は条文番号が近く混線しやすいため、個別追加より比較表形式が有効。

### 新規章として作る価値が高いもの

- 「令和時事・新法まとめ」: AI推進法、空き家、鳥獣、個情法。
- 「令和判例まとめ」: 性同一性障害法、国の関与。
- 「行政法の手続比較」: 聴聞・弁明、意見公募、秩序罰、執行停止。
- 「民法改正・時効・親族」: R8親族改正、時効完成後承認、相殺。

## 君の教科書！への投入方針

1. 誤答履歴から、科目・分野別に苦手章を自動生成する。
2. 誤答2回以上の論点は「最優先章」として先頭に出す。
3. 付箋がある科目は「自分で気になっている章」として表示する。
4. TAC模試の新知識は「今日インプットする新知識」として、時事・判例・条文比較に分けて提示する。
5. 判断が必要な記述式問41〜46の正解確定は、てらしぃ確認後に `validationStatus` を更新する。

## チェック観点

- TAC模試本文・選択肢の全文転載を避け、論点要約と自作問題に留める。
- 令和改正・新法・最新判例は、条文番号と施行時期を確認してから本格反映する。
- 生成した教科書は、出典候補・根拠条文・復習アクションを分けて表示する。
- 可否判断が曖昧な内容は、アプリへ確定投入せず「てらしぃ確認」扱いにする。
