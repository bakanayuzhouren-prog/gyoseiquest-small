DB = 原典置き場（佐藤先生NOTE等を貼る場所）
N・C = なかチャンネル（中谷先生）記述予想メモ
content/textbook/app = アプリ表示用（条文順・出題形式）

運用:
1. 原典を DB/<科目>/ に置く。なかチャンネル由来は N・C/<科目>/ にメモ
2. content/textbook/app/<科目>/ に再構成.mdを書く（記述はQ1型）
   - 問: 長い事例＋トラップ。末尾だけ一点＋「40字程度で記述しなさい。」
   - 解答例: NOTE／なかチャンネルのポイント答案1文。空白除き**必ず38〜45字**＋（〇〇字）
   - 切るポイント: トラップの切り方
   - 画像: 問の下 [[image:textbook/<slug>/q{N}]]
   - 佐藤×中谷が同一論点なら1問に併合して濃く／論点が違えば別問（AGENTS.md「N・C」節）
3. AGENTS.md「教科書・記述カードの標準構成（Q1型）」と skills/gyosei-kijutsu-textbook/SKILL.md
4. npm run bundle:db-textbooks
