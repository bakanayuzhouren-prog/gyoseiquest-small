対象アカウント: @appshi113（あぷし / 行政書士受験生）

========================================
投稿前ゲート（必須）
========================================

1. Cursorが画像を目視し、誤情報をてらしぃへ報告する
2. 誤りがあれば Cursor が Codex 用プロンプトを prompts/codex-fix-*.md に置く
3. てらしぃが Codex に渡して図を直す
4. てらしぃ目視OKになってから、下のコピペ予約へ進む

チェック前の予約投稿はしない（AGENTS.md「教材画像の誤情報チェック」）。

========================================
コピペで予約投稿する手順（X公式）
========================================

1. このフォルダの「記述対策」内で、投稿したい番号フォルダを開く
2. 「コピペ本文.txt」をメモ帳で開き、全文をコピー
3. X（Webまたはアプリ）で投稿作成を開く
4. 本文を貼り付け
5. 同じフォルダの「投稿用画像.png」を添付
6. 「スケジュール設定」で日時を予約 → 投稿予約
   日時は `記述対策/予約カレンダー.txt` どおり。毎日 朝 8:00 / 昼 12:00 / 晩 21:00。番号の若い順。

※1フォルダ＝1投稿（本文1つ＋画像1枚）
※本文は AGENTS.md の完成形のみ。語を差し替える。句点なし。ハッシュタグは #行政書士受験生 から。型を勝手に変えない。

増やし方
========================================

新規図ができたら:
1. 記述対策/NN-題名-qN/ を作る
2. 投稿用画像.png を置く
3. コピペ本文.txt を置く（下の型）
4. 予約カレンダー.txt に1行追加
