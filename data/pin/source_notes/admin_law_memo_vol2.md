# 行政書士試験 学習メモ（第2巻：1-30ページ）

## 1. 国家賠償法1条：加害公務員の特定（P1-4）
**【重要判例：最判昭57.4.1】**
- **争点：** 誰がやったかハッキリしない場合でも、国に責任を問えるか？
- **結論：** **特定できなくても、国は責任を負う。**
- **重要フレーズ（記述対策）：** 「一連の職務上の行為の過程において他人に被害を生じさせた場合、**具体的にどの公務員のどのような違法行為によるものかを特定できなくても**、国または公共団体は賠償責任を負う。」

## 2. 公権力の行使（P5-12）
- **国賠法1条の対象：** 警察、税務署、公立学校の教育活動、公立病院の「検診」など。
- **対象外：** 国や地方公共団体が行う「経済活動（土地の買収など）」は、民法が適用される。

## 3. 国賠法2条：公の営造物の設置・管理の瑕疵（P13-22）
**【重要ポイント】** 道路や橋が壊れていて怪我をした場合。公務員にミス（過失）がなくても、国は責任を負う（**無過失責任**）。
- **【最判昭50.6.26：赤色灯標柱事件】**
    - 工事標識・赤色灯が先行車により転倒した直後で、原状回復の時間的余裕がなければ管理の瑕疵はない。
- **【最判昭50.7.25：故障車の長時間放置】**
    - 約87時間放置して安全措置を怠れば、道路管理の瑕疵があり得る。警察に規制権限がある、では道路管理者は免れない。
- **【最判昭59.1.26：大東水害訴訟】**
    - 未改修・改修途上の河川は過渡的な安全性で足りる。氾濫したことだけでは直ちに瑕疵ではない。昭56.12.16は大阪国際空港（供用関連瑕疵）。

## 4. 警察官の職務執行と国家賠償（P23-30）
**【重要判例：パトカー追跡事件】**
- **争点：** 逃走車を追いかけて、その逃走車が第三者と事故を起こした場合、警察に責任はあるか？
- **結論：** **追跡方法が不相当（やりすぎ）であれば違法。**
- **重要フレーズ：** 「追跡が職務目的を遂行する上で不必要であるか、または**追跡の開始・継続・方法が不相当**である場合に限って違法となる。」

# 行政書士試験 学習メモ（第2巻：31-60ページ）

## 1. 国家賠償法3条：費用負担者の責任（P31-38）
**【重要ポイント】** 公務員の給料を払っている人と、実際に仕事を指示している人が違う場合、どちらに責任があるか？
- **結論：** **どちらも責任を負う。**
- **記述対策フレーズ：** 「公務員の選任監督者と俸給等の負担者が異なる場合、**俸給等の負担者もまた**、損害を賠償する責任を負う。」
- **理由：** 被害者がどこに請求すればいいか迷わないようにし、救済を確実にするため。

## 2. 損失補償（そんしつほしょう）：憲法29条3項（P39-48）
**【意味】** 適法な行政活動（道路を作るなど）によって、特定の人が損害を受けた場合に、国がお金を払って埋め合わせること。
- **【最判昭43.11.27：森林法違憲判決】**
    - 補償が必要なのは、それが特定の個人に対する**「特別の犠牲」**といえる場合。
- **【最判昭48.4.25：油樽事件】**
    - 補償の程度は、当時の時価による**「正当な補償（完全な補償）」**でなければならない。

## 3. 地方自治法：住民の権利と直接請求（P49-56）
地方自治は「民主主義の学校」と呼ばれ、住民が直接参加できる仕組みが重要です。
- **条例の制定・改廃請求：** 有権者の**50分の1**以上の署名が必要。請求先は「長」。
- **事務監査請求：** 有権者の**50分の1**以上の署名が必要。請求先は「監査委員」。
- **解職請求（リコール）：** 有権者の**3分の1**以上の署名が必要。請求先は「選挙管理委員会」。

## 4. 自治事務と法定受託事務（P57-60）
- **自治事務：** 地方公共団体が自分の判断でやる仕事（例：図書館の運営、ゴミ処理）。
- **法定受託事務：** 本来は国の仕事だが、法律によって地方に任されている仕事（例：戸籍事務、国政選挙）。

# 行政書士試験 学習メモ（第2巻：61-90ページ）

## 1. 普通地方公共団体の議会と長（P61-68）
地方自治体では、住民から直接選ばれた「議会」と「長（知事・市町村長）」が互いに牽制し合う**二元代表制**をとっています。
- **長による再議（さいぎ）：** 議会の議決に納得いかない場合、長はもう一度考え直すよう求めることができる。
- **専決処分（せんけつしょぶん）：** 緊急時など、議会が開けない場合に長が代わりに決めること。ただし、後で議会の**承認**が必要。

## 2. 住民監査請求（P69-78）
住民が「役所のお金（公金）の使い方がおかしい！」と思った時に、まず監査委員に調べるよう求める制度です。
- **対象：** 公金の支出、財産の管理、怠る事実（取るべきお金を取っていない）など。
- **期間：** 原則として、その行為があった日から**1年以内**。
- **前置主義：** 次の「住民訴訟」を起こすには、まずこの「住民監査請求」を必ず先にしなければならない。

## 3. 住民訴訟（じゅうみんそしょう）（P79-85）
監査の結果に納得いかない場合、裁判所に訴える制度です。
- **原告：** その自治体の**住民**であれば、直接の被害がなくても訴えられる（客観訴訟）。
- **【重要判例：最大判昭62.4.22】（議員の海外視察）**
    - 視察が実態のない「観光旅行」であれば、公金の支出は違法となり、参加した議員に返還を求めることができる。

## 4. 地方自治体に対する国の関与（P86-90）
国が地方に対して行うアドバイスや命令のルールです。
- **原則：** 必要最小限度でなければならず、地方の自主性を尊重しなければならない。
- **是正の要求：** 地方の仕事が法律違反である場合、大臣や知事が「直しなさい」と求めること。

# 行政書士試験 学習メモ（第2巻：91-110ページ）

## 1. 事務の委託と広域連合（P91-98）
一つの自治体では解決できない問題を、他の自治体と協力して行う仕組みです。
- **事務の委託：** 自分の仕事の一部を、他の自治体に「お願いします」と任せること（規約を作り、議会の議決が必要）。
- **一部事務組合：** 特定の仕事（例：ゴミ処理、火葬場の運営）を共同で行うために作る新しい組織。
- **広域連合：** より広い範囲で、より複雑な仕事（例：介護保険の運営）を共同で行うための強力な組織。

## 2. 公の施設（おおやのしせつ）（P99-104）
住民の福祉を増進するために自治体が設ける施設（図書館、公園、体育館など）です。
- **設置・廃止：** 必ず**条例**で定めなければならない。
- **正当な理由なき拒否の禁止：** 住民が施設を使うのを、正当な理由なく拒んではならない。
- **不当な差別的扱いの禁止：** 特定の住民を不当に有利にしたり、不利にしたりしてはならない。

## 3. 指定管理者制度（P105-108）
公の施設の管理を、民間企業やNPO法人に任せる仕組みです。
- **導入のルール：** あらかじめ**条例**で定める必要がある。
- **管理の権限：** 指定管理者は、施設の利用許可を出す権限も持つことができる。

## 4. 関与の類型（P109-110）
国や県が、下の自治体に対して行う働きかけの名称です。
- **技術的な助言・勧告：** 「こうするといいですよ」というアドバイス。
- **是正の要求：** 「法律違反だから直しなさい」という強い命令。
- **同意：** 地方が何かをする前に、国などの許可を得ること。
