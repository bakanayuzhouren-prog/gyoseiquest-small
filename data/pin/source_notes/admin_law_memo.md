# 行政書士試験 学習メモ（1-30ページ）

## 1. 租税法律関係と信義則（P1-3）
**【最判昭62.10.30】**
- **争点：** 租税法律主義が支配する世界で「信義則」は適用されるか？
- **結論：** **適用され得る。**
- **重要ポイント（試験頻出）：** - 本来、租税法律主義が優先されるため、信義則の適用は**慎重**でなければならない。
    - 「特別の事情」がある場合に限り、例外的に適用される。
    - 本事案（青色申告の更正）では、納税者の過失もあり「特別の事情」は認められず、適用は否定された。

## 2. 公法と私法：私法規定の適用（P4-7）
**【最判昭28.2.18 / 最判昭39.10.29】**
- **公有水面埋立法に基づく使用許可：** 公法上の関係であっても、権利の譲渡について私法の規定（民法等）が類推適用されることがある。
- **農地買収処分と民法177条：** - 国による農地買収は公法上の行為だが、国が対抗要件（登記）を備えていない場合、第三者に権利を主張できない（民法177条の類推適用）。

## 3. 行政上の法律関係と消滅時効（P8-12）
- **原則：** 行政上の債権も、別段の定めがなければ**会計法により5年**で消滅する。
- **例外（重要）：** - **地方公務員への手当（退職金など）：** 公法上の権利であっても、性質上「私的債権」に近いものは、民法の規定（10年等）が適用される場合がある。
    - **国税の還付金：** 特別の定めがあるため、それに従う。

## 4. 行政法規に違反する私法上の行為（P13-18）
- **取締規定と効力規定：** - 行政法規（例：食糧管理法、宅建業法）に違反した契約の効力。
    - **結論：** 公法上の制裁を受けるとしても、私法上の契約（売買など）は**原則として有効**。ただし、公序良俗に反するほど著しい違反の場合は無効となり得る。

## 5. 行政主体と行政機関（P19-25）
- **行政主体：** 国、地方公共団体など（法人格を持ち、権利義務の帰属点となる）。
- **行政機関：** 行政主体のために活動する機関（法人格はない）。
    - **行政庁：** 意思決定し、外部に表示する権限を持つ（知事、大臣、税務署長など）。
    - **補助機関：** 行政庁を助ける（副知事、職員など）。
    - **執行機関：** 実力を行使する（警察官、消防士など）。

## 6. 行政立法の分類（P26-30）
- **法規命令：** 国民の権利義務に関わる。法律の委任が必要。
    - **執行命令：** 手続き的な細則。
    - **委任命令：** 新たな権利義務を定める（個別具体的な委任が必要）。
- **行政規則：** 組織内部のルール。法律の委任は不要。
    - **訓令・通達：** 上級機関から下級機関への命令。原則として国民を拘束しない。
    - **審査基準・処分基準：** 透明性を高めるための内部基準。

# 行政書士試験 学習メモ（31-60ページ）

## 1. 行政立法の委任と限界（P31-35）
**【監獄法施行規則事件：最判昭59.12.12】**
- **事案：** 法律の委任に基づき、施行規則で「接見時の指紋採取」を義務付けたことの是非。
- **重要フレーズ（記述対策）：** - 「法律の委任により発せられる命令は、その**委任の範囲内**でなければならない。」
    - 「本件規則は、法律が具体的に委任していない事項を定めたものであり、**法の委任の範囲を逸脱し無効**である。」
- **結論：** 指紋採取を義務付ける規定は無効。

## 2. 行政行為の概念と公定力（P36-42）
**【公定力の根拠】**
- **重要ポイント：** 行政行為に瑕疵（ミス）があっても、それが**重大かつ明白で当然無効**といえる場合を除き、権限のある機関によって取り消されるまでは、何人もその効力を否定できない。
- **記述対策キーワード：** 「法的安定性」「重大かつ明白な瑕疵」「当然無効」

## 3. 行政行為の撤回と取消し（P43-48）
- **職権取消し：** 行為時に瑕疵があった場合。遡及して効力を失わせる。法律の根拠は**不要**。
- **撤回：** 行為時は適法だったが、その後の後発的事情により効力を維持できなくなった場合。将来に向かって失効させる。法律の根拠は**不要**。
- **【重要判例：最判昭49.2.5】**
    - 授益的行政行為（許可など）の撤回には、**撤回すべき公益上の必要**が、**撤回により被る当事者の不利益**を上回る必要がある。

## 4. 行政上の強制執行と即時強制（P49-55）
**【宝塚市パチンコ条例事件：最判平14.7.9】**
- **事案：** 条例違反のパチンコ店建設に対し、市が「建築差止の裁判上の救済」を求めた事例。
- **重要フレーズ（記述対策）：** - 「行政権の主体として、行政上の義務履行を求める訴訟（行政自らが行う民事訴訟）は、**法律の特別の規定がない限り、許されない。**」
    - 「行政上の義務履行については、特段の事情がない限り、**行政代執行などの自力執行制度**によるべきである。」

## 5. 行政代執行のプロセス（P56-60）
- **要件（記述式頻出）：**
    1. 他人が代わってなすことができる義務（**代替的作為義務**）であること。
    2. 他の方法では履行を確保することが困難であること。
    3. その不履行を放置することが**著しく公益に反する**と認められること。
- **手続：** 戒告 → 通知 → 実行 → 費用徴収。
- **重要：** 行政代執行法に基づき行われる。

# 行政書士試験 学習メモ（61-90ページ）

## 1. 行政行為の効力：公定力（こうていりょく）（P61-68）
**【意味】** 行政行為にたとえ間違い（瑕疵）があっても、それが「重大かつ明白」で無効といえる場合を除き、取り消されるまでは誰でもその効力を否定できない力。

- **記述対策フレーズ：** 「**重大かつ明白な瑕疵**がない限り、権限のある機関が**取り消さない限り**有効なものとして扱われる。」
- **理由：** 誰でも勝手に「これは無効だ」と言い出すと、社会が混乱（法的安定性の破壊）してしまうため。

## 2. 行政行為の瑕疵：無効と取消し（P69-75）
- **無効：** 最初から全く効力がない。いつでも誰でも主張できる。
- **取消し：** 取り消されるまでは有効。取り消されると「最初からなかったこと（遡及効）」になる。
- **【最判昭36.3.7】（課税処分の瑕疵）**
    - 課税処分のミスが「無効」になるのは、そのミスが外から見ても明らかに「重大かつ明白」な時だけ。

## 3. 理由の提示（P76-82）
**【行政手続法8条・14条】**
- **原則：** 不利益処分などを行う時は、相手に「なぜこの処分をするのか」という**理由を同時に示さなければならない。**
- **重要判例（青色申告取消事件）：** - 理由の提示は、行政庁の判断の慎重さを確保し、相手方が不服申立てをしやすくするために必要。
    - 理由が不十分な場合、その処分は**違法として取り消される。**

## 4. 行政上の強制手段：直接強制と即時強制（P83-90）
- **直接強制：** 義務を果たさない人の身体や財産に直接力を加える。法律の根拠が絶対に必要。
- **即時強制：** 義務を命じる時間がない緊急時に、いきなり実力を行使する（例：火事の時の家屋壊し、感染症の強制入院）。

# 行政書士試験 学習メモ（91-120ページ）

## 1. 行政手続法の目的と適用除外（P91-98）
**【目的】** 行政運営の公正の確保と透明性の向上を図り、国民の権利利益を保護すること。
- **適用除外（重要）：** 国会や裁判所の行為、地方公共団体の「条例」に基づく処分などは、行政手続法が適用されない場合がある（独自のルールがあるため）。

## 2. 申請に対する処分（P99-105）
国民が役所に「許可をください」とお願いした時のルールです。
- **審査基準：** 役所はあらかじめ「どんな条件ならOKか」という基準を定め、公表するよう**努めなければならない（努力義務）**。
- **標準処理期間：** 申請してから結果が出るまでの目安時間を定めるよう**努める**。
- **理由の提示：** 申請を拒否する場合は、必ず理由を**同時に**示さなければならない。

## 3. 不利益処分と「聴聞（ちょうもん）」「弁明（べんめい）」（P106-115）
役所が国民にペナルティを与える（免許取消など）前の、言い分を聞くチャンス。
- **聴聞（重いペナルティ）：** 許可の取消しなど。口頭で意見を言える、厳しい手続き。
- **弁明の機会の付与（軽いペナルティ）：** 業務停止など。原則として「書面」で行う。
- **【最判昭37.11.28】（聴聞の権利）**
    - 相手の言い分を聞く手続きを省いて行った不利益処分は、原則として**違法**となり取り消しの対象になる。

## 4. 行政指導（P116-120）
役所が「こうしてほしい」とお願いすること（強制力はない）。
- **原則：** 相手が従わないからといって、嫌がらせをしたり不当な扱いをしてはいけない。
- **中止等の求め：** 法律違反でもないのにしつこい指導を受けている場合、国民は「もうやめてください」と申し出ることができる。

# 行政書士試験 学習メモ（121-150ページ）

## 1. 行政不服審査法の目的と基本原則（P121-128）
**【目的】** 簡易迅速かつ公正な手続により、国民の権利利益の救済を図ること。
- **審査請求（原則）：** 処分のあったことを知った日の翌日から**3ヶ月以内**に行う。
- **自由選択原則：** 審査請求をするか、いきなり裁判（取消訴訟）をするかは、原則として国民が自由に選べる。

## 2. 審理員（しんりいん）と審査会（P129-136）
不公平を防ぐための「チェック係」の仕組みです。
- **審理員：** 処分に関わっていない職員から選ばれる。審理をリードする。
- **行政不服審査会：** 第三者の有識者グループ。審理員が出した結論が正しいか、最後に客観的な意見（答申）を出す。

## 3. 執行停止（しっこうていし）（P137-143）
文句を言っている間、処分の進行を止めるルール。
- **原則：** 審査請求をしても、処分の効力は**止まらない（執行不停止の原則）**。
- **例外：** 重大な損害を避けるために緊急の必要があるときは、申し立てにより一時的に止められる。

## 4. 裁決（さいけつ）（P144-150）
審査の結果としての最終判断。
- **却下（きゃっか）：** 期限切れなど、手続き上のミスで中身を見ずに門前払いすること。
- **棄却（ききゃく）：** 中身を調べた結果、役所の処分が正しかったと認めること。
- **認容（にんよう）：** 国民の言い分が認められ、処分が取り消されること。
- **【重要：不利益変更禁止の原則】** 審査請求をしたことで、元の処分より重いペナルティに変えられることはない。
