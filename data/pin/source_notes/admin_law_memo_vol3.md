# 行政書士試験 学習メモ（第3巻：1-30ページ）

## 1. 条例と法律の関係：徳島市公安条例事件（P1-8）
**【最大判昭50.9.10】**
- **争点：** 法律と条例が同じことを定めている場合、条例は違反（無効）になるか？
- **結論：** **直ちに違反とはならない。**
- **重要フレーズ（記述対策）：** 「条例が国の法令に違反するかどうかは、両者の対象事項と規定文言を対比するのみでなく、それぞれの**趣旨、目的、内容及び効果を比較**し、両者の間に矛盾抵触があるかどうかによって決すべきである。」

## 2. 公務員の不法行為と個人の責任（P9-16）
公務員が仕事中にミスをして誰かに損害を与えた場合、その公務員個人に責任を問えるか？
- **結論：** **公務員個人は、直接の賠償責任を負わない。**（責任を負うのは国や自治体のみ）
- **【重要判例：最判昭30.4.19】**
    - 公務員に「故意または重大な過失」がある場合、国が賠償した後にその公務員へ**求償（お金を返せと言うこと）**できるが、被害者に対して公務員個人が直接責任を負うことはない。

## 3. 国家賠償法1条：職務執行の「違法性」（P17-25）
**【重要判例：宅建業法上の規制権限の不行使（最判平元.11.24）】**
- **内容：** 役所が規制（取り締まり）をサボったことで被害が出た場合、いつ「違法」と言えるか？
- **記述対策キーワード：** 「許容される限度を逸脱して著しく合理性を欠く」「権限の不行使が著しく不当」

## 4. 判例：水俣病視察と国家賠償（P26-30）
- **争点：** 大臣が現地を視察しなかったことや、規制を遅らせたことは違法か？
- **結論：** 深刻な被害が拡大していることを予見できたのに、何もしなかった場合は**違法**となる。

# 行政書士試験 学習メモ（第3巻：31-60ページ）

## 1. 規制権限の不行使と国家賠償（P31-40）
役所が法律で認められた権限（取り締まりなど）を「あえて使わなかった」ことで被害が出た場合の話です。
- **【重要判例：大東水害訴訟（最判昭56.12.16）】**
    - 河川の改修工事が遅れて水害が起きた場合、当時の技術や予算の状況を考えて、役所が「やるべきことをやっていた」なら違法とは言えない。
- **【重要判例：クロロキン薬害事件（最判平7.6.23）】**
    - 厚生大臣が副作用のある薬の販売を禁止しなかったことについて、当時の医学的知見で危険性が予見できたのに放置した場合は**違法**となる。

## 2. 土地収用と損失補償（P41-48）
公共事業のために私有地を強制的に取得する場合のルールです。
- **収用委員会：** 土地の価格（補償金）などを決める独立した行政委員会。
- **正当な補償の範囲：** - 単に土地の代金だけでなく、そこにあった建物を取り壊す費用や、営業ができなくなる損害（移転料）も含まれる。

## 3. 憲法29条3項と直接請求（P49-55）
- **【重要判例：森林法違憲判決】**
    - 法律に補償の規定がなくても、憲法29条3項を根拠に、直接「お金を払ってください」と国に請求できる場合がある。

## 4. 営造物の設置・管理の瑕疵（P56-60）
**【重要判例：国道13号線落石事故（最判昭45.8.20）】**
- **内容：** 崖崩れの危険がある道路に防護柵がなく、落石で事故が起きた。
- **結論：** 予算が足りなかったという理由は言い訳にならず、**管理の瑕疵（ミス）**が認められる。

# 行政書士試験 学習メモ（第3巻：61-90ページ）

## 1. 税務署長による更正処分と国家賠償（P61-68）
**【最判平5.3.11】**
- **内容：** 税務署長が行った更正処分（税額の訂正）が、後に裁判で取り消された場合、すぐに国家賠償法上の「違法」になるか？
- **結論：** **直ちに違法とはならない。**
- **重要フレーズ（記述対策）：** 「税務署長が、職務上通常尽くすべき注意義務を尽くすことなく、**漫然と更正をしたと認め得るような事情**がある場合に限り、違法となる。」
- **理由：** 役所の判断が少し間違っていただけで毎回賠償させていたら、役所が思い切った仕事ができなくなるため。

## 2. 公立学校での事故と国家賠償（P69-75）
**【最判昭62.2.6：部活動中の事故】**
- **ポイント：** 学校の先生には、生徒が怪我をしないように注意する「安全配慮義務」がある。
- **判断基準：** 事故が起きることを予見できたか（予見可能性）、そして防ぐための行動をとったか（結果回避義務）。

## 3. 地方自治法：住民訴訟と「怠る事実」（P76-82）
住民訴訟は、お金を「使いすぎた」時だけでなく、本来「取るべきお金を取っていない」時も対象になります。
- **不当利得返還請求の怠却：** 役所が間違えて誰かにお金を多く払いすぎたのに、それを「返して」と言わずに放置していること。
- **記述対策キーワード：** 「公金の賦課・徴収を怠る事実」「財産の管理を怠る事実」

## 4. 条例による罰則の委任（P83-90）
- **原則：** 法律の委任があれば、条例で「懲役」や「罰金」などの罰則を定めることができる。
- **【重要判例：最大判昭37.5.30】**
    - 法律が「条例で罰則を決めてもいいよ」と包括的に委任していれば、憲法に違反しない。

# 行政書士試験 学習メモ（第3巻：91-116ページ）

## 1. 行政調査と憲法31条・35条（P91-98）
**【重要判例：川添事件（最判昭48.7.10）】**
- **内容：** 税務調査（強制調査）に「裁判所の令状」がいらないのは憲法違反ではないか？
- **結論：** **憲法違反ではない。**
- **重要フレーズ（記述対策）：** 「行政調査は**刑事責任を問うための手続ではない**ため、憲法35条の令状主義がそのまま適用されるわけではない。」
- **ポイント：** 目的が「正しい課税」のためであり、犯罪捜査ではないから許されるという理屈です。

## 2. 行政手続と憲法31条（P99-105）
**【重要判例：成田新法事件（最大判平4.7.1）】**
- **内容：** 行政手続には、憲法31条（適正手続）の保障が及ぶか？
- **結論：** **及ぶ。**
- **記述対策キーワード：** 「行政手続は刑事手続ではないが、国民に不利益を与える点では共通するため、**憲法31条の保障の枠組みが及ぶ**。」
- **例外：** 緊急性がある場合などは、事前の告知・聴聞を省いても直ちに違憲とはならない。

## 3. 国家賠償法2条：営造物の瑕疵と「供用関連瑕疵」（P106-112）
**【重要判例：大阪国際空港騒音訴訟（最大判昭56.12.16）】**
- **内容：** 空港の騒音被害は「営造物の瑕疵（かし）」にあたるか？
- **結論：** **あたる。**
- **ポイント：** 施設そのものが壊れていなくても、その**使いかた（供用）によって周りに被害を与えている**なら、管理のミス（瑕疵）といえる。

## 4. 総まとめ：行政法の全体構造（P113-116）
- **行政組織法：** 誰がやるか（国、地方公共団体）
- **行政作用法：** どうやるか（行政行為、行政調査、行政手続）
- **行政救済法：** 困った時どうするか（行政不服審査、行政事件訴訟、国家賠償）
