# 行政書士試験 学習メモ（151-173ページ）

## 1. 取消訴訟（とりけしそしょう）の要件（P151-158）
裁判所に訴えを認めてもらうための「ハードル（訴訟要件）」です。
- **処分性：** 役所の行為が、国民の権利義務を具体的に決定するものであること。
- **原告適格：** 訴える資格があること。法律上の利益を持つ人に限られる。
- **出訴期間：** 処分を知った日から**6ヶ月以内**（または処分の日から1年以内）。

## 2. 取消訴訟以外の抗告訴訟（P159-165）
- **無効等確認訴訟：** 処分のミスが「重大かつ明白」なときに、無効であることを確認する。
- **不作為の違法確認訴訟：** 申請したのに、役所が「何もしない（放置）」ことの違法を問う。
- **義務付け訴訟：** 役所に「許可を出せ！」「処分をしろ！」と命令するよう裁判所に求める。
- **差止（さしとめ）訴訟：** 役所が処分をしようとしているのを、事前に「やるな！」と止める。

## 3. 執行停止（しっこうていし）（P166-169）
**【行政事件訴訟法25条】**
- 裁判中であっても、原則として処分の効力は止まらない。
- **重大な損害を避けるため緊急の必要があるとき**は、裁判所は申立てにより執行を止められる。
- ただし、**「公共の福祉に重大な影響を及ぼすおそれ」**があるときはできない。

## 4. 判決の種類（P170-173）
- **却下判決：** 訴訟要件（期間など）を満たしていないため、中身を調べずに門前払い。
- **棄却判決：** 訴えを調べたが、役所の処分は正しかったと認める。
- **認容判決：** 国民の訴えを認め、処分を取り消す。
- **事情判決（重要）：** 処分は違法だが、それを取り消すと社会がパニック（公共の福祉に反する）になる場合、**処分は取り消さずに「違法であることだけ」を宣言する。**
