# 受験生向け知識ベース

混同しやすい論点を、結論と理由のセットで置く場所。`data/knowledge/quiz/` と `learn/` は上書きされるので、手編集はここ（または `canonical/`）だけ。

## 目的

質問するモードで、通常の回答のあとに「〇〇に関しても、学習しますか？」を1件出せるようにする。承諾されたら、このフォルダの該当MDを優先して説明する。

## 登録形式

各ファイルの本文に、少なくとも次を書く。

- 安定したID（ファイル名または冒頭）
- タイトル、科目、検索語・別名
- 学習上の疑問／混同しやすい認識
- 正しいルールと適用範囲
- 具体例
- 判断手順
- 根拠条文／判例／出典URL／確認日
- 関連する問題・カード
- 追加学習の案内文
- 追加学習時の質問文

法令は e-Gov 等の一次資料で確認してから書く。市販教材・模試の問題文・肢・解説は全文転載しない。友人の個人情報は置かない。

## 法令確認の方針

- 条文は条・項を確認する。
- 判例は年月日と判旨の芯だけ。確認できない細部は断定しない。
- 既存カードが条文と矛盾したら、既存カードも直す。
