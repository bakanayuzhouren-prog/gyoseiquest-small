# 基礎法学 第12問 — 次の文章の空欄 [ ア ] 〜 [ エ ] に当てはまる語句の組合せとして、妥当

## 問題文

次の文章の空欄 [ ア ] 〜 [ エ ] に当てはまる語句の組合せとして、妥当なものはどれか。

ヨーロッパ大陸において、伝統的に [ ア ] 制に対して消極的な態度がとられていることは知られるが、これはそこでの裁判観につながると考えられる。それによれば、裁判官の意見が区々に分かれていることを外部に明らかにすることは、裁判所の権威を害するとされる。[ ア ] 制は、その先例としての力を弱めるのみではなく、裁判所全体の威信を減退させると考えられているようである。裁判所内部にいかに意見の分裂があっても、 [ イ ] として力をもつ [ ウ ] のみが一枚岩のように示されることが、裁判への信頼を生むとされるのであろう。しかし、果たして外観上つねに [ エ ] の裁判の形をとり、異なる意見の表明を抑えることが、裁判所の威信を高めることになろうか。英米的な考え方からすると、各裁判官に自らの意見を独自に述べる機会を与える方が、外部からみても裁判官の独立を保障し、司法の威信を増すともいえよう。ここには、大陸的な裁判観と英米的な裁判観のちがいがあるように思われる。

（出典　伊藤正己「裁判官と学者の間」1993年から）

## もっと深掘る（M列）

### 肢ア

【ア】 少数意見
文脈を見ると、「裁判官の意見が区々に（バラバラに）分かれていることを外部に明らかにすること」に対して消極的な態度をとる、とあります。意見が分かれた際の、採用されなかった側の意見を**「少数意見」**と呼びます。

【イ】 判例 ／ 【ウ】 多数意見
文章の後半で「裁判所内部にいかに意見の分裂があっても、[ イ ]として力をもつ[ ウ ]のみが一枚岩のように示される」とあります。
裁判において、最終的に「これがルールです」と示され、後の裁判の先例（モデル）となるのが**「判例」です。そして、その判例としての効力を持つのは、多数の裁判官が賛成した「多数意見」**だけ、ということになります。

【エ】 全員一致
少数意見を隠して、多数意見だけを「裁判所の意思」として発表すると、外から見たときには、あたかも裁判官全員が最初から同じ意見だったかのように見えます。これを**「全員一致」**の形と表現しています。

🏁 結論
ア：少数意見（分かれた意見のうちの少ない方）

イ：判例（裁判の先例としての法的な力）

ウ：多数意見（結論を支えるメインの意見）

エ：全員一致（外見上の見え方）

これらが全て揃っている 選択肢 3 が正解となります。

📝 日本の制度はどうなっている？（重要ポイント）
解説の「ワンポイント・アドバイス」にある通り、日本は少し特殊な形をとっています。

最高裁判所： 各裁判官の意見（少数意見も含む）を裁判書に記載しなければなりません（裁判所法11条）。

なぜ？： 私たちが「最高裁判所裁判官国民審査」で、その裁判官がどんな判断をしたのかを確認し、ふさわしい人物かどうかをチェックする材料にするためです。

豆知識： 下級裁判所（地裁や高裁）では、合議（複数の裁判官で話し合うこと）の内容は秘密とされており、少数意見は公表されません。最高裁だけが特別な「英米法に近いスタイル」をとっていると覚えると整理しやすいですよ！
