# 一般知識・個人情報保護法（肢別93）— 試験用要約

出典: 独学応援 NOTE「個人情報保護法はこの肢別を回せばOK」。**肢の全文は省略**し、○×・条文・改正ポイントのみ。

**足切り**: 一般知識で個情法**3問GET**が最優先。

---

## キーワード総論

| 概念 | 要点 |
|------|------|
| 保護対象 | **生存する個人**（外国人・未成年・従業者・パート可） |
| 公知情報 | 電話帳・官報・新聞等でも**保護対象** |
| 映像 | 防犯カメラ等、**個人識別可能**なら個人情報 |
| 法人情報 | 法人自体は×。**役員等の個人**情報は○ |
| 病院カルテ | 民間病院も**個情法**（改正で**一本化**） |

## 2. 目的・国の責務（1・4・5条）

| 肢 | 結論 | ポイント |
|----|------|----------|
| 高度情報社会・利用拡大が背景 | ○ | 1条 |
| 国・地方の責務明確 | ○ | 4条・5条 |
| 財産的権利利益含まない | × | **財産的も含む**（1条） |
| 有用活用が**最大の目的** | × | **個人の権利利益保護**が主。活用は配慮 |
| 保護目的＋事業者への有用性配慮 | ○ | 1条（出題想定） |

**1条**: デジタル社会・基本理念・個情委設置・**有用性に配慮しつつ個人の権利利益保護**。

## 4. 利用目的の制限・例外（16条・17条・21条）

### 利用目的を超えて取扱ってはならない — 例外4つ（16条但書等）

| 例外 | 内容 |
|------|------|
| ア | 生命・身体・財産保護＋同意困難 |
| イ | **法令に基づく** |
| ウ | 公衆衛生・児童育成＋同意困難 |
| エ | 国・地方・委託者の法令事務協力＋同意で支障 |
| オ（合併で目的超過） | × **適用除外に非該当** |

### 通知・公表（18条3・21条）

| 肢 | 結論 | 条文 |
|----|------|------|
| 取得状況から目的明らか→通知不要 | ○ | 18条3（宅配等） |
| 国・地方協力で通知が支障→不要 | ○ | 18条3 |
| 取得後速やかに通知又は公表 | ○ | 21条1項 |
| 目的変更→通知又は公表 | ○ | 21条3項（**同意不要**） |
| 目的変更の通知は努力義務 | × | **法的義務** |
| 変更は「相当の関連性」必要 | × | 改正で**「相当」削除**（17条2） |
| 変更時に本人同意必要 | × | **通知・公表で足りる** |
| 目的をできる限り特定・変更は関連性の範囲 | ○ | 17条 |

## 5. 努力義務 vs 法的義務

| 項目 | 努力 | 義務 |
|------|------|------|
| 安全管理・従業者監督・委託監督（23条） | | ○ |
| 正確・最新保持（範囲内） | ○ | |
| 不要になったら消去（75条） | ○ | |
| 行政機関・事実合致（60条） | ○ | |

**思考力**: 「努力じゃ済まないよな」→義務／「無理ゲー」→努力。

## 6. 用語・適用範囲（2条・16条・38条）

| 肢 | 結論 | ポイント |
|----|------|----------|
| DB等＝電子のみ | × | **紙も**含む（容易検索可） |
| Google等の一般検索エンジン＝DB等 | × | **体系的構成**＋政令定め |
| 非営利団体は対象外 | × | 営利非営利**無関係** |
| 個人事業者は対象外 | × | **含む** |
| 名前なしでメール・電話のみ流出 | × | **識別可能**なら規制対象 |
| 従業5000人未満は対象外 | × | **改正で規模要件撤廃** |
| 取扱事業者に国・地方含む | × | **16条2項で除外** |
| 独立行政法人＝取扱事業者 | × | **適用除外** |
| 地方公共団体＝取扱事業者 | ○ | 除外なので**該当しない** |
| NPO＝取扱事業者外 | × | 該当しうる |

### 保有個人データ vs 個人データ vs DB等

| 用語 | 定義要点 |
|------|----------|
| 個人情報 | アンケート等の情報 |
| 個人データ | 個人情報DB等の**構成要素** |
| 個人情報DB等 | 電子**又は**紙で容易検索可の集合 |
| **保有個人データ** | 開示・訂正・削除・利用停止等の**権限**を事業者が有する個人データ |

**委託例**: A（給与）がDB保有・訂正権限。B（委託先）は個人データのみで**保有個人データ×**。

### 2社経営者・グループ

| 肢 | 結論 |
|----|------|
| 片方で得た情報を他社利用＝第三者提供に非該当 | × **別法人格→第三者提供** |

| 肢 | 結論 |
|----|------|

| 両罰規定なし | × **あり** |

## 8. 第三者提供（27条・77条）

| 肢 | 結論 |
|----|------|
| 原則同意なく第三者提供禁止 | ○ |
| 合併等の承継提供→受領者は第三者に非該当 | ○（23条オの利用目的超過とは別論点） |

**オプトアウト**: 同意なく提供可の特例。**要配慮個人情報は除外**。

---

## 9. 個人識別符号・要配慮（2条2・2条3）

| 肢 | 結論 | ポイント |
|----|------|----------|
| 個人識別符号＝単体で個人情報・照合容易性不要 | ○ | マイナンバー・免許番号等。**クレカ番号は符号×**（識別**情報**にはなりうる） |
| 要配慮の定義（政令） | ○ | 人種・信条・社会的身分・病歴・犯罪経歴等 |
| 社会的身分＝努力で変えられないもの。人種に肌色含む？ | × 肌色は含まない（出典要旨） |
| 要配慮は同意取得原則＋オプトアウト除外 | ○ |
| 宗教建物訪問・書籍購入＝要配慮 | × **宗教そのもの**が要配慮 |
| 生命保護等でも要配慮は同意なく取得不可 | × **例外あり**（同意困難・法令協力等） |

---

## 10. 匿名加工・仮名加工・個人関連情報（2条7・43条等）

| 種類 | 要点 |
|------|------|
| **匿名加工** | 識別不可＋**復元不可**。個情規定**適用外**（71条） |
| **仮名加工** | 復元可。内部利用想定・規制緩い |
| **個人関連情報** | 個情・仮名・匿名のいずれでもない。氏名と**未結合**（閲覧履歴・位置情報等） |

| 肢 | 結論 |
|----|------|
| 匿名加工の定義 | ○ |
| 復元可能性を**完全排除**まで要求 | × **通常復元不能で足りる** |
| 匿名加工→個情規定適用されない | ○ |
| 第三者提供時・項目・方法**公表**＋匿名である旨**明示** | ○ 43条 |
| WEB閲覧履歴（氏名なし）＝個人データ | × → **個人関連情報** |

## 11. 行政機関（改正一本化後）

**注意**: 行政機関個人情報保護法**廃止**→個情法に統合。旧法のみの肢（45・51等）は**出題対象外**だが、統合後の行政機関規定は要確認。

| 肢 | 結論 | ポイント |
|----|------|----------|
| 外国人の行政機関保有個情は保護外 | × **生存する個人** |
| 地方の保有個情も個情法適用 | ○ 一本化 |
| 死亡者情報 | ○ 原則**対象外** |
| 目的外利用・提供は同意なく禁止 | × **法令・相当理由**で可 |
| 開示で生命等害するおそれ | × → **不開示** |
| 法人等の権利・競争地位害するおそれ | × → **不開示** |
| 国の安全・国際関係等 | ○ **不開示** |
| 他者権利害するが法令上知り得る情報 | ○ **開示** |
| 評価・判断の不当を理由に訂正請求 | × **事実の訂正** |
| 職員個人にも義務・罰則 | ○ |
| 訂正請求を口頭で | × **書面**（保有個人情報訂正請求書） |
| 開示請求を口頭で | × **書面** |
| 行政機関訂正は原則**開示請求先行** | ○ |
| 民間事業者への訂正も開示先行 | × **直接訂正可** |

## 試験直前メモ

- **1条目的**は選択肢1つとして高確率 → 六法で目通し
- **16条2項適用除外**（国・地方・独法）は超頻出
- **保有個人データ**と委託（A/B会社）の理解問題に注意
- **改正**: 一本化・5000人撤廃・大学除外削除・17条2「相当」削除
- 個人識別**符号** vs **情報**、匿名 vs 仮名 vs 個人関連情報の4分類
