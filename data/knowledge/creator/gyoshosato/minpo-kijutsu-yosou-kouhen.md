出典: 行政書士独学応援 NOTE「記述予想 民法 後編」。**事案の長文は省略**し、条文・要件・結論のみ。

## 31. 根抵当権（398条2・398条22）

| 条文 | ポイント |
|------|----------|
| 398条2 | 不特定債権を**極度額**の範囲で担保 |
| 398条22 | 元本確定後、現存債務が極度額超 → **極度額の支払**（又は供託）で根抵当権消滅 |

**物上根保証人X**: 極度額1億設定・確定後1.3億 → **1億支払**で土地取られずに済む（超過分の債務不履行責任は債務者Bに残る）。

地上権・対抗可能賃借権を目的とする根抵当も論点同型。受領拒否時は**供託**も選択肢。

## 33. 保佐人と取消権（120・13・126条）

| ケース | 取消 |
|--------|------|
| 被保佐人Aが不動産売買（13条同意要行為） | **可** |
| 被保佐人Aが自転車購入（日常行為） | **不可** |

**120条**: 取消できるのは制限行為能力者・代理人・承継人・同意権者に限る。

**126条**: 追認できる時から**5年**／行為の時から**20年**で消滅。

## 34. 占有回収・盗品回復（200・198・199・192・193・194・196条）

### 占有回収の訴え（200条）

| 要件 | 内容 |
|------|------|
| 期間 | 占有侵奪から**1年以内** |
| 請求 | 物の返還＋損害賠償 |
| 200条2項 | **特定承継人**には原則不可。ただし承継人が**侵奪の事実を知っていた**ときは可 |

### 占有保持（198条）・占有保全（199条）

| 訴え | 要件・請求 |
|------|------------|
| 198条 | 占有**妨害** → 停止＋損害賠償 |
| 199条 | 占有妨害の**おそれ** → 予防又は損害賠償の担保 |

### 盗品回復（193条）vs 即時取得（192条）

絵画盗難→C転売→Cが**善意無過失で即時取得** → Aは所有者・占有回収とも不可。

| 条文 | ポイント |
|------|----------|
| 193条 | 盗難又は遺失の時から**2年**、占有者に回復請求 |
| 194条 | **無償回復可**: 競売・公の市場・同種物販売商人から善意取得。それ以外は**対価弁償** |
| 196条 | 原則**保存必要費用**償還。占有者が**果実**取得時は無償可 |

**判断**: 占有回収か盗品回復かを問題文から切り分ける。

## 35. 寄託契約（661条）

寄託物の性質・瑕疵で受寄者に損害 → 寄託者の賠償責任。

**免責**: 寄託者が**過失なく**性質・瑕疵を知らず、又は**受寄者が知っていた**とき。

## 36. 債権者代位権の転用（大判昭4.12.16）

B（賃借人）が甲土地を占有前にCが占拠 → Bは占有回収不可。

賃借権の対抗要件なし → 賃借権に基づく妨害排除も不可。

**解答骨子**: BはA（所有者）の**所有権に基づく妨害排除請求権**を**代位行使**。

## 37. 契約不適合責任（562〜566・541・542条）

### 通知期限

| 種類 | 期限 |
|------|------|
| 種類・品質（566条） | 不適合を**知った時**から**1年以内** |
| その他 | 166条（知った時5年／行使可能10年） |

**566条但書**: 通知なくても請求可 — ①売主が引渡時に**知っていた** ②**重過失**で不知。

### 請求の順序

1. **追完**（562条: 修補・代替・不足補充）
2. **代金減額**（563条: 原則追完先行）
3. **解除**（564条）— 541条催告解除／542条催告不要
4. **損害賠償**（売主の帰責事由を問題文で判断）

## 38. 協議を行う旨の合意（151条）

時効完成間近・訴訟・催告で関係悪化を避けたい → **協議を行う旨の合意を書面**。

| ポイント | 内容 |
|----------|------|
| 猶予 | 原則**1年**（短い定め期間があれば**早い方**） |
| 決裂後 | 拒否通知から**6か月**は完成猶予 |
| 延長 | **5年以内**に延長合意を繰り返し可 |

## 39. 抵当権の妨害排除請求（最判平17.3.10）

Bが家賃を超低額・敷金高額設定で**物上代位を困難**に → 抵当権者AはCに**抵当権に基づく妨害排除請求**可。

**明渡請求**（判例）: 所有者Bが抵当権侵害を防ぐ**適切な維持管理が期待できない**とき。

## 40. 連帯債務と相殺（439条・改正）

A・B・CがDに300万連帯債務（各100万負担）。CがDに300万反対債権。DがAに300万請求。

**Aの抗辩**: Cの負担部分**100万円を限度**に履行拒否可（439条）。

## 41. 追認（横断整理・記述の心構え）

詐欺・制限行為能力・無権代理で共通する**追認**論点。記述は予想暗記より**択一の横断理解**が本質。

| 分野 | 追認の効果 |
|------|------------|
| 無権代理 | 追認で有効（113条） |
| 制限能力 | 追認で不可取消（122条） |
| 詐欺・強迫 | 追認で取消不可 |

126条時効（5年／20年）も各分野で共通確認。

## 44. 使用者責任・工作物・動物（715・717・718条）

### 715条 使用者責任

| 免責 | 内容 |
|------|------|
| 715条主文 | 選任・監督に相当注意／相当注意でも損害生ずべき |

**求償**: A→Bへ**信義則上相当**な範囲（公平分担）。

**国・公共団体**: 715条型免責なし。公務員に故意過失→国等が賠償。求償は公務員の**故意・重過失**。

### 717条 工作物責任

占有者Bが必要注意 → 免責。**717条3**: 二次的に**所有者A**が責任。A・B→請負Zへ求償可。

### 718条 動物占有者

**相当注意**で管理 → 免責。

## 45. 消滅時効・承認と保証人（457条・改正）

**完成前と完成後は別世界。**

### 時効完成前

| 事由 | 効果 |
|------|------|
| 主債務者Bが承認 | 時効更新 → **保証人Cにも及ぶ**（457条） |
| 保証人Cが承認 | 主債務は**更新されない** |

### 時効完成後

| 事由 | 効果 |
|------|------|
| Bが承認（利益放棄） | Bは援用不可。Cは**主債務の時効援用可**（相対効）→ 付従で保証も消滅 |
| Cが保証債務承認 | Bが主債務時効援用 → 不随でCの保証消滅 |

**信義則**: 主債務完成後B承認→Cも保証承認→その後Cが主債務時効援用は**不可**（最判昭43.9.26系）。

## 46. 混同と地上権（179条1項但書）

Bが地上権者かつ後に甲土地を取得 → 混同消滅しそうだが、地上権が**C銀行抵当権の目的** → **消滅しない**（179条1項但書: 第三者権利の目的であるとき）。

## 47. 賃貸借と転貸借の終了

A賃貸人 — B賃借人 — C転借人（B承諾転貸）

| 終了原因 | Cの対抗 |
|----------|---------|
| A-B **合意解除** | 転貸借でAに**対抗可** |
| A-B **法定解除**（債務不履行等） | 転借権で**対抗不可** |

**例**: B家賃滞納→A解除 → AがCに返還請求 → **Bの債務不履行**としてB-C転貸借終了 → C退場。

## 48. 指図による占有移転と即時取得（184・192条）

BがAの自転車を占有。CがBから購入するが実物はD（寄託先）にあり。

**192条即時取得**: 占有が要件。判例 — **指図による占有移転も占有に該当**。

**184条要件**: BがDに「以後**Cのために**占有せよ」と命じ、**Cが承諾**。

→ Cが指図占有移転により占有要件充足 → **即時取得**で所有者。

**暗記骨子**: 以後○○のために占有せよ＋第三者承諾 → 指図占有移転 → 即時取得。
