# ヤマあて R6 vs R7 — 差分論点

同一番号でも**記述が異なる**項目。本試験直前の取り違え防止用。

---

## 行政法

| No | R6 | R7 |
|----|----|-----|
| 3 国賠被告 | 指定確認検査機関の取消訴訟被告＝**都道府県・指定都市** | 建築確認の国賠被告＝**委託元都道府県・指定都市**（指定機関ではない） |
| 4 指定機関 | 誤確認→建築主は指定機関を被告に**国賠可** | 安全認定も可。取消訴訟内で**安全認定の違法性主張可** |
| 8 感染症・逃亡 | 知事が自治法で**秩序罰50万可** | **不可**。非訟事件手続法で**裁判所のみ**秩序罰 |
| 9 代執行手続 | 期限→**代執行令書**通知→戒告 | 期限→**戒告**→代執行令書（通知順序の記述差に注意） |
| 10 代執行 | 森林中止×／工作物撤去○ | 同趣旨（条文引用の有無で表現差） |
| 20 事実行為 | **処分庁の上級**に審査請求のもの | **処分庁**に審査請求のもの（誰が審査庁か） |
| 22 再調査 | 再調査でも**口頭意見**可（処分庁へ申立） | 審査請求と同様**審理員**へ口頭意見（R7は審査請求側の記述） |
| 23 再審査 | 原裁決違法でも**原処分OKなら棄却** | 原裁決違法でも**原処分OKなら棄却可**（同結論・表現差） |
| 25 収用 | 所有権確認＝**無効確認の訴え** | 所有権確認＝**争点訴訟** |
| 32 取消訴訟管轄 | （記載なし／通常地方裁判所） | 原告普通裁判籍所在地の**高等裁判所**にも提起可 |
| 37 行訴法執行停止 | 裁量のみ | **義務的執行停止は行訴法になし**（不服審25条4のみ義務的） |

## 憲法・その他

| 論点 | メモ |
|------|------|
| 建築基準法65条 | R6「優先適用**ならない**」／R7「優先適用**される**」→ **R7が試験想定**（記述・択一で要確認） |
| 撤回 | 両年度「監督行政庁も撤回可」記述あり→**通説と異なる**可能性。六法・講義正解表で要確認 |
