## 基礎法学

### 問1 基礎法学：その他／その他の、科する／課する、直ちに

- 出題の狙い: 例示包含は「その他の」。制裁は「科する」。救助義務は「直ちに」。
- 判断ルール: 「その他」は並列、「その他の」は前掲が後続の例示であるときに用いる。制裁・刑罰には「科する」、義務や税の賦課には「課する」。時期は、直ちに（猶予なし）・速やかに・遅滞なく（正当理由があれば遅れ得る）の順で緩む。道路交通法72条1項の救護は直ちに。
- ひっかけ: その他とその他のを逆にする。科すると課するを混ぜる。直ちに＝遅滞なく。
- 暗記: 例示包含＝その他の。制裁＝科する。救護＝直ちに。
- 根拠: 行政事件訴訟法3条3項 / 地方自治法15条2項 / 道路交通法72条1項

#### もっと深掘る

■ 結論

例示包含は「その他の」。制裁は「科する」。救護は「直ちに」。

■ ひっかけ

[[red:その他＝包含、科する＝税、直ちに＝遅滞なく。]]

■ 暗記

その他の＝例示。科する＝制裁。直ちに＝猶予なし。

#### 新作問題

法令用語について妥当なものはどれか。

1. 前掲が後続の例示であるときは「その他の」を用い、制裁には「科する」を用い、救護のように猶予を許さないときは「直ちに」を用いる。
2. 「その他」は常に例示包含を意味する。
3. 過料を定めるときは「課する」が正しい。
4. 「遅滞なく」は、正当な理由があっても遅れることができない。

正解: 1

その他の＝例示包含。科する＝制裁。直ちに＝猶予なし。

### 問2 基礎法学：裁判員制度

- 出題の狙い: 第一審のみ。行政書士は欠格でない。事実認定・法令適用・量刑。評決は裁判官と裁判員の双方を含む多数。
- 判断ルール: 裁判員制度は平成21年実施。対象は一定の重大な刑事事件の第一審であり、控訴審には及ばない。裁判員は衆議院議員の選挙権を有する者から選ばれ、行政書士であることは欠格事由ではない。合議体は事実認定のほか法令の適用及び量刑も行う。評決は、裁判官及び裁判員の双方の意見を含む合議体の員の過半数による。
- ひっかけ: 控訴審も対象、行政書士は欠格、量刑は裁判官だけ、全員一致。
- 暗記: 第一審だけ。行政書士もなれる。法令適用・量刑も。双方を含む過半数。
- 根拠: 裁判員の参加する刑事裁判に関する法律6条1項 / 同13条 / 同15条 / 同67条1項

#### もっと深掘る

■ 結論

第一審のみ。行政書士は欠格でない。事実認定・法令適用・量刑。評決は裁判官と裁判員の双方を含む過半数。

■ ひっかけ

[[red:控訴審も対象、行政書士は欠格、量刑は裁判官だけ。]]

■ 暗記

第一審。欠格に行政書士なし。双方を含む過半数。

#### 新作問題

裁判員制度について妥当なものはどれか。

1. 対象は一定の重大な刑事事件の第一審であり、控訴審には及ばない。行政書士であることは欠格事由ではない。
2. 控訴審でも裁判員が参加する。
3. 行政書士は裁判員になることができない。

## 行政法総論

### 問9 行政法総論：許可は命令的行為・裁量は狭い／特許は形成的行為・裁量は広い

- 出題の狙い: 自然の自由の回復か、新しい権利の付与かで切る。
- 判断ルール: 許可は、本来自由な活動を法令で制限したうえで、その制限を個別に解除する命令的行為であり、裁量は狭い。特許は、私人に本来ない権利又は法的地位を新たに付与する形成的行為であり、裁量は広い。
- ひっかけ: 許可＝形成的、特許＝命令的、許可の裁量は広い。
- 暗記: 許可＝命令的・裁量狭い。特許＝形成的・裁量広い。
- 根拠: 行政法総論・行政行為の分類

#### もっと深掘る

■ 結論

許可は命令的行為で裁量は狭い。特許は形成的行為で裁量は広い。

■ ひっかけ

[[red:許可＝形成的、特許＝命令的、許可の裁量は広い。]]

■ 暗記

許可＝狭い命令的。特許＝広い形成的。

#### 新作問題

許可と特許の学理上の分類について妥当なものはどれか。

1. 許可は命令的行為で裁量は狭く、特許は形成的行為で裁量は広い。
2. 許可は形成的行為で裁量は広い。
3. 特許は命令的行為で裁量は狭い。
4. 許可と特許は、いずれも形成的行為である。

正解: 1

許可＝制限の解除。特許＝新たな権利付与。

### 問26 行政法総論：人事院規則と給与報告・懲戒

- 出題の狙い: 人事院規則は制定改廃できる。給与は国会及び内閣へ同時報告。懲戒は任命権者。勤務条件の根本基準の変更は国会。
- 判断ルール: 人事院は、法律を実施するため、又は法律の委任に基づき、人事院規則を制定し、いつでも改廃できる。給与表が適当であるかどうかは、少なくとも毎年一回、同時に国会及び内閣に報告する。懲戒処分は任命権者が行う。勤務条件の根本基準を社会一般の情勢に適応させる変更は国会が行う。
- ひっかけ: 給与報告は内閣だけ、懲戒は人事院が行う、根本基準の変更は人事院だけ。
- 暗記: 人事院規則は改廃可。給与は国会と内閣へ同時。懲戒は任命権者。
- 根拠: 国家公務員法16条1項 / 同18条の2 / 同28条 / 同84条

#### もっと深掘る

■ 結論

人事院規則は制定改廃できる。給与は国会及び内閣へ同時報告。懲戒は任命権者。根本基準の変更は国会。

■ ひっかけ

[[red:報告は内閣だけ、懲戒は人事院、根本基準は人事院が変える。]]

■ 暗記

規則は改廃可。報告は国会＋内閣。懲戒＝任命権者。

#### 新作問題

人事院について妥当なものはどれか。

1. 人事院は、法律を実施するため又は法律の委任に基づき人事院規則を定め、いつでも改廃することができる。
2. 給与表が適当かどうかの報告は、内閣に対してのみ行う。
3. 懲戒処分は、人事院が行う。
4. 勤務条件の根本基準の変更は、人事院が単独で行う。

正解: 1

16条1項。報告は28条2項で国会及び内閣。懲戒は84条で任命権者。

## 行政手続法

### 問12 行政手続法：弁明の機会の付与と資料閲覧

- 出題の狙い: 弁明は原則弁明書。証拠提出可。書面通知。代理人可。資料閲覧は聴聞だけ。
- 判断ルール: 弁明は、行政庁が口頭を認めたときを除き弁明書の提出による。証拠書類等を提出できる。行政庁は提出期限までに相当な期間をおいて、所定事項を書面で通知する。弁明の通知を受けた者も代理人を選任できる。聴聞の当事者等は原因事実を証する資料の閲覧を求め得るが、弁明では18条1項前段は準用されず、閲覧を求めることができない。
- ひっかけ: 弁明でも資料閲覧できる、弁明は常に口頭、代理人は聴聞だけ。
- 暗記: 弁明＝弁明書・証拠可・書面通知・代理人可。閲覧は聴聞だけ。
- 根拠: 行政手続法29条 / 行政手続法30条 / 行政手続法31条 / 行政手続法16条 / 行政手続法18条

#### もっと深掘る

■ ひっかけ

[[red:弁明でも閲覧可、弁明は常に口頭。]]

■ 暗記

## 行政不服審査法

### 問14 行政不服審査法：総代は取下げできない／代理人は特別委任で取下げ可

- 出題の狙い: 総代と代理人の取下げ権限を混ぜない。
- 判断ルール: 代表者又は管理人の定めがある法人でない社団・財団は、その名で審査請求できる。総代は取下げを除き一切の行為ができるが、特別の委任があっても取下げはできない。審査請求の代理人は特別の委任を受けたときに限り取下げできる。参加人の代理人も、参加の取下げは特別の委任を要する。処分に係る権利の譲受人は、審査庁の許可を得て審査請求人の地位を承継できる。
- ひっかけ: 総代も特別委任で取下げ可、譲受人は審理員の許可。
- 暗記: 総代＝取下げ不可。代理人＝特別委任で取下げ可。承継＝審査庁の許可。
- 根拠: 行政不服審査法10条 / 行政不服審査法11条3項 / 行政不服審査法12条2項 / 行政不服審査法13条4項 / 行政不服審査法15条6項

#### もっと深掘る

■ 結論

総代は取下げできない。代理人は特別委任があれば取下げできる。地位承継は審査庁の許可。

■ ひっかけ

[[red:総代も特別委任で取下げ、承継は審理員の許可。]]

■ 暗記

総代×取下げ。代理人○特別委任。

#### 新作問題

審査請求の審理関係人について誤っているものはどれか。

1. 総代は、特別の委任を受けた場合に限り、審査請求を取り下げることができる。
2. 法人でない社団で代表者の定めがあるものは、その名で審査請求できる。
3. 審査請求の代理人は、特別の委任を受けたときに限り取下げできる。
4. 権利の譲受人は、審査庁の許可を得て審査請求人の地位を承継できる。

正解: 1

11条3項。総代は特別委任でも取下げ不可。代理人は12条2項で特別委任があれば可。

### 問15 行政不服審査法：審査庁が上級でも処分庁でもないときは変更できない

- 出題の狙い: 取消しはできるが変更はできない場合がある。
- 判断ルール: 審査請求は裁決があるまでいつでも取り下げられ、審理開始後も審査庁の同意は不要。諮問先は行政不服審査会等であり、情報公開・個人情報保護審査会ではない。処分についての審査請求に理由があるときは、裁決で処分の全部又は一部を取り消し、又は変更する。ただし審査庁が処分庁の上級行政庁でも処分庁でもないときは、変更できない。事情裁決は、違法又は不当でも公益上著しい障害があるときは棄却できる。申請に基づく処分が手続違法で取り消されても、処分庁は申請を認容する義務まではない。
- ひっかけ: 取下げに同意要、諮問先を情報公開審査会、上級でも処分庁でもない審査庁も変更可。
- 暗記: 上級でも処分庁でもない審査庁は変更不可。取下げに同意不要。
- 根拠: 行政不服審査法27条1項 / 行政不服審査法43条1項 / 行政不服審査法46条1項 / 行政不服審査法45条3項 / 行政不服審査法52条2項

#### もっと深掘る

■ 結論

理由があるときは取消し又は変更。上級でも処分庁でもない審査庁は変更できない。取下げに同意不要。

■ ひっかけ

[[red:取下げに同意要、諮問＝情報公開審査会、誰でも変更可。]]

■ 暗記

変更は上級又は処分庁だけ。

#### 新作問題

審査請求の終了について正しいものはどれか。

1. 処分についての審査請求に理由があるときでも、審査庁が処分庁の上級行政庁でも処分庁でもないときは、裁決で当該処分を変更することはできない。
2. 審理開始後の取下げには、審査庁の同意が必要である。
3. 審理員意見書の提出を受けたときは、情報公開・個人情報保護審査会に諮問しなければならない。
4. 申請に基づく処分が手続違法で取り消されたときは、処分庁は申請を認容する処分をしなければならない。

正解: 1

46条1項ただし書。取下げは27条で同意不要。諮問先は行服審査会等。

## 行政事件訴訟法

### 問19 行政事件訴訟法：第三者効は取消判決だけ

- 出題の狙い: 32条1項は無効確認・不作為違法確認・義務付け・差止めに準用されない。

- ひっかけ: 無効確認も第三者効、義務付けも第三者効。
- 暗記: 第三者効＝取消判決だけ。他類型は準用なし。
- 根拠: 行政事件訴訟法32条1項 / 行政事件訴訟法38条

■ 結論

第三者効があるのは取消判決だけ。無効確認・不作為違法確認・義務付け・差止めには及ばない。

■ ひっかけ

[[red:無効確認も第三者効、義務付けも第三者効。]]

■ 暗記

32条1項は他類型に準用されない。

#### 新作問題

判決の第三者効について正しいものはどれか。

1. 処分又は裁決を取り消す判決は、第三者に対しても効力を生ずる。
2. 無効確認判決も第三者に対して効力を生ずる。
3. 不作為の違法確認判決も第三者に対して効力を生ずる。

### 問18 行政事件訴訟法：形式的当事者訴訟と実質的当事者訴訟

- 出題の狙い: 法令が当事者間の訴訟形式を定めた増額訴訟か、公法上の法律関係の確認か。
- 判断ルール: 個別法に損失補償規定がないときの憲法29条3項に基づく補償請求は実質的当事者訴訟。土地収用法上、起業者を被告とする補償額の増額訴訟は形式的当事者訴訟。収用裁決の無効を前提とする所有権確認は争点訴訟。薬事法上の通信販売できる権利の確認は実質的当事者訴訟。著作権法に基づく補償金額の増額訴訟は形式的当事者訴訟。
- ひっかけ: 29条3項直請求＝形式的、収用の増額＝実質的。
- 暗記: 形式的＝法令が定めた当事者間の額の争い。29条3項直請求は実質的。
- 根拠: 行政事件訴訟法4条 / 土地収用法 / 著作権法

#### もっと深掘る

■ 結論

収用・著作権の補償額増額は形式的当事者訴訟。憲法29条3項直請求や権利確認は実質的。裁決無効前提の所有権確認は争点訴訟。

■ ひっかけ

[[red:29条3項直請求＝形式的、収用の増額＝実質的。]]

■ 暗記

額の増減で当事者同士＝形式的。

#### 新作問題

形式的当事者訴訟に当たるものはどれか。

1. 土地収用法に基づき、起業者を被告として収用裁決で示された損失補償額の増額を求める訴え。
2. 個別法に補償規定がないときの憲法29条3項に基づく損失補償請求。
3. 収用裁決の無効を前提とする土地所有権確認の訴え。
4. 医薬品を店舗外の者に販売できる権利の確認の訴え。

正解: 1

収用の増額と著作権補償の増額は形式的。29条3項直請求は実質的。

### 問25 行政事件訴訟法：国歌起立命令と確認の利益

- 出題の狙い: 思想良心は原則合憲。通達・職務命令は処分でない。義務不存在確認は差止めとの補充性を欠く。不利益取扱い予防の公法上の確認には確認の利益があり得る。差止めの重大な損害は執行停止で足りれば否定。
- 判断ルール: 国歌斉唱時の起立斉唱を命ずる職務命令は、思想・良心の自由を侵害しない。教委の通達や校長の職務命令は、教員の権利義務を直接変動させず抗告訴訟の対象たる処分ではない。職務命令に基づく公的義務の不存在確認は、懲戒の差止めに対する補充性を欠き不適法とされた。懲戒以外の不利益取扱いを防ぐ公法上の法律関係確認には、確認の利益が認められ得る。差止めの重大な損害は、取消訴訟と執行停止で容易に救済できるときは認められない。
