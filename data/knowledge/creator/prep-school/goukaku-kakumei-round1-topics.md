## 基礎法学

### 問1 基礎法学：法の効力と刑法の適用範囲

- 出題の狙い: 国外で起きた犯罪にも、日本の刑法が及ぶ場合があることを知る。
- 判断ルール: 日本の刑法は、日本国内の犯罪に適用するのが原則です。ただし、日本人の国外犯など、国外で起きた犯罪にも及ぶ例外があります。「外国人の国外犯罪には一切及ばない」は誤りです。
- ひっかけ: 国外だから絶対に適用されない、と決めつける。
- 暗記: 刑法は国内犯が原則だが、国外犯にも例外がある。「国外だから一切及ばない」は誤り。
- 根拠: 刑法1条 / 刑法2条以下 / 刑法6条

#### もっと深掘る

法の効力は「いつ・誰に・どこで」効くかを分けて考えます。刑法の場所的適用は属地主義が原則でも、国民の国外犯など例外規定があります。試験では「一切及ばない」という言い切りがひっかけになります。

#### 新作問題

刑法の適用範囲について妥当なものはどれか。

1. 外国人の国外犯罪には、日本刑法が一切適用されない。
2. 属地主義を原則としつつ、国外犯にも一定の適用があり得る。
3. 刑が軽くなっても遡及適用は常に許されない。
4. 特別法より一般法が常に優先する。

正解: 2

国外犯にも例外規定がある。「一切適用されない」は誤り。

### 問2 基礎法学：裁判外の紛争解決（ADR）の種類

- 出題の狙い: 仲裁・あっせん・和解・調停の違いを言葉で説明できる。
- 判断ルール: 仲裁は第三者が判断して解決する手続。あっせんは第三者が間に入って話をまとめる手続。和解は当事者同士が譲歩して合意する手続。調停は委員会などが仲介して処理する手続です。
- ひっかけ: 仲裁と調停、あっせんと和解の意味を入れ替える。
- 暗記: 仲裁は第三者が決める。あっせんは仲介。和解は当事者の譲歩。調停は委員会などが仲介する。
- 根拠: ADR法 / 民事調停法

#### もっと深掘る

裁判以外で争いを収める方法をまとめてADRと呼びます。試験では定義の入れ替えが定番なので、各語を「誰がどう解決するか」で覚えます。

#### 新作問題

第三者が判断して紛争を解決する手続はどれか。

1. あっせん
2. 仲裁
3. 和解
4. 調停

正解: 2

仲裁は第三者の判断によって紛争を解決する。

## 憲法

### 問3 憲法：外国人の在留期間更新と法務大臣の裁量

- 出題の狙い: 在留更新の不許可がいつ違法になるかを知る。
- 判断ルール: 外国人に入国の自由は保障されていません。在留期間の更新を認めるかは法務大臣の広い裁量です。事実の基礎を全く欠く場合や、社会通念上著しく妥当性を欠く場合に、裁量の逸脱・濫用として違法になります。
- ひっかけ: 外国人には在留の権利がある、上陸拒否事由がなければ不許可はできない、と読む。
- 暗記: 在留更新の許否は法務大臣の広い裁量。全く事実の基礎を欠くか、著しく妥当性を欠くときに違法になる。
- 根拠: 最大判昭和53年10月4日 / 出入国管理及び難民認定法

#### もっと深掘る

マクリーン判決の整理です。人権保障は在留制度の枠内で考え、更新不許可の審査は裁量逸脱・濫用の有無に絞ります。

#### 新作問題

在留期間更新不許可の違法性判断として妥当なものはどれか。

1. 外国人には入国の自由が保障される。
2. 上陸拒否事由に準ずる事由がなければ不許可は許されない。
3. 全く事実の基礎を欠くか著しく妥当性を欠く場合に裁量逸脱となり得る。
4. 更新事由の判断は法務大臣の裁量ではない。

正解: 3

広範な裁量を前提に、著しい妥当性欠如等で違法となる。

### 問4 憲法：表現の自由・報道・取材の保障の違い

- 出題の狙い: 憲法21条で直接保障されるものと、精神に照らして尊重されるものを分ける。
- 判断ルール: 事実の報道の自由は憲法21条で保障されます。取材の自由や図書等の閲読の自由は、21条の精神に照らして十分尊重に値するとされます。私人間の反論文掲載請求権が21条で当然に保障されるわけではありません。
- ひっかけ: 取材・閲読も21条の直接保障、反論権も憲法上当然、と広げる。
- 暗記: 報道の自由は憲法21条で保障。取材や閲読は「精神に照らして尊重」。私人間の反論権は当然には保障されない。
- 根拠: 憲法21条 / 博多駅事件 / レペタ事件

#### もっと深掘る

表現の周辺領域は「直接保障か／精神に照らして尊重か」の二段で整理します。

#### 新作問題

表現の自由の判例整理として妥当なものはどれか。

1. 取材の自由は憲法21条により直接保障される。
2. 報道の自由は憲法21条により保障される。
3. 私人間の反論文掲載請求権は常に21条で保障される。
4. 閲読の自由は憲法上まったく保護されない。

正解: 2

報道の自由は21条保障。取材・閲読は精神に照らし尊重、が基本整理。

### 問5 憲法：国会議員は全国民の代表（自由委任）

- 出題の狙い: 比例代表でも、議員は政党のロボットではないという原則を押さえる。
- 判断ルール: 憲法は国会議員を「全国民の代表」と定めます。政党の指示どおりに動け、という命令委任ではなく、自分の判断で行動する自由委任が原則とされます。
- ひっかけ: 比例代表だから常に政党の命令に従うべき、と一択にする。
- 暗記: 国会議員は全国民の代表。政党の言いなりになる命令委任ではなく、自由委任が原則。
- 根拠: 憲法43条 / 公職選挙法

#### もっと深掘る

比例代表の党籍変更問題では、「政党への投票」と「全国民の代表・自由委任」の緊張関係が問われます。

#### 新作問題

国会議員の地位の説明として妥当なものはどれか。

1. 憲法は国会議員を政党の代表と規定する。
2. 憲法は国会議員を全国民の代表と規定する。
3. 自由委任の原則は比例代表には及ばない。
4. 党籍変更があれば常に議席を失う。

正解: 2

憲法43条は全国民の代表と規定する。

### 問6 憲法：租税法律主義

- 出題の狙い: 税金のルールは法律で決める、という原則を知る。
- 判断ルール: 租税を課すには、課税の要件などを法律で定める必要があります（租税法律主義）。すでにできた信頼を後から法律で変える場合は、権利の性質・変更の程度・公益などを総合して合憲性を判断します。
- ひっかけ: 遡及的変更は常に違憲、または常に合憲、と極端に切る。
- 暗記: 税金の課し方は法律で決める（租税法律主義）。後からルールを変えるときは、信頼保護と公益を総合衡量する。
- 根拠: 憲法84条 / 憲法30条

#### もっと深掘る

憲法84条の基本です。「法律で明確に」が第一関門で、途中変更・遡及は衡量の問題になります。

#### 新作問題

租税法律主義の説明として妥当なものはどれか。

1. 課税要件は政令だけで足りる。
2. 課税要件等は法律で定める必要がある。
3. 遡及的変更は常に違憲である。
4. 租税法律主義は地方税には及ばない。

正解: 2

課税要件の定めは法律によるのが租税法律主義の核心。

### 問7 憲法：憲法に明文があるか数える問題

- 出題の狙い: 望ましい制度でも、憲法本文に書いていなければ「明文あり」と数えない。
- 判断ルール: 「憲法に規定されているものはいくつあるか」型では、政策として正しくても憲法の条文にない事項は数えません。条文の文言の有無で数えます。
- ひっかけ: 望ましい制度だから憲法に必ず明文がある、と読む。
- 暗記: 「いくつあるか」は憲法の条文に書いてあるかで数える。望ましい内容でも明文がなければ数えない。
- 根拠: 憲法各条

#### もっと深掘る

各肢を憲法の目次に照合する作業です。法律や判例にあっても、憲法本文になければ明文ではありません。

#### 新作問題

憲法の明文規定の数え方として妥当なものはどれか。

1. 政策的に正しい内容はすべて明文がある。
2. 条文の文言の有無を基準に数える。
3. 法律にあれば憲法明文と同じに数える。
4. 判例があれば明文と同じに数える。

正解: 2

明文の有無は憲法の文言で数える。

### 問49 憲法：租税法律主義と課税ルールの変更

- 出題の狙い: 課税の中身は法律で明確に定め、後からの変更は衡量で見る。
- 判断ルール: 課税要件や賦課徴収の手続は、法律で明確に定める必要があります。すでにできた信頼を後から変える場合は、権利の性質・変更の程度・公益を総合衡量します。
- ひっかけ: 変更は常に合憲、または常に違憲、と一刀両断する。
- 暗記: 課税の要件は法律で明確に定める。後から変えるときは、信頼保護と公益を総合衡量する。
- 根拠: 憲法84条

#### もっと深掘る

問6の財政とセットで、84条を答案化します。

#### 新作問題

租税法律主義について妥当なものはどれか。

1. 課税要件は告示だけで足りる。
2. 課税要件等は法律で明確に定める必要がある。
3. 事後変更は常に違憲である。
4. 地方税には租税法律主義は及ばない。

正解: 2

課税要件の明確な法定が租税法律主義の中核。

## 行政法総論

### 問8 行政組織法：権限の委任・法定代理・授権代理・専決代決

- 出題の狙い: 法律の根拠の要否と、誰の名で外に出るかを切り分ける。
- 判断ルール: 委任と法定代理は法律の根拠が要る。授権代理・専決・代決は法律の根拠が不要。委任は権限が移り受任機関が自己の名で行使する。法定代理は代理機関が自己の名で行使し、行政庁があらかじめ代理機関を指定できる。授権代理は本人の名。専決・代決は内部決裁で対外的には行政庁の名。上級は特別の根拠なく下級の権限を代行できないが、委任後も指揮監督は残る。
- ひっかけ: 代理は全部根拠不要、専決だけ根拠が要る、法定代理は機関指定できない、上級は指揮監督で下級の権限を代行できる、委任すると指揮監督も消える。
- 暗記: 委任・法定代理は法律の根拠あり。授権代理・専決・代決は不要。法定代理は機関指定可。上級は根拠なく下級権限を代行できないが、委任後も指揮監督は残る。
- 根拠: 行政法総論・行政機関の権限 / 地方自治法152条

#### もっと深掘る

先に「法律の根拠」と「誰の名で外に出るか」を分ける。

| | 法律の根拠 | 対外の名 | 権限の所在 |
|---|---|---|---|
| **委任** | 要る | 受任機関 | 受任機関へ移る |
| **法定代理** | 要る | 代理機関 | 本人に残る。代理人が行使 |
| **授権代理** | 不要 | 本人（本来の行政庁） | 本人に残る |
| **専決** | 不要 | 行政庁 | 行政庁。在庁中の内部分担 |
| **代決** | 不要 | 行政庁 | 行政庁。欠け・事故・不在のとき |

専決と代決の違い: 専決は平常の内部分担。代決は行政庁が動けないときの代替。どちらも外に対する権限は移らない。

法定代理の機関指定: 法律が代理機関を置く（例: 長に事故があるときの副市町村長）。行政庁があらかじめ代理すべき機関・順序を指定できる。「指定できない」は×。

上級と下級: 指揮監督（訓令・通達）は特別の根拠なしでできる。下級の権限そのものを上級が代わって行使するには、法令の特別の根拠が要る。委任しても指揮監督は残る。問8の正解はこの最後。

#### 新作問題

行政機関の権限の移し方について、妥当なものはどれか。

1. 権限の代理は種類を問わず、法律の根拠は不要である。
2. 専決には法律の根拠が要り、代決には不要である。
3. 法定代理では、あらかじめ代理機関を指定することはできない。
4. 上級は下級へ権限を委任しても、下級への指揮監督権を行使できる。

正解: 4

委任で権限は移っても指揮監督は残る。代理は法定なら根拠要、授権なら不要。専決も代決も根拠不要。法定代理は機関指定できる。

### 問9 行政法総論：課税の無効・狸の森・理由附記の治癒・指定医の撤回

- 出題の狙い: 無効・違法性の承継・治癒・撤回を、一般論と例外で切り分ける。
- 判断ルール: 一般の無効は重大かつ明白。課税は第三者保護が薄いので明白は不要になり得るが、重大な瑕疵だけでは足りず、課税要件の根幹の過誤と、不可争力を押し付けることが著しく不当な例外事情が要る（最判昭48.4.26）。狸の森は安全認定の違法を建築確認取消で主張できる（最判平21.12.17）。更正の理由附記不備は裁決で根拠が明らかにされても治癒されない（最判昭47.12.5）。中絶指定医の指定は、明文がなくても公益上の必要が高ければ撤回できる（最判昭63.6.17）。
- ひっかけ: 課税は重大なら即無効、課税でも常に明白が要る、狸の森でも承継しない、裁決で治癒される、明文がないと撤回できない。
- 暗記: 課税の無効は明白不要になり得るが重大だけでは足りない。狸の森は承継可。理由不備は裁決でも治癒されない。指定医は明文なしでも撤回可。
- 根拠: 最判昭48.4.26 / 最判平21.12.17 / 最判昭47.12.5 / 最判昭63.6.17

#### もっと深掘る

組合せの切り方。

**課税の無効（昭48.4.26）** 課税は課税庁と納税者の間の話で、処分を信頼する第三者保護は薄い。だから一般の「重大かつ明白」ほど明白性は厳しくない。ただし「重大なら即無効」ではない。課税要件の根幹の過誤があり、徴税の安定を考えても不可争力で不利益を甘受させるのが著しく不当な例外事情があるときに、当然無効になり得る。

**狸の森（平21.12.17）** 特別区の安全認定のあと建築確認。安全認定が取り消されていなくても、建築確認の取消訴訟で安全認定の違法を主張できる。同一目的で結合して効果、周辺住民の手続保障が薄い、が理由。原則（戒告で先行の除却命令を叩けない）と混ぜない。

**理由附記の治癒（昭47.12.5）** 更正の段階で十分な理由を主張できない以上、裁決書で具体的根拠が出ても瑕疵は治癒されない。一級建築士の理由提示（平23.6.7）は「どの程度書くか」で、治癒の話と棚が違う。

**指定医の撤回（昭63.6.17）** 人工妊娠中絶を行い得る医師の指定。撤回の明文がなくても、不利益を考慮しても公益上の必要が高ければ撤回できる。処分布置権。

#### 新作問題

行政行為の効力に関する判例の整理として、妥当なものはどれか。

1. 課税処分が無効になるには、常に重大かつ明白な瑕疵が必要である。
2. 安全認定の違法を、後続の建築確認の取消訴訟で主張できる場合がある。
3. 更正の理由不備は、審査裁決で根拠が明らかになれば治癒される。
4. 中絶指定医の指定は、撤回の明文がなければ撤回できない。

正解: 2

狸の森。課税は明白不要になり得るが重大だけでは足りない。理由不備は治癒されない。指定医は明文なしでも撤回可。

### 問10 義務履行確保：代執行の根拠・手続・費用（直接強制との違い）

- 出題の狙い: 代執行は法律（条例を含む）。戒告・令書は非常・危険切迫なら省略可。費用は文書の納付命令のあと国税滞納処分の例。
- 判断ルール: 代執行も直接強制も法律の定めが要る。直接強制に一般法はなく、条例だけではできない（条例で動き得るのは即時強制側）。代執行の対象は法律（法律の委任に基づく命令・規則及び条例を含む。）により命ぜられた代替的作為義務。戒告と代執行令書の通知は、非常の場合または危険切迫で急速実施の緊急の必要があり手続の暇がないときに省略できる。費用は額と納期日を定め文書で納付を命じ、国税滞納処分の例により徴収する。民事訴訟が原則ではない。
- ひっかけ: 直接強制は条例でも可、条例の義務は代執行できない、戒告は絶対省略不可、費用は民事訴訟、緊急切迫とだけ覚える。
- 暗記: 代執行・直接強制は法律。条例の代替的作為も代執行の対象。戒告・令書は非常または危険切迫で省略可。費用は文書で命じ、国税滞納処分の例。
- 根拠: 行政代執行法1条 / 同2条 / 同3条 / 同5条 / 同6条

#### もっと深掘る

問10の切る順。

### 問13 行政手続法：行政指導の中止申出と是正申出

### 問14 行政手続法：行政指導の意味と適用範囲

#### 新作問題

1. 不作為を求める指導は行政指導に含まれない。

### 問17 行政事件訴訟法：抗告訴訟の対象になる処分か

正解: 3

2項道路の一括指定も私権制限を生じさせるなら処分となり得る。内定取消しは原則として処分ではない。

## 債権総論

### 問30 債権総論：債権者代位権の考え方
