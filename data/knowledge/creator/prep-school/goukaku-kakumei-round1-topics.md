## 基礎法学

### 問1 基礎法学：法の効力と刑法の適用範囲

- 出題の狙い: 国外で起きた犯罪にも、日本の刑法が及ぶ場合があることを知る。
- 判断ルール: 日本の刑法は、日本国内の犯罪に適用するのが原則です。ただし、日本人の国外犯など、国外で起きた犯罪にも及ぶ例外があります。「外国人の国外犯罪には一切及ばない」は誤りです。
- ひっかけ: 国外だから絶対に適用されない、と決めつける。
- 暗記: 刑法は国内犯が原則だが、国外犯にも例外がある。「国外だから一切及ばない」は誤り。
- 根拠: 刑法1条 / 刑法2条以下 / 刑法6条

#### もっと深掘る

法の効力は「いつ・誰に・どこで」効くかを分けて考えます。刑法の場所的適用は属地主義が原則でも、国民の国外犯など例外規定があります。試験では「一切及ばない」という言い切りがひっかけになります。

#### 新作問題

刑法の適用範囲について妥当なものはどれか。

1. 外国人の国外犯罪には、日本刑法が一切適用されない。
2. 属地主義を原則としつつ、国外犯にも一定の適用があり得る。
3. 刑が軽くなっても遡及適用は常に許されない。
4. 特別法より一般法が常に優先する。

正解: 2

国外犯にも例外規定がある。「一切適用されない」は誤り。

### 問2 基礎法学：裁判外の紛争解決（ADR）の種類

- 出題の狙い: 仲裁・あっせん・和解・調停の違いを言葉で説明できる。
- 判断ルール: 仲裁は第三者が判断して解決する手続。あっせんは第三者が間に入って話をまとめる手続。和解は当事者同士が譲歩して合意する手続。調停は委員会などが仲介して処理する手続です。
- ひっかけ: 仲裁と調停、あっせんと和解の意味を入れ替える。
- 暗記: 仲裁は第三者が決める。あっせんは仲介。和解は当事者の譲歩。調停は委員会などが仲介する。
- 根拠: ADR法 / 民事調停法

#### もっと深掘る

裁判以外で争いを収める方法をまとめてADRと呼びます。試験では定義の入れ替えが定番なので、各語を「誰がどう解決するか」で覚えます。

#### 新作問題

第三者が判断して紛争を解決する手続はどれか。

1. あっせん
2. 仲裁
3. 和解
4. 調停

正解: 2

仲裁は第三者の判断によって紛争を解決する。

## 憲法

### 問3 憲法：外国人の在留期間更新と法務大臣の裁量

- 出題の狙い: 在留更新の不許可がいつ違法になるかを知る。
- 判断ルール: 外国人に入国の自由は保障されていません。在留期間の更新を認めるかは法務大臣の広い裁量です。事実の基礎を全く欠く場合や、社会通念上著しく妥当性を欠く場合に、裁量の逸脱・濫用として違法になります。
- ひっかけ: 外国人には在留の権利がある、上陸拒否事由がなければ不許可はできない、と読む。
- 暗記: 在留更新の許否は法務大臣の広い裁量。全く事実の基礎を欠くか、著しく妥当性を欠くときに違法になる。
- 根拠: 最大判昭和53年10月4日 / 出入国管理及び難民認定法

#### もっと深掘る

マクリーン判決の整理です。人権保障は在留制度の枠内で考え、更新不許可の審査は裁量逸脱・濫用の有無に絞ります。

#### 新作問題

在留期間更新不許可の違法性判断として妥当なものはどれか。

1. 外国人には入国の自由が保障される。
2. 上陸拒否事由に準ずる事由がなければ不許可は許されない。
3. 全く事実の基礎を欠くか著しく妥当性を欠く場合に裁量逸脱となり得る。
4. 更新事由の判断は法務大臣の裁量ではない。

正解: 3

広範な裁量を前提に、著しい妥当性欠如等で違法となる。

### 問4 憲法：表現の自由・報道・取材の保障の違い

- 出題の狙い: 憲法21条で直接保障されるものと、精神に照らして尊重されるものを分ける。
- 判断ルール: 事実の報道の自由は憲法21条で保障されます。取材の自由や図書等の閲読の自由は、21条の精神に照らして十分尊重に値するとされます。私人間の反論文掲載請求権が21条で当然に保障されるわけではありません。
- ひっかけ: 取材・閲読も21条の直接保障、反論権も憲法上当然、と広げる。
- 暗記: 報道の自由は憲法21条で保障。取材や閲読は「精神に照らして尊重」。私人間の反論権は当然には保障されない。
- 根拠: 憲法21条 / 博多駅事件 / レペタ事件

#### もっと深掘る

表現の周辺領域は「直接保障か／精神に照らして尊重か」の二段で整理します。

#### 新作問題

表現の自由の判例整理として妥当なものはどれか。

1. 取材の自由は憲法21条により直接保障される。
2. 報道の自由は憲法21条により保障される。
3. 私人間の反論文掲載請求権は常に21条で保障される。
4. 閲読の自由は憲法上まったく保護されない。

正解: 2

報道の自由は21条保障。取材・閲読は精神に照らし尊重、が基本整理。

### 問5 憲法：国会議員は全国民の代表（自由委任）

- 出題の狙い: 比例代表でも、議員は政党のロボットではないという原則を押さえる。
- 判断ルール: 憲法は国会議員を「全国民の代表」と定めます。政党の指示どおりに動け、という命令委任ではなく、自分の判断で行動する自由委任が原則とされます。
- ひっかけ: 比例代表だから常に政党の命令に従うべき、と一択にする。
- 暗記: 国会議員は全国民の代表。政党の言いなりになる命令委任ではなく、自由委任が原則。
- 根拠: 憲法43条 / 公職選挙法

#### もっと深掘る

比例代表の党籍変更問題では、「政党への投票」と「全国民の代表・自由委任」の緊張関係が問われます。

#### 新作問題

国会議員の地位の説明として妥当なものはどれか。

1. 憲法は国会議員を政党の代表と規定する。
2. 憲法は国会議員を全国民の代表と規定する。
3. 自由委任の原則は比例代表には及ばない。
4. 党籍変更があれば常に議席を失う。

正解: 2

憲法43条は全国民の代表と規定する。

### 問6 憲法：租税法律主義

- 出題の狙い: 税金のルールは法律で決める、という原則を知る。
- 判断ルール: 租税を課すには、課税の要件などを法律で定める必要があります（租税法律主義）。すでにできた信頼を後から法律で変える場合は、権利の性質・変更の程度・公益などを総合して合憲性を判断します。
- ひっかけ: 遡及的変更は常に違憲、または常に合憲、と極端に切る。
- 暗記: 税金の課し方は法律で決める（租税法律主義）。後からルールを変えるときは、信頼保護と公益を総合衡量する。
- 根拠: 憲法84条 / 憲法30条

#### もっと深掘る

憲法84条の基本です。「法律で明確に」が第一関門で、途中変更・遡及は衡量の問題になります。

#### 新作問題

租税法律主義の説明として妥当なものはどれか。

1. 課税要件は政令だけで足りる。
2. 課税要件等は法律で定める必要がある。
3. 遡及的変更は常に違憲である。
4. 租税法律主義は地方税には及ばない。

正解: 2

課税要件の定めは法律によるのが租税法律主義の核心。

### 問7 憲法：憲法に明文があるか数える問題

- 出題の狙い: 望ましい制度でも、憲法本文に書いていなければ「明文あり」と数えない。
- 判断ルール: 「憲法に規定されているものはいくつあるか」型では、政策として正しくても憲法の条文にない事項は数えません。条文の文言の有無で数えます。
- ひっかけ: 望ましい制度だから憲法に必ず明文がある、と読む。
- 暗記: 「いくつあるか」は憲法の条文に書いてあるかで数える。望ましい内容でも明文がなければ数えない。
- 根拠: 憲法各条

#### もっと深掘る

各肢を憲法の目次に照合する作業です。法律や判例にあっても、憲法本文になければ明文ではありません。

#### 新作問題

憲法の明文規定の数え方として妥当なものはどれか。

1. 政策的に正しい内容はすべて明文がある。
2. 条文の文言の有無を基準に数える。
3. 法律にあれば憲法明文と同じに数える。
4. 判例があれば明文と同じに数える。

正解: 2

明文の有無は憲法の文言で数える。

### 問49 憲法：租税法律主義と課税ルールの変更

- 出題の狙い: 課税の中身は法律で明確に定め、後からの変更は衡量で見る。
- 判断ルール: 課税要件や賦課徴収の手続は、法律で明確に定める必要があります。すでにできた信頼を後から変える場合は、権利の性質・変更の程度・公益を総合衡量します。
- ひっかけ: 変更は常に合憲、または常に違憲、と一刀両断する。
- 暗記: 課税の要件は法律で明確に定める。後から変えるときは、信頼保護と公益を総合衡量する。
- 根拠: 憲法84条

#### もっと深掘る

問6の財政とセットで、84条を答案化します。

#### 新作問題

租税法律主義について妥当なものはどれか。

1. 課税要件は告示だけで足りる。
2. 課税要件等は法律で明確に定める必要がある。
3. 事後変更は常に違憲である。
4. 地方税には租税法律主義は及ばない。

正解: 2

課税要件の明確な法定が租税法律主義の中核。

## 行政法総論

### 問8 行政組織法：権限の委任と代理の違い

- 出題の狙い: 誰の名前で処分するかを見て、委任と代理を区別する。
- 判断ルール: 権限の委任では、受任した機関が自分の名前で権限を行使します。代理では、権限は本来の行政庁に残り、本来の行政庁の名前で行使します。専決・代決は内部の決裁方法で、外に対する権限の所在は変えません。
- ひっかけ: 委任すると指揮監督も消える、専決で外部権限まで移る、と入れ替える。
- 暗記: 委任は権限が移り、受任機関が自分の名で行使する。代理は本来の行政庁の名で行使する。専決・代決は内部処理。
- 根拠: 行政法総論・行政機関の権限

#### もっと深掘る

「誰の名で処分するか」を先に確認します。委任後も上級機関の指揮監督が当然に消えるわけではありません。

#### 新作問題

PがQへ法令に基づき権限を委任した。妥当な説明はどれか。

1. Qは自己の名で行使し、Pの指揮監督関係は当然には消えない。
2. Pが自己の名で行使し続ける。
3. 法律の根拠は一切不要である。
4. 委任は内部決裁にすぎない。

正解: 1

委任では権限がQへ移り、Qが自己の名で行使する。

### 問10 義務履行確保：代執行の費用の取り方

- 出題の狙い: 代執行にかかった費用を、どうやって義務者から取るかを知る。
- 判断ルール: 代執行に要した費用は、金額と納める期限を決め、文書で納付を命じて徴収します。原則として民事訴訟で取り立てるわけではありません。
- ひっかけ: 費用は民事訴訟でしか取れない、と覚える。
- 暗記: 代執行の費用は、額と納期を決めて文書で納付を命じ、行政上の手続で徴収する。民事訴訟が原則ではない。
- 根拠: 行政代執行法2条 / 同5条 / 同6条

#### もっと深掘る

代執行は、代わりにやってその費用を義務者に負担させる制度です。費用徴収の手続を民事訴訟と混同しないことが重要です。

#### 新作問題

代執行に要した費用の徴収について妥当なものはどれか。

1. 必ず民事訴訟で徴収する。
2. 額と納期日を定め、文書で納付を命じて徴収する。
3. 口頭の戒告だけで足りる。
4. 費用徴収の手続は不要である。

正解: 2

費用は額・納期日を定め文書で納付を命じて徴収する。

### 問26 行政組織法：内閣と内閣府のしくみ

- 出題の狙い: 内閣官房の主任の大臣は内閣総理大臣であることを知る。
- 判断ルール: 各大臣は主任の大臣として行政事務を分担管理し、事務を分担しない大臣も認められます。内閣官房に関する事項の主任の大臣は内閣総理大臣です。
- ひっかけ: 職の名前や設置根拠を雑に入れ替える。
- 暗記: 内閣官房の主任の大臣は内閣総理大臣。大臣の分担管理と、無任所大臣があり得る点も押さえる。
- 根拠: 内閣法 / 内閣府設置法

#### もっと深掘る

国の行政組織は「誰が主任か」「何を置けるか」の条文知識です。

#### 新作問題

国の行政組織について妥当なものはどれか。

1. 内閣官房に係る事項の主任の大臣は内閣総理大臣である。
2. 無任所大臣は一切認められない。
3. 内閣府に外局を置くことはできない。
4. 総理に事故があっても臨時代理の制度はない。

正解: 1

内閣官房の主任の大臣は内閣総理大臣。

## 地方自治法

### 問9 地方自治法：住民監査請求の請求権者（選挙権は不要）

- 出題の狙い: 選挙権がなくても、住民なら公金支出などの監査請求ができることを知る。
- 判断ルール: 住民監査請求は、その普通地方公共団体の住民であればできます。選挙権を持っていなくても、住民であれば、違法・不当な公金支出など財務会計上の問題について監査請求できます。
- ひっかけ: 選挙権がある人だけが請求できる、納税者だけ、と狭く読む。
- 暗記: 選挙権がなくても、その自治体の住民であれば、違法・不当な公金支出について住民監査請求ができる。
- 根拠: 地方自治法242条

#### もっと深掘る

住民監査請求は、住民が監査委員に「このお金の使い方はおかしい」とチェックを求める手続です。ポイントは「選挙権」ではなく「住民」であることです。対象の中心は違法・不当な財務会計上の行為や怠る事実です。

#### 新作問題

住民監査請求について正しいものはどれか。

1. 選挙権を持つ住民だけが請求できる。
2. 選挙権がなくても、住民であれば違法・不当な公金支出について請求できる。
3. 日本国民であれば住所地を問わず誰でも請求できる。
4. 議員だけが請求できる。

正解: 2

請求できるのは選挙権の有無ではなく、当該団体の住民であること。

### 問22 地方自治法：地方議会の通年会期

- 出題の狙い: 議会を一年中開いておく仕組みを条例で決められることを知る。
- 判断ルール: 普通地方公共団体の議会は、条例で定めるところにより、定例会・臨時会ではなく、一年を通じた会期（通年会期）とすることができます。
- ひっかけ: 通年会期は条例では決められない、と覚える。
- 暗記: 地方議会は、条例で通年の会期にすることができる。
- 根拠: 地方自治法102条 / 同109条 / 同97条

#### もっと深掘る

地方議会は「何が条例で変えられるか」が頻出です。通年会期はその典型です。

#### 新作問題

普通地方公共団体の議会について妥当なものはどれか。

1. 通年の会期を条例で定めることはできない。
2. 条例で定めるところにより、通年の会期とすることができる。
3. 予算を増額して議決することは一切できない。
4. 除名後に再当選した議員は常に拒める。

正解: 2

条例により通年会期を定めることができる。

### 問23 地方自治法：地方公共団体の会計の基本

- 出題の狙い: その年の支出はその年の収入で賄う、という原則を知る。
- 判断ルール: 各会計年度の歳出は、その年度の歳入で賄います（会計年度独立の原則）。会計管理者は、長の命令がなければ支出できません。地方債を起こすには法令の根拠が必要です。
- ひっかけ: 地方債は条例だけで自由、会計管理者は独断で支出できる、と誤る。
- 暗記: その年の支出は、その年の収入で賄う。支出には長の命令が必要。地方債には法令の根拠が必要。
- 根拠: 地方自治法208条 / 同232条の4 / 同230条

#### もっと深掘る

財務は手続の厳格さが得点源です。

#### 新作問題

普通地方公共団体の財務について妥当なものはどれか。

1. 会計管理者は長の命令なしに自由に支出できる。
2. 各会計年度の歳出は、その年度の歳入をもって充てる。
3. 地方債は根拠なく起こせる。
4. 公金の取扱いに金融機関指定は不要である。

正解: 2

会計年度独立の原則により、歳出はその年度の歳入で充てる。

### 問24 地方自治法：住民監査請求は行われようとしている行為にもできる

- 出題の狙い: まだ終わっていない行為でも、明らかにされそうなら請求できることを知る。
- 判断ルール: 住民監査請求は、すでに行われた財務会計上の行為だけでなく、違法・不当な財務会計上の行為が行われようとしている場合にもできます。
- ひっかけ: 行為が終わる前は一切請求できない、と覚える。
- 暗記: 住民監査請求は、すでに行われた行為だけでなく、行われようとしている行為についてもできる。
- 根拠: 地方自治法242条

#### もっと深掘る

「終わってからしか請求できない」は誤りです。相当の確実さをもって行われようとしている財務会計上の行為についても、住民は監査請求できます。問9の「誰が請求できるか」と分けて覚えると混乱しません。

#### 新作問題

住民監査請求の時期について正しいものはどれか。

1. 行為が完全に終わった後でなければ請求できない。
2. 行われようとしている行為についても請求できる。
3. 行為の計画段階では一切請求できない。
4. 裁判所の許可があるときだけ事前に請求できる。

正解: 2

行われようとしている行為についても住民監査請求ができる。

## 行政不服審査法

### 問11 行政不服審査法：審査請求の対象と適用除外

4. 審査請求は違法な処分に限られる。

正解: 2

出入国・帰化は処分・不作為とも適用除外。不当な処分も対象となり得る。

### 問13 行政手続法：行政指導の中止申出と是正申出

### 問14 行政手続法：行政指導の意味と適用範囲

#### 新作問題

行政手続法上の行政指導について妥当なものはどれか。

## 行政事件訴訟法

### 問17 行政事件訴訟法：抗告訴訟の対象になる処分か

- 出題の狙い: 国民の権利義務を直接変える行為かどうかを見る。
- 判断ルール: 抗告訴訟の対象になるのは、公権力の行使として国民の権利義務を直接変動させる行為です。住民票の続柄記載のように法的効果がない行為は処分ではありません。公務員の採用内定取消しも、原則として処分ではありません。
- ひっかけ: 損害賠償が出るから内定取消しも処分だ、と効果の種類を取り違える。
- 暗記: 処分になるかは、権利義務を直接変える法的効果があるかで見る。採用内定の取消しは原則として処分ではない。
- 根拠: 行政事件訴訟法3条 / 最判平11.1.21 / 最判昭57.5.27

#### もっと深掘る

処分性は「法的効果の有無」が核心です。

#### 新作問題

抗告訴訟の対象（処分性）について妥当なものはどれか。

1. 住民票の続柄記載は常に処分である。
2. 公務員の採用内定取消しは、損害賠償責任が生じ得るから常に処分である。
3. 一括指定による2項道路の指定でも、私権制限が生じれば処分となり得る。
4. 労災就学援護費の不支給決定は処分になり得ない。

正解: 3

2項道路の一括指定も私権制限を生じさせるなら処分となり得る。内定取消しは原則として処分ではない。

### 問18 行政事件訴訟法：不作為の違法確認訴訟

- 出題の狙い: 申請したのに返事がないときの訴訟と、勝っても処分が出るわけではないことを知る。
- 判断ルール: 法令に基づく申請をしたのに、相当期間内に何の処分もしない場合に、不作為の違法確認を求められます。勝訴しても、申請どおりの処分を命じる判決にはなりません。
- ひっかけ: 勝訴すれば申請どおりの処分が当然に出る、申請がなくても使える、と広げる。

#### 新作問題

不作為の違法確認訴訟について妥当なものはどれか。

正解: 3

申請後の不応答が対象。勝訴しても申請どおりの処分を命ずるものではない。

### 問19 行政事件訴訟法：差止め訴訟と仮の差止め

- 出題の狙い: 将来の処分を止める訴訟と、その仮の救済の要件を知る。
- 判断ルール: 差止め訴訟は、行政庁がこれからする処分などを止めさせる本案訴訟です。仮の差止めは、償うことのできない損害を避ける緊急の必要があり、本案に理由があるとみえるときに、申立てにより認められ得ます。裁判所が職権で行うものではありません。

#### 新作問題

正解: 3

申立て、償うことのできない損害、緊急性、本案理由が必要となる。

## 民法物権

### 問25 物権：抵当権の一括競売と妨害排除

#### 新作問題

正解: 1

## 民法総則

### 問27 民法総則：後見・保佐・補助の開始と本人の同意

- 出題の狙い: どの審判に本人の同意が要るかを区別する。

#### 新作問題

文章理解の空欄補充で最初に行うべきことはどれか。

1. 一番難しそうな語を選ぶ。
2. 段落の役割と前後の接続関係を確認する。
3. 法律用語だけを探す。

段落役割と接続関係の確認が先。
