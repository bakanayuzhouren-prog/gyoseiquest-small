## 基礎法学

### 問1 基礎法学：法源と罪刑法定主義

- 出題の狙い: 刑事事件では、処罰根拠がないときに条理で処罰できないことを押さえる。
- 判断ルール: 刑罰を科すには、あらかじめ法律で犯罪と刑罰が定められている必要があります。刑事で適用法がない場合、条理を根拠に処罰するのではなく、罪刑法定主義により無罪方向で考えます。
- ひっかけ: 民事の補充法源としての条理を、刑事処罰の根拠にも使えると混同する。
- 暗記: 刑事で法律なしなら条理処罰ではなく罪刑法定主義。法律なければ罰しない。
- 根拠: 罪刑法定主義 / 刑法

#### もっと深掘る

結論：刑事処罰は法律が根拠です。理由：罪刑法定主義により、何が犯罪でどんな刑かを事前に法律で定める必要があるからです。暗記：民事の条理、刑事は法律。

#### 新作問題

刑事事件で、ある行為を処罰する明文規定が見当たらない場合の考え方として妥当なものはどれか。

1. 社会常識に反する行為なら条理だけで処罰できる。
2. 裁判所が後から犯罪類型を作れば処罰できる。
3. 類似する犯罪規定を広げて常に処罰できる。
4. 法律上の処罰根拠がなければ、罪刑法定主義により処罰できない。

正解: 4

刑事処罰には法律上の根拠が必要で、条理だけで処罰することはできません。

### 問2 基礎法学：紛争解決と裁判制度

- 出題の狙い: 高等裁判所の管轄と、行政書士の代理権の限界を区別する。
- 判断ルール: 高等裁判所は地方裁判所等の判決に対する控訴だけでなく、簡易裁判所の刑事事件の控訴を扱う場面もあります。行政書士には、司法書士のような簡裁訴訟代理権はありません。
- ひっかけ: 簡裁代理権を行政書士にもあると誤認する。
- 暗記: 行政書士は書類作成の専門家だが、簡裁代理権までは持たない。
- 根拠: 裁判所法 / 行政書士法

#### もっと深掘る

結論：高裁の管轄と士業の代理権は別々に整理します。理由：裁判所の審級制度と、各士業に認められる業務範囲は根拠法が異なるからです。暗記：簡裁代理は行政書士ではなく認定司法書士。

#### 新作問題

行政書士の裁判関連業務について妥当なものはどれか。

1. 行政書士は当然に簡易裁判所で訴訟代理人になれる。
2. 行政書士は地方裁判所で弁護士と同じ訴訟代理権を持つ。
3. 行政書士には、行政書士法上当然の簡裁訴訟代理権はない。
4. 行政書士は刑事事件の弁護人として活動できる。

正解: 3

行政書士に当然の簡裁訴訟代理権はありません。

## 憲法

### 問3 憲法：私人間効力と昭和女子大事件

- 出題の狙い: 憲法の人権規定が私人間で直接適用されるわけではないことを押さえる。
- 判断ルール: 憲法の人権規定は、原則として国家と私人の関係を規律します。私人間では、民法90条などの私法の一般条項を通じて、憲法価値を間接的に反映させます。
- ひっかけ: 私人間の紛争に憲法条文をそのまま直接適用すると考える。
- 暗記: 私人間効力は原則として間接適用。民法90条などを通す。
- 根拠: 憲法 / 民法90条 / 昭和女子大事件

#### もっと深掘る

結論：昭和女子大事件は間接適用の代表です。理由：私人間の法律関係は私法で処理しつつ、憲法の価値を公序良俗などに反映させるからです。暗記：私人間は憲法を直撃させず、私法で受ける。

#### 新作問題

私人間効力の説明として妥当なものはどれか。

1. 私人間では人権規定の価値は一切考慮されない。
2. 私人間では常に憲法条文が直接適用される。
3. 私人間では私法の一般条項を通じて憲法価値を考慮することがある。
4. 私人間効力は財産権にだけ認められる考え方である。

正解: 3

私人間では民法90条などを通じた間接適用が問題になります。

### 問4 憲法：財産権と損失補償

- 出題の狙い: 憲法29条3項の正当な補償の考え方を整理する。
- 判断ルール: 私有財産を公共のために用いる場合は、正当な補償が必要です。規制の性質・程度によって補償の要否が問題となり、あらゆる財産制限に当然に完全補償が必要となるわけではありません。
- ひっかけ: 財産権制限があれば常に同じ補償が必要と単純化する。
- 暗記: 損失補償は公共用収用などで問題。規制なら性質と程度を見る。
- 根拠: 憲法29条3項

#### もっと深掘る

結論：憲法29条3項は公共のための特別な犠牲を補償する仕組みです。理由：公共の利益のために特定人へ過度な負担を負わせる場合、公平の観点から補償が必要になるからです。暗記：特別犠牲なら補償を疑う。

#### 新作問題

損失補償について妥当なものはどれか。

1. 公共事業のために私有財産を用いる場合、正当な補償が問題となる。
2. 財産権への制限は、どんな軽微な規制でも必ず完全補償を要する。
3. 損失補償は刑罰の一種である。
4. 憲法は財産権の内容を法律で定めることを一切認めていない。

正解: 1

公共のために私有財産を用いる場合には、正当な補償が問題になります。

### 問5 憲法：国会の最高機関性

- 出題の狙い: 国会が最高機関とされる意味を、政治的美称説で押さえる。
- 判断ルール: 憲法41条の「国権の最高機関」は、国会が他機関を法的に上下支配するという意味ではなく、国民代表機関としての政治的重要性を示す表現と理解されます。
- ひっかけ: 最高機関を、内閣や裁判所への法的優越と読む。
- 暗記: 国会の最高機関性は政治的美称。法的な上下関係ではない。
- 根拠: 憲法41条

#### もっと深掘る

結論：最高機関は政治的美称です。理由：日本国憲法は権力分立を採用しており、国会が内閣・裁判所を全面的に支配する構造ではないからです。暗記：最高はえらい名前、法的支配ではない。

#### 新作問題

国会が「国権の最高機関」とされる意味として妥当なものはどれか。

1. 国会は裁判所の個別事件の判決内容を変更できる。
2. 国会は国民代表機関として政治的に重要な地位にある。
3. 内閣は国会の下部組織であり独自の権限を持たない。
4. 最高機関とは、国会がすべての行政処分を直接行う意味である。

正解: 2

最高機関性は政治的美称とされ、法的な全面優越を意味しません。

### 問6 憲法：違憲審査と砂川事件

- 出題の狙い: 高度に政治的な国家行為に対する司法審査の限界を理解する。
- 判断ルール: 砂川事件では、安全保障条約のような高度に政治性を有する問題について、一見極めて明白に違憲無効と認められない限り、裁判所の審査になじみにくいとされました。
- ひっかけ: 政治性があれば裁判所が常に完全審査する、または常に一切審査しないと極端に考える。
- 暗記: 砂川は一見極めて明白基準。高度政治問題は司法審査が抑制される。
- 根拠: 砂川事件 / 統治行為論

#### もっと深掘る

結論：砂川事件では司法審査の抑制が示されます。理由：安全保障のような高度政治問題は、裁判所より政治部門の判断に委ねられる面が強いからです。暗記：砂川は一見明白。

#### 新作問題

砂川事件に関する説明として妥当なものはどれか。

1. 安全保障条約は裁判所が常に政策の当否まで全面審査する。
2. 高度の政治性があるため、一見極めて明白に違憲でない限り司法判断は抑制される。
3. 裁判所は統治行為についても必ず違憲判決を出さなければならない。
4. 砂川事件は私人間効力を直接適用した判例である。

正解: 2

砂川事件では高度政治性と一見極めて明白基準がポイントです。

### 問7 憲法：財政と決算検査

- 出題の狙い: 決算が会計検査院の検査を経て国会へ提出される流れを押さえる。
- 判断ルール: 国の収入支出の決算は、会計検査院が検査し、内閣が次年度に国会へ提出します。予算の議決と決算の検査・提出を混同しないことが重要です。
- ひっかけ: 決算を内閣だけで完結させる、または会計検査院の検査を抜かす。
- 暗記: 決算は会計検査院が検査し、内閣が国会へ提出。
- 根拠: 憲法90条

#### もっと深掘る

結論：決算は会計検査院の検査を経て国会へ出ます。理由：財政運営の事後チェックを独立機関が行い、国会が政治的に監督するためです。暗記：決算は検査院チェック。

#### 新作問題

国の決算に関する説明として妥当なものはどれか。

1. 決算は会計検査院の検査を経て、内閣が国会に提出する。
2. 決算は衆議院だけが作成する。
3. 会計検査院は予算案を議決する機関である。
4. 決算は国会に提出されない。

正解: 1

決算は会計検査院の検査を経て内閣から国会へ提出されます。

## 行政法総論

### 問8 行政法総論：行政法の一般原則と権限濫用

- 出題の狙い: 行政権限は目的に沿って使わなければならないことを理解する。
- 判断ルール: 行政庁は、法律上の権限を形式的に持っていても、その権限を本来の目的から外れて用いると違法となることがあります。個室付浴場を妨げる目的で児童遊園設置認可を利用した判例は、権限濫用の典型です。
- ひっかけ: 形式的に権限があれば、目的がずれていても常に適法と考える。
- 暗記: 行政権限は目的どおりに使う。別目的で使うと濫用になり得る。
- 根拠: 行政法の一般原則 / 権限濫用

#### もっと深掘る

結論：権限は目的外に使うと違法になり得ます。理由：行政権限は法律が予定した目的のために与えられているからです。暗記：権限ありでも目的ずれは危険。

#### 新作問題

行政庁が、形式上は可能な認可を、まったく別の営業を妨害する目的で利用した場合の説明として妥当なものはどれか。

1. 形式的権限があれば目的は一切問われない。
2. 行政庁の内心目的は常に審査対象外である。
3. 法律目的から外れた権限行使として違法となることがある。
4. 行政法には権限濫用という考え方はない。

正解: 3

権限を本来の目的から外れて使うと、権限濫用として違法となり得ます。

### 問9 行政法総論：内閣府の外局

- 出題の狙い: 内閣府外局の代表例を押さえる。
- 判断ルール: 内閣府の外局には、金融庁、個人情報保護委員会、カジノ管理委員会などがあります。省の外局と内閣府の外局を取り違えないようにします。
- ひっかけ: 庁や委員会ならすべて同じ府省の外局だと考える。
- 暗記: 内閣府外局は金融庁・個情委・カジノ管理委員会を押さえる。
- 根拠: 内閣府設置法

#### もっと深掘る

結論：内閣府外局は具体名で覚えます。理由：組織法分野は抽象論より、どの機関がどこに属するかが問われやすいからです。暗記：金融・個情・カジノは内閣府。

#### 新作問題

内閣府の外局として押さえるべき組合せはどれか。

1. 金融庁・個人情報保護委員会・カジノ管理委員会
2. 国税庁・文化庁・スポーツ庁
3. 消防庁・観光庁・林野庁
4. 特許庁・中小企業庁・資源エネルギー庁

正解: 1

金融庁、個人情報保護委員会、カジノ管理委員会は内閣府外局です。

### 問10 行政法総論：行政上の強制措置（即時強制・執行罰）

- 出題の狙い: 即時強制と代執行法の関係、執行罰と憲法39条の違いを押さえる。
- 判断ルール: 即時強制は、すでに成立した行政上の義務の履行確保を目的とするものではないため、行政代執行法1条の適用はありません。そのため、条例を根拠に行うこともできます。執行罰は刑罰ではないので、くり返し課しても憲法39条後半（一事不再理）には当たりません。加算税と罰金刑の併科は可能です。条例違反の秩序罰は、原則として地方公共団体の長が行政処分として課します。情報提供目的の氏名等公表は、制裁目的でなければ個別の法律根拠がなくても行い得ます。
- ひっかけ: 即時強制も代執行と同じく法律根拠が必須、執行罰の反復は憲法39条違反、と決めつける。
- 暗記: 即時強制は義務履行確保ではない→条例根拠もあり得る。執行罰は刑罰ではないので一事不再理の対象外。
- 根拠: 行政代執行法1条 / 憲法39条 / 地方自治法255条の3 / 最大判昭和33年4月30日

#### もっと深掘る

結論：即時強制は代執行法の外にあり、条例根拠でも行い得ます。理由：代執行法は義務履行確保の一般法ですが、即時強制は義務の不履行を前提としない強制だからです。暗記：即時強制は「義務がないのに動く」。執行罰は「刑罰ではない」。

#### 新作問題

行政上の強制措置について妥当なものはどれか。

1. 執行罰をくり返し課すことは、憲法39条後半に違反する。
2. 即時強制は義務履行確保を直接の目的としないため、条例を根拠に行い得る。
3. 加算税を課した場合、罰金刑を併せて科すことはできない。
4. 条例違反の秩序罰は、必ず裁判所の裁判で科す。

正解: 2

即時強制は義務履行確保を目的としないため、行政代執行法1条の適用がなく、条例根拠でも行い得る。

### 問25 行政法総論：公務員判例と給料請求権の相続

- 出題の狙い: 公務員の地位争訟中に死亡した場合の給料請求権を理解する。
- 判断ルール: 免職処分取消訴訟の係属中に公務員が死亡しても、死亡までの給料請求権など財産的権利は相続の対象となり得ます。地位そのものと金銭請求権を分けて考えます。
- ひっかけ: 本人が死亡したら、関連する金銭請求権も当然にすべて消えると考える。
- 暗記: 地位は一身専属でも、死亡までの給料請求権は相続を考える。
- 根拠: 公務員判例 / 取消訴訟

#### もっと深掘る

結論：給料請求権は相続され得ます。理由：公務員としての地位そのものは本人に結びつく一方、既に発生した金銭債権は財産権として扱えるからです。暗記：地位とお金を分ける。

#### 新作問題

免職処分を争っていた公務員が訴訟中に死亡した場合の説明として妥当なものはどれか。

1. 死亡までに発生した給料請求権は、財産権として相続され得る。
2. 死亡により、発生済みの金銭債権も当然にすべて消滅する。
3. 公務員の地位は相続人が当然に承継する。
4. 取消訴訟中の死亡により、国家賠償法2条の問題だけになる。

正解: 1

地位と金銭債権は分け、給料請求権は相続され得ます。

### 問26 行政法総論：情報公開請求権と不開示理由追加

- 出題の狙い: 情報公開請求権の非相続性と、不開示理由の追加主張を押さえる。
- 判断ルール: 情報公開請求権は、請求者本人の地位に着目した権利として相続されないとされます。また、不開示決定取消訴訟では、行政庁が不開示理由を追加主張できる場合があります。
- ひっかけ: 開示請求権を通常の金銭債権のように相続できると考える。
- 暗記: 開示請求権は非相続。不開示理由の追加主張は可能な場合あり。
- 根拠: 情報公開法 / 情報公開判例

#### もっと深掘る

結論：情報公開請求権は相続されません。理由：誰でも請求できる制度ではありますが、いったんした請求上の地位は請求者本人に結びつくものとして扱われるからです。暗記：情報公開は非相続。

#### 新作問題

情報公開に関する判例の理解として妥当なものはどれか。

1. 開示請求権は請求者死亡により当然に相続人へ承継される。
2. 開示請求権は相続されないとされる。
3. 不開示決定取消訴訟で不開示理由の追加主張は常に禁止される。
4. 情報公開請求は国賠2条の営造物利用に限って認められる。

正解: 2

情報公開請求権は相続されないとされます。

## 行政手続法

### 問11 行政手続法：審査基準と処分基準の公表

- 出題の狙い: 審査基準と処分基準で、公表義務の強さが違うことを押さえる。
- 判断ルール: 申請に対する処分の審査基準は、行政上特別の支障がある場合を除き公にしておく義務があります。不利益処分の処分基準は、公にしておくよう努める努力義務です。
- ひっかけ: 審査基準と処分基準をどちらも義務、またはどちらも努力義務とする。
- 暗記: 審査基準は公表義務、処分基準は公表努力。
