# 行政手続法 第56問 — 聴聞では参加人の制度があり、弁明にはない

## 学習項目（A列）

聴聞では参加人の制度があり、弁明にはない

## もっと深掘る（B列）

なぜ不利益処分には「標準処理期間」がないのか？理由は、それぞれの性質の違いにあります。申請（Standard Processing Period あり）：国民が「許可をください」とお願いするものです。「いつ結果が出るの？」という不安を解消し、行政のダラダラを防止するために期間を定める努力義務があります。不利益処分（なし）：行政が「お前はルール違反をしたから営業停止だ！」と一方的にペナルティを与えるものです。行政が**「あなたを処分するまで、だいたい1ヶ月くらいかかりますね」という目安をあらかじめ公表するというのは、処分の性質上なじみません。**申請と不利益処分の「基準・期間」の比較ここを整理しておくと、もうひっかかりません。項目申請に対する処分不利益処分基準審査基準（義務）処分基準（努力義務）期間標準処理期間（努力義務）設定なし公表原則として公表（義務）原則として公表（努力義務）今回の「2」の文章の間違い：「不利益処分を行うか否か決定するまでに……標準的な期間を定め……」という部分は、行政手続法には存在しない架空のルールです。💡 覚え方のポイント「トドの親分」の時と同じようにイメージで覚えましょう。申請（お願い）： 「いつ返事くれるの？（期間）」が大事。不利益処分（お仕置き）： 「いつお仕置きされるの？」ではなく、**「どういう時にお仕置きされるの？（処分基準）」**の方が国民にとっては重要です。
