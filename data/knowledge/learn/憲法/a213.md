# 憲法 第213問 — 内閣は、法律がなければ、予算を執行することはできない

## 学習項目（A列）

内閣は、法律がなければ、予算を執行することはできない

## もっと深掘る（B列）

1. 受験生向けアドバイス：「予算」と「法律」は別物！多くの受験生が「何かにお金を使うには、法律の根拠が必要なのでは？」と考えがちですが、日本国憲法の下では、予算と法律は形式的に異なるもの（予算・法律二元説）とされています。法律: 国民の権利を制限したり、義務を課したりする「ルール」。予算: 一会計年度における国の収入と支出の「見積もり（計画）」。国会で「予算」が議決されれば、それ自体が内閣に対して「お金を使ってよい」という法的授権（権限）を与えます。したがって、支出を認める法律が別途存在しなくても、予算の議決だけで執行は可能です。2. 関連知識：予算の性質と効力試験で問われる「予算のポイント」を、法律と比較してまとめました。項目予算法律提出権内閣のみ（憲法73条5号）内閣・国会議員の両方成立の形国会の「議決」国会の「議決」公布の要否不要（告示される）必要（天皇の国事行為）法規範性国家機関（内閣など）を拘束する国民と国家の両方を拘束する3. 「法律」が必要なケースとの区別ここがさらに深いひっかけポイントです。予算の執行（支出）: 予算の議決だけでOK。租税の徴収（収入）: 「法律」が必要（憲法84条：租税法律主義）。つまり、「国がお金を集める（税金）」ときには法律が絶対に必要ですが、「国がお金を使う（執行）」ときには、国会の認めた予算があれば法律は必須ではない、という違いがあります。4. 行政書士試験での「ひっかけ」パターン過去問では、以下のような表現で受験生を惑わせてきます。パターンA: 「予算は、法律と同じく天皇が公布しなければ効力を生じない。」×：予算は公布されません。パターンB: 「内閣が予算を提出する際、あらかじめ参議院の同意を得なければならない。」×：予算はまず衆議院に提出しなければなりません（衆議院先議権：憲法60条1項）。学習のヒント行政書士試験の勉強中、こうした「似ているけれど決定的に違うもの」に直面したら、アプリ開発の「条件分岐（If文）」のように整理してみるとスッキリするかもしれません。If (収入 == 税金) { 法律が必要 }Else If (支出 == 予算執行) { 議決だけでOK }
