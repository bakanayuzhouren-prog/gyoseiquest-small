# 行政事件訴訟法 第25問 — 土地改良法に基づく土地改良施行認可処分の取消しが求められた場合、原状回復が困難だとしても訴えの利益は

## 学習項目（A列）

土地改良法に基づく土地改良施行認可処分の取消しが求められた場合、原状回復が困難だとしても訴えの利益は失われない

## もっと深掘る（B列）

最判平元．６．２０について解説してゆくよ！
① ストーリーを4コマで説明！
この事件は、とある遺跡の「史跡指定」が解除されたことで、考古学の研究者たちが国を訴えたバトルだよ。

【1コマ目：世紀の大発見！「梅木遺跡」】
考古学を研究しているXさんたちが、大分県で「梅木遺跡」というすごい遺跡を発見したんだ。この功績が認められて、国（文部大臣）はこの遺跡を国の「史跡」に指定。これで遺跡は守られ、Xさんたちは安心して研究できる！と喜んでいたよ。

【2コマ目：国、まさかの手のひら返し】
ところが数年後、国は突然「やっぱりこの遺跡、史跡じゃなくてもいいや。史跡指定を解除します！」という処分を下したんだ。理由は、遺跡の価値が思ったほどじゃなかった、ということらしい。これには研究者たちもビックリ！

【3コマ目：研究者、ブチギレ！「俺たちの研究を邪魔するな！」】
「史跡じゃなくなったら、土地が開発されて遺跡が壊されちゃうじゃないか！」「俺たちの研究が続けられなくなる！」と怒った研究者Xさんたち。「こんな処分は無効だ！取り消せ！」と、国を相手に裁判（取消訴訟）を起こしたんだ。

【4コマ目：最高裁の冷たい一言「あなた方、部外者ですよ」】
しかし、最高裁判所はXさんたちの訴えをバッサリ。「気持ちはわかるけど、文化財保護法は、あなたたち研究者『個人』の利益を守るためにある法律じゃないんだ。だから、あなたたちにこの裁判を起こす資格（原告適格）はありません」と、門前払いにしてしまったんだ。

② 重要論点を判旨から読み解く
この判例で一番大事なのは、行政事件訴訟法9条1項でいう「法律上の利益を有する者（＝裁判を起こせる人）」って誰なの？っていう超重要テーマ。

最高裁の結論は、「処分の根拠となる法律が、あなた個人の利益を守ろうとしてくれているか？」で決まる、ということ。

文化財保護法の目的は「みんなのため」
最高裁はこう言っているよ。

「文化財保護法は、文化財を保存・活用して、国民みんなの文化的向上に役立てるのが目的だよね。研究者が研究できるっていう利益も、この『国民みんなの利益』の中に含まれちゃってる（吸収・解消されてる）んだ。法律がわざわざ『研究者個人の特別な利益』として守ってあげよう、とまでは書いていないよ」

つまり、研究がしにくくなるっていう不利益は、あくまで「国民全体の利益がちょっと減った」という話の一部であって、「あなた個人の権利が直接侵害された」とは言えない、ということ。
だから、研究者Xさんには裁判を起こす資格（原告適格）が認められなかったんだ。

これは、遺跡の近くに住んでいる住民も同じ。史跡があることで静かな環境で暮らせるっていう利益も、法律が個別に守っているわけじゃないから、原告適格は認められない、と判断されたよ。

③ 行政書士試験を想定した問題
さあ、ここからは試験本番のモードに切り替えて、問題にチャレンジしてみよう！

【問題】（択一式）
行政事件訴訟法に定める取消訴訟の原告適格に関する次の記述のうち、最高裁判所の判例の趣旨に照らし、誤っているものはどれか。

1.  公衆浴場法に基づく適正配置規制は、既存の公衆浴場業者の営業上の利益を保護する趣旨を含むため、距離制限に違反してなされた他の公衆浴場の営業許可処分について、既存業者はその取消しを求める原告適格を有する。
2.  都市計画法に基づく開発許可処分により、周辺地域に著しい環境の悪化が生じるおそれがある場合、当該地域に居住する住民は、健康で快適な生活を営む利益を個別的に侵害される者として、当該処分の取消しを求める原告適格を有する。
3.  文化財保護法は、文化財の研究者が史跡の保存・活用から受ける利益について、同法の目的とする一般的、抽象的な公益のなかに吸収・解消させずに、特に文化財の学術研究者の学問研究上の利益の保護について特段の配慮をしているため、史跡を研究の対象とする学術研究者には、史跡の指定解除処分の取消しを求める原告適格が認められる。
4.  森林法が保安林の指定によって確保しようとしている利益は、主として公共の利益であるが、同時に、その指定により利益を受ける地域内の個人の個別的利益をも保護する趣旨を含むため、当該地域内の者は、保安林指定解除処分の取消しを求める原告適格を有する。

【解答・解説】
正解：３

1.  正しい。
    公衆浴場の距離制限は、乱立を防いで経営の安定を図ることで、国民保健・環境衛生という公益を守る目的がある。同時に、既存業者の営業上の利益も事実上保護しているよね、というのが判例の考え方。したがって、既存業者には原告適格が認められるよ（最判昭37.1.19）。

2.  正しい。
    開発許可によって、騒音や大気汚染などで健康や生活環境に「著しい被害」を直接受けるおそれのある住民は、その利益が法律上保護されるべきものとして、原告適格が認められるよ（最判平9.1.28）。

3.  誤り。
    これが今回の判例の核心部分だね。判旨にある通り、文化財保護法は、研究者の学問研究上の利益を「個人の個別的利益」として保護する趣旨までは含んでいない。あくまで国民全体の利益（一般的公益）の中に吸収されるものだから、研究者に原告適格は認められない、というのが結論だよ。

4.  正しい。
    保安林の指定解除で、洪水や渇水などの危険に直接さらされることになる地域住民の利益は、単なる事実上の利益じゃなくて、森林法が保護する個々人の個別的利益でもある、と判断されている。だから、これらの住民には原告適格が認められるんだ（最判昭57.9.9）。

💡 ワンポイントアドバイス：
原告適格の問題が出たら、「その法律は『みんなの利益』だけじゃなく、『個人の利益』も守ろうとしてるかな？」と考えてみよう。ライバル業者の排除（1）、生活環境の保護（2）、災害からの保護（4）は個人の利益と結びつきやすいけど、今回の「研究のしやすさ」は少し間接的だよね。この「利益の直接性」の感覚を掴むのが合格への近道だよ！
