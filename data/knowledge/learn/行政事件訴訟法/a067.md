# 行政事件訴訟法 第67問 — 行政庁の拘束は、行訴法のすべての抗告訴訟に準用される

## 学習項目（A列）

行政庁の拘束は、行訴法のすべての抗告訴訟に準用される

## もっと深掘る（B列）

行政事件訴訟法31条「事情判決」について解説してゆくよ！
① ストーリーを4コマで説明！
いきなり条文だとイメージしにくいから、まずは「違法なダム建設」をめぐる架空のストーリーで見てみよう。

【1コマ目：県「ダム造るぞ！」、住民「待った！手続きが違法だ！」】
見出し：違法な建設計画、発進！
とある県が、大事な環境アセスメント（影響調査）をすっ飛ばして、巨大ダムの建設許可を出したんだ。これに怒った住民Xさんたちが「許可処分は違法だ！取り消せ！」と裁判（取消訴訟）を起こしたよ。

【2コマ目：裁判中に、ダムはどんどん完成へ…】
見出し：進む工事、長い裁判
でも、裁判って時間がかかるじゃん？訴訟をやっている間に、ダムの工事はどんどん進んで、もう9割がた完成しちゃった。ダムには水も溜まり始めて、周辺の道路や施設もダムがある前提で整備されちゃったんだ。

【3コマ目：裁判所「処分は違法！…でも、取り消しません！」】
見出し：まさかの「違法だけど棄却」判決
そしてついに判決の日。裁判所は「県の許可処分は、確かに手続きを無視した『違法』なものでした」と認めてくれた！でも、続けてこう言ったんだ。「今さらこれを取り消してダムを壊すと、莫大なお金が無駄になるし、地域の生活も大混乱する。だから、処分は取り消しません！」って。これが「事情判決」だよ。

【4コマ目：主文で「違法宣言」！住民、次の戦いへ】
見出し：次につながる「違法」のお墨付き
住民Xさんたちは形式上は負けちゃったけど、判決の主文（一番大事な結論部分）には「この処分は違法である」ってハッキリ書いてもらえた。これって、国や県に損害賠償を請求する裁判を起こすときに、超強力な証拠になるんだ。Xさんたちは、この「お墨付き」を武器に、次はお金の賠償を求める戦いに進むことができるんだよ。

② 重要論点を条文から読み解く
この「事情判決」って、一体何なんだろう？条文のポイントをかみ砕いて見ていくよ。

結論から言うと、「処分は確かに違法。でも、今さらそれを取り消すと社会全体に与える悪影響がデカすぎるから、今回は特別に処分を取り消さないでおくね」っていう、裁判所の苦渋の決断なんだ。

事情判決が認められるには、厳しい要件があるよ。

*   **要件①：処分が「違法」であること**
    これが大前提。裁判所が「この処分、アウトだね」って認定しないと話が始まらない。適法な処分に対しては絶対に適用されないよ。

*   **要件②：取り消すと「公の利益に著しい障害」が生じること**
    「ちょっと困る」レベルじゃダメ。「著しい障害」、つまりダムを壊す莫大な費用とか、公共施設の利用がストップして住民が大パニックになるとか、社会全体にめちゃくちゃデカい不利益が発生する場合じゃなきゃいけないんだ。

*   **要件③：いろんな事情を天秤にかけること（比較衡量）**
    裁判所は、「原告が受ける損害」と「取り消さないことによる公共の利益」を天秤にかけるんだ。原告のダメージの大きさや、その損害を賠償できるか、なども全部ひっくるめて考えて、「うーん、今回は取り消さない方が社会のためだな」って判断したときだけ、この判決が出される。

*   **効果：「請求棄却」＋「主文で違法宣言」**
    これが最大のポイント！訴えは退けられる（請求棄却）から、形式的には原告の負け。でも、判決の「主文」で「あなたの言う通り、この処分は違法でしたよ」ってお墨付きをくれるんだ。この「違法宣言」があるから、原告は次に国家賠償請求訴訟を起こしやすくなる、っていう仕組みなんだね。

③ 行政書士試験を想定した問題
さあ、ここからは試験本番のモードに切り替えて、問題にチャレンジしてみよう！

【問題】（択一式・5肢択一）
行政事件訴訟法が定める事情判決に関する次の記述のうち、正しいものはどれか。

1.  事情判決は、処分が適法であることを前提としつつも、公共の福祉の観点から原告の請求を棄却するものであるため、判決の主文において処分が適法であることを宣言しなければならない。
2.  裁判所は、事情判決をするにあたり、原告の受ける損害の程度を考慮する必要はなく、もっぱら処分を取り消すことにより公の利益に著しい障害を生ずるか否かによって判断する。
3.  事情判決は、原告の請求を棄却する判決であるから、当該処分が違法であることは判決理由中で示されるにとどまり、主文で宣言されることはない。
4.  処分が違法であることを理由とする取消訴訟において、当該処分を取り消すことにより公の利益に著しい障害を生ずる場合であっても、原告の受ける損害が金銭賠償によっても償うことができないような重大なものであるときは、事情判決をすることは許されないと解されている。
5.  事情判決の制度は、行政処分の効力を争う訴訟類型に広く認められており、取消訴訟のほか、無効等確認訴訟においても、その性質に反しない限り準用される。

【解答・解説】
正解：4

1.  誤り
    事情判決の大前提は「処分が違法」であることだよ。適法な処分には適用されない。そして、主文では「違法であること」を宣言するんだ。「適法を前提」という部分が根本的に間違っているね。

2.  誤り
    行政事件訴訟法31条1項には「原告の受ける損害の程度、その損害の賠償又は防止の程度及び方法その他一切の事情を考慮したうえ」とハッキリ書いてある。原告の損害と公共の利益を天秤にかける（比較衡量する）のが事情判決だから、この記述は誤り。

3.  誤り
    これぞ頻出のひっかけポイント！事情判決の最大の特徴は、請求を棄却しつつも「主文において、処分又は裁決が違法であることを宣言しなければならない」点にある。判決理由中だけじゃなくて、「主文」で宣言されるからこそ、価値があるんだ。

4.  正しい
    その通り。裁判所は「一切の事情を考慮」するんだ。もし原告の受ける損害が、お金では到底償えないほど重大なもの（例えば、健康被害やかけがえのない自然環境の喪失など）である場合、いくら公共の利益のためとはいえ、原告の請求を棄却することは「公共の福祉に適合しない」と判断されることがある。そのような場合には、事情判決をすることは許されない、と考えるのが判例・通説だよ。

5.  誤り
    事情判決の規定（行訴法31条）は、無効等確認訴訟には準用されていない（行訴法38条1項参照）。考えてみれば当たり前で、「無効」な処分はそもそも最初から効力がゼロ。だから、「取り消すと影響がデカいから見逃す」っていう発想自体が成り立たないんだね。

💡 ワンポイントアドバイス：
事情判決は「形式的には負け、でも実質的には一部勝ち」という特殊な判決だ。「違法だけど棄却」と「主文での違法宣言」は必ずセットで覚えよう！この違法宣言が、次の国家賠償請求への「招待状」になる、とイメージすると忘れにくいよ。

## 根拠条文（I列）

（特別の事情による請求の棄却）
第三十一条　
取消訴訟については、処分又は裁決が違法ではあるが、これを取り消すことにより公の利益に著しい障害を生ずる場合において、原告の受ける損害の程度、その損害の賠償又は防止の程度及び方法その他一切の事情を考慮したうえ、処分又は裁決を取り消すことが公共の福祉に適合しないと認めるときは、裁判所は、請求を棄却することができる。この場合には、当該判決の主文において、処分又は裁決が違法であることを宣言しなければならない。
２　裁判所は、相当と認めるときは、終局判決前に、判決をもつて、処分又は裁決が違法であることを宣言することができる。
３　終局判決に事実及び理由を記載するには、前項の判決を引用することができる。
