# 債権総論 第40問 — 詐害行為の立証責任は債務者が負い、受益者の悪意に関しては、受益者自らの善意について立証責任を負う

## 学習項目（A列）

詐害行為の立証責任は債務者が負い、受益者の悪意に関しては、受益者自らの善意について立証責任を負う

## もっと深掘る（B列）

**1. 根拠（条文・法理）結論：誤り**

詐害行為取消権（民法424条1項）を行使する債権者は、債務者が債権者を害することを知って行為をしたこと（詐害意思）や、その行為によって利益を受けた者（受益者）が債務者の詐害意思を知っていたこと（悪意）など、詐害行為の要件について立証責任を負うのが原則です。ただし、受益者の悪意の立証については、受益者が善意であることを主張する場合には、その善意の立証責任は受益者自身が負うとされています（[[red:最判昭和33年9月11日]]）。

**考え方のポイント**

詐害行為の立証責任は、その取消しを求める **債権者** が負うのが原則です。特に受益者の悪意については、債権者が立証することは困難であるため、受益者が自らの善意を主張する場合には、受益者自身がそれを立証するという例外的なルールが判例によって確立されています。

**2. 具体例**

-   **状況**：債務者Cが、債権者Aへの多額の借金があるにもかかわらず、唯一の財産である土地を受益者Bに不当に安い価格で売却しました。債権者Aは、この売却が詐害行為であるとして、詐害行為取消権を行使しようとしています。
-   **結果**：債権者Aは、CがAを害することを知って土地を売却したこと、およびBがCの詐害行為を知っていたこと（悪意）を立証する必要があります。しかし、もしBが「自分はCの詐害行為について全く知らず、善意だった」と主張するならば、B自身がその善意を証明する責任を負うことになります。

**3. 過去問の急所（ひっかけ対策）詐害行為の立証責任の主体**
詐害行為の要件（債務者の詐害意思、受益者の悪意など）の立証責任は、詐害行為取消権を行使する債権者が負います。
→ ひっかけ：詐害行為の立証責任は債務者が負う → **[[red:×]]受益者の悪意の立証責任**
受益者の悪意の立証責任は、原則として債権者が負います。しかし、受益者が善意を主張する場合には、受益者自身がその善意を立証する責任を負います。
→ ひっかけ：受益者の悪意の立証責任は常に債権者が負う → **[[red:×]]**
→ ひっかけ：受益者の悪意の立証責任は常に受益者が負う → **[[red:×]]4. 周辺知識**

-   **民法424条1項**：債権者は、債務者が債権者を害することを知ってした行為について、その行為によって利益を受けた者に対し、その行為を取り消すことができる旨を定めています。
-   **民法424条の2**：詐害行為取消権は、受益者からさらに財産を取得した転得者に対しても行使できますが、転得者にも悪意があることが要件となります。転得者の悪意の立証責任も、受益者の場合と同様の考え方が適用されます。

**受験生へのアドバイス**

立証責任の所在は、民法の各分野で重要な論点となります。詐害行為取消権における立証責任は、原則と判例による例外（受益者の善意の立証責任）を正確に区別して理解しておくことが、得点に繋がるポイントです。
