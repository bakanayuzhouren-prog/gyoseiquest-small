# 基礎法学 第71問 — 要件事実とは、具体的事実のことをいう

## 学習項目（A列）

要件事実とは、具体的事実のことをいう

## もっと深掘る（B列）

1. 要件事実の立ち位置（3つの階層）法律の議論を構造化すると、以下の3つのレイヤーに分かれます。レイヤー名称内容具体例抽象（法）法律要件条文に書かれた抽象的な条件「他人の権利を侵害したこと」連結（主張）要件事実条文の条件にピッタリ合う特定の事実「AがBの所有する自転車を壊した事実」具体（証拠）具体的事実（間接事実）要件事実を裏付けるための断片的な事実「現場にAの靴が落ちていた」「防犯カメラに映っていた」2. なぜ「要件事実」を区別するのか？裁判では、当事者が好き勝手なエピソード（具体的事実）を語っても、それが法律の要件に結びつかなければ意味がありません。フィルターの役割: 「その話は、どの条文のどの要件を満たすための事実ですか？」という問いに対する答えが要件事実です。主張立証責任の所在: どちらの当事者が、どの事実を証明しなければ負けてしまうのか、というルール（分配）を決めるための基準になります。3. プログラミング的・構造的視点での理解法文を構造化して捉える際、要件事実は「関数の引数（ひきすう）」に近い存在です。関数（法律要件）: function 損害賠償(不法行為事実, 損害の発生, 因果関係) { ... }引数（要件事実）: 損害賠償("Aが自転車を壊した", "修理代3万円", "衝突が原因")実データ（具体的事実）: 現場の写真、修理の見積書、目撃者の証言このように、抽象的な「法」と、ドロドロした「現実の事件」を繋ぐインターフェースの役割を果たしているのが要件事実です。まとめ「要件事実 ＝ 具体的事実」ではなく、「要件事実 ＝ 法律要件に該当する、必要最小限の事実」と整理しておきましょう。行政書士試験の記述式問題や、法文をビジュアル化して整理する際も、この「どの言葉が要件事実にあたるのか？」という視点を持つと、論理の骨組みが非常にクリアに見えてきます。
