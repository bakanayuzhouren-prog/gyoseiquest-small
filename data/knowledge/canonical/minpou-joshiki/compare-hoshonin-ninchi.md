# 比較 — 人選と親子の空白（04〜05）

| | 保証人を債権者が指名 | 認知はいつから子か |
|--|---------------------|-------------------|
| 非常識 | 自分で選んでおいて資力・能力不足で交代要求 | 認知した日から子（途中まで親なし） |
| 常識 | 自分で選んだ人の欠点を後から問うな | 子に親なき空白はいらない |
| 結論 | 450条の行為能力・資力・交代請求は**適用しない** | **出生時**に遡る |
| 短い例外 | 5条の取消しは別問題 | 第三者の既得権は害さない（784条ただし書） |
