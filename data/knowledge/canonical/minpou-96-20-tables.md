# 96条・20条の試験用表

模試の肢全文は載せない。てらしぃの敗因（相手方と第三者の混線、法定代理人の沈黙＝追認みなし忘れ、無権代理へのベタ貼り）を表にする。

## 1. 問27：誰の主観を見るか（相手方 ≠ 第三者）

強迫は相手方の主観を問わず取り消せる、は維持。混ぜるなは「取消しの可否」と「対抗」と「取消し後」。

| 聞くこと | 見る人 | 判断軸 | 条文 |
|---|---|---|---|
| 第三者の**詐欺**で取消せるか | **相手方** | 知り、又は知ることができたか | 96条2項 |
| 第三者の**強迫**で取消せるか | 見ない | いかなる場合でも取消せる | 96条1項（2項は詐欺だけ） |
| 詐欺取消を取消し**前**の第三者に対抗できるか | **その第三者** | 善意かつ無過失なら対抗不可（登記不要） | 96条3項 |
| 詐欺取消の**後**に入った不動産の第三者 | 登記 | 原則、先に登記した者 | 177条（復帰的物権変動） |

強迫取消は96条3項の対象外。取消し前の第三者にも原則対抗可。

**暗記** 取消しの可否（第三者詐欺）＝相手方。対抗（取消し前）＝第三者の善意無過失。取消し後の不動産＝登記。

## 2. 問28：21条の詐術（黙秘と「あいまって」）

黙秘だけは詐術にならない、は維持。判例の言い回し（他の言動とあいまって誤信させ、又は誤信を強めた）は**詐術の成立**の話。成立したら効果は**取り消せない**。

| 事実 | 詐術 | 取消し |
|---|---|---|
| 制限行為能力者であることを**黙秘しただけ** | ならない | **できる** |
| 他の言動とあいまって誤信させ、又は誤信を強めた（最判昭44.2.13） | **なる** | **できない**（21条） |

肢に判例フレーズがあると丸に見える。見るのは右列。フレーズが正しくても「取消原因になる／取り消せる」と書いてあれば×。

## 3. 問28：催告の沈黙（20条）と無権代理（114条）

未成年者・成年被後見人本人への催告は効力なし、は維持。敗因は**法定代理人への無回答＝追認みなし**（20条2項）。無権代理の本人催告（114条＝拒絶みなし）をここに貼ると落ちる。

| 催告の相手・中身 | 無回答 | 条文 |
|---|---|---|
| 未成年者・成年被後見人本人（まだ制限中） | **効力なし** | 追認権がない |
| 能力を得た本人（追認する？） | **追認**みなし | 20条1項 |
| **法定代理人等**（権限内について追認する？） | **追認**みなし | 20条2項 |
| 特別の方式・方式具備の通知なし | **取消し**みなし | 20条3項 |
| 被保佐人・同意要の被補助人へ「追認を得よ」 | **取消し**みなし | 20条4項 |
| 無権代理の**本人**（追認する？） | **追認拒絶**みなし | 114条 |

| | 黙ったとき |
|---|---|
| 無権代理・本人（114条） | 追認しない（拒絶みなし）→本人に効かない |
| 制限行為能力・**法定代理人**（20条2項） | **追認した**とみなす |

「追認しないと取り消される」は無権代理側の感覚。法定代理人催告には使わない。
