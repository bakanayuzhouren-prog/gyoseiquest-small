# 事情判決と執行停止の取消し

e-Gov。行政不服審査法は平成26年法律第68号、行政事件訴訟法は昭和37年法律第139号。確認日 2026-10-23。再審査請求の事情裁決は64条4項。66条は審理手続の準用で、45条から49条を準用対象から除く。66条に事情裁決の4項はない。

## 事情裁決と事情判決

どちらも、公の利益に著しい障害が生ずる場合に、損害の程度、賠償又は防止の程度及び方法、その他一切の事情を考慮し、取り消すことが公共の福祉に適合しないと認めるときは、棄却することができる。選んだときは、主文で宣言しなければならない。棄却は任意、宣言は義務。

| | 行審法45条3項 | 行訴法31条1項 |
|---|---|---|
| 対象 | 処分についての審査請求。事実上の行為の撤廃もこの項の文言に入る | 取消訴訟 |
| 前提 | 違法又は不当 | 違法 |
| 避ける効果 | 取消し、又は撤廃 | 取消し |
| 棄却 | することができる | することができる |
| 宣言 | 違法又は不当 | 違法 |

不作為の審査請求に、45条3項と同型の事情裁決はない。理由があるときは、違法又は不当の宣言をする（49条3項）。再調査の請求にもない。理由があれば取消し・変更等をし、事実上の行為は宣言に撤廃又は変更を加える（58条・59条）。61条の準用列挙に45条はない。再審査請求には、原裁決等を取り消し又は撤廃することが公共の福祉に適合しないと認めるときは棄却することができる、という同型がある（64条4項）。選んだときは、主文で原裁決等が違法又は不当であることを宣言しなければならない。

行訴法31条は、無効等確認・義務付け・差止めへは38条で準用されていない。処分又は裁決の取消しを求める民衆訴訟・機関訴訟には、9条と10条1項を除き取消訴訟の規定が準用される（43条1項）。

31条2項は、相当と認めるとき、終局判決前でも違法を宣言することができる。

## 認めるとき

「と認めるとき」の効果が常に任意、ではない。

行審法25条4項は、審査請求人の申立てがあり、重大な損害を避けるために緊急の必要があると認めるときは、執行停止をしなければならない。ただし、公共の福祉に重大な影響を及ぼすおそれがあるとき、又は本案について理由がないとみえるときは、この限りでない。

行審法46条2項と49条3項は、一定の処分をすべきものと認めるときは、上級行政庁なら命ずる。処分庁又は不作為庁自身なら、自らその処分をする。できる、とは書いていない。

行審法41条1項は、必要な審理を終えたと認めるときは、審理手続を終結するものとする。

行訴法で今回拾った「と認めるとき」「と認める場合」は、効果がすることができる、であった。執行停止を取り消さなければならないのは27条4項で、きっかけは内閣総理大臣の異議があったときである。

## 執行停止の取消し

| | 行審法26条 | 行訴法26条1項 |
|---|---|---|
| 時期 | 執行停止をした後 | 執行停止の決定が確定した後 |
| 要件 | 公共の福祉に重大な影響を及ぼすことが明らかとなったとき、その他事情が変更したとき | その理由が消滅し、その他事情が変更したとき |
| 始め方 | 申立ての語はない | 相手方の申立て |
| 効果 | 取り消すことができる | 決定をもって取り消すことができる |

行訴法27条4項は別である。異議があったときは、既にした執行停止の決定を取り消さなければならない。
