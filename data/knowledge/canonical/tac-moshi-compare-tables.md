## 1. 行政代執行法 1条・2条（問10）

| 項目 | 1条（代執行） | 2条（代替的作為義務） |
|------|----------------|------------------------|
| 前提 | 法律又は**条例**に基づく代執行 | 同左 |
| 対象義務 | **代替的作為義務**のみ | 非代替的作為義務は対象外 |
| 即時強制 | 義務履行確保手段**ではない** | — |
| 条例 | 1条の「法律」は条例**含まない**（新手続は条例で不可） | 2条の「法律」は条例**含む**（代替義務の課しは可） |

**ひっかけ**: 即時強制＝代執行法1条の反対解釈で条例即時強制が可能、という型。

## 7. 法解釈の類型（TAC2・基礎法学）

立法者の意思は**重要な資料の一つ**。法的安定性も**考慮**。文言が出発点。唯一絶対ではない。刑法の類推は罪刑法定で**原則禁止**。

| 類型 | 切り方 | 定番具体例 |
|------|--------|------------|
| 拡張 | 文言の**枠の中**を広く | 717条「土地の工作物」←工場内の据付機械・エレベーター・軌道 |
| 類推 | 文言の**外**の類似へ | 768条財産分与→内縁解消。94条2項類推適用 |
| 縮小 | 広すぎる文言を絞る | 177条第三者＝当事者・包括承継人以外で、登記欠缺を主張する正当な利益を有する者 |
| 反対 | 書いてない側は逆 | 未成年者同意→成年はこの規定上は同意不要。代執行法1条型 |
| もちろん | より強い理由で当然 | 車進入禁止なら飛行機は当然禁止 |

**ひっかけ**: 工場機械＝類推、内縁財産分与＝拡張、177条＝拡張、刑法でも類推OK、立法者意思が唯一。

## 8. 法令用語・効力（TAC3・基礎法学）

| 項目 | 切り方 |
|------|--------|
| その他 | 前と後は別物（並列） |
| その他の | 前は後の例示（国賠2条の営造物） |
| 科する | 刑・**過料** |
| 課する | 税・義務 |
| スピード | **直ちに＞速やかに＞遅滞なく** |
| 法律／命令 | 国会／行政機関（「国＝法律」は粗い） |
| 施行 | 無指定は公布から20日経過後。附則で公布日施行もあり |
| 刑法6条 | 軽い方による。**重くなった新法は遡及しない** |
| 先特後普 | 先にできた特別法 ＞ 後の一般法 |
| 外国人の国外犯 | 保護主義（2条）・世界主義（4条の2）であり得る |

民訴＝処分権・弁論。自白は証拠調べ不要だが、事実認定が一切不要ではない。違法収集の抑止と無罪推定は刑訴。裁判員は2009年〜、事実認定と量刑にも関与。

## 9. ADR・法源・裁判所（基礎法学）

| ADR | 切り方 |
|------|--------|
| 調停 | 原則 裁判官1＋委員2人以上。相当なら裁判官だけ可 |
| 和解 | 互譲（695条）。定義は互譲。創設的効力は性質論 |
| 仲裁 | 第三者が**判断**。当事者が選ぶ |
| あっせん | 仲介。民間人に限らない |

制定法＞判例。先例拘束は**事実上**（実定法の上ではない）。民事は条理補充、刑事は罪刑法定。学説は法源ではない。

法令違憲は原則大法廷。罰金以下の第一審は簡裁。人事訴訟第一審は家裁（控訴＝高裁、上告＝最高裁）。認定司法書士＝法務大臣の認定＋簡裁＋140万以下。
