# 戦後日本経済（年代順）

## 結論

試験では年号の丸暗記より、復興→高度成長→為替と石油→消費税という塊で並べる。国民所得倍増計画は1960年の閣議決定である（1961年開始と書いてある資料をそのまま採用しない）。

## 比較表（時期ブロック）

### 1947–1968 復興から高度成長

| 年 | 出来事 |
|----|--------|
| 1947 | 傾斜生産方式 |
| 1949 | ドッジ・ライン、シャウプ勧告 |
| 1950〜53 | 朝鮮特需 |
| 1954年末頃〜1957 | 神武景気 |
| 1956 | 経済白書「もはや戦後ではない」 |
| 1960 | 国民所得倍増計画を閣議決定 |
| 1964 | 東京オリンピック、IMF8条国移行、OECD加盟 |
| 1968 | 名目GNPが西ドイツを上回り自由世界第2位 |

### 1971–1987 為替と石油

| 年 | 出来事 |
|----|--------|
| 1971 | ニクソン・ショック |
| 1971 | スミソニアン協定 |
| 1972 | 日本列島改造論 |
| 1973 | 変動相場制への移行 |
| 1973 | 第一次石油危機 |
| 1976 | キングストン合意 |
| 1985 | プラザ合意 |
| 1986 | 前川レポート |
| 1987 | ルーブル合意 |

### 1989–2019 消費税と危機

| 年 | 出来事 |
|----|--------|
| 1989 | 消費税3％導入 |
| 1990〜91年頃 | バブル経済崩壊 |
| 1997 | 消費税5％ |
| 2008 | リーマン・ショック |
| 2014 | 消費税8％ |
| 2019 | 消費税10％、軽減税率8％ |

## 間違えやすい点

- 所得倍増を1961年の閣議決定とする。
- 消費税導入を1997年と読む。
- 1968年の自由世界第2位と、のちの名目GDP順位を同一視する。
