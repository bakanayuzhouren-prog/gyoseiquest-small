# 裁判員制度

## 結論

裁判員法は2004年に成立し、制度は2009年に開始した。対象は死刑又は無期の拘禁刑に当たる罪の事件等である。原則の構成は裁判官3人、裁判員6人である。

## 比較表

| 判断軸 | 内容 |
|--------|------|
| 人数（原則） | 裁判官3人、裁判員6人 |
| 争いのない事件 | 裁判官1人、裁判員4人の構成が可能 |
| 選任 | 衆議院議員の選挙権を有する者から無作為に選ばれる |
| 共同で判断すること | 事実認定、法令の適用、刑の量定 |
| 裁判官のみ | 法令の解釈、訴訟手続上の判断 |
| 評決 | 有罪・無罪及び量刑は、双方の職種を含む過半数 |
| 除外され得る事件 | 裁判員や親族等へ危害が及ぶおそれがある事件、著しく長期化する事件 |

「死刑又は無期懲役・禁錮」とは書かない。現行法の文言は死刑又は無期の拘禁刑である。

## 間違えやすい点

- 法令の解釈まで裁判員との合議とする。
- 人数を検察審査会（11人）と混ぜる。
- 裁判員だけの過半数で足りるとする。
- 制度開始を2004年とする（成立年と開始年の取り違え）。
