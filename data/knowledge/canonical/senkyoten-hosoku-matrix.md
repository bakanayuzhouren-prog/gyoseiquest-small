# 占有改定 — 「引渡し」に含まれるか（行政書士試験）

## 結論早見表

| 論点 | 条文 | 占有改定で「引渡し」？ | 根拠 |
|------|------|------------------------|------|
| 動産物権変動の対抗要件 | 178条 | **○ 含まれる** | 判例・通説 |
| 譲渡担保の対抗要件 | 178条・譲渡担保 | **○ 含まれる** | 最判昭30.6.2 |
| 先取特権の消滅（第三取得者への引渡し） | 333条 | **○ 含まれる** | **大判大6.7.26** |
| 集合物譲渡担保（後から入った在庫） | 183条・譲渡担保 | **○ 含まれる** | 最判昭62.11.10 |
| 即時取得の「占有を始めた」 | 192条 | **× 含まれない** | **最判昭35.2.11** |
| 質権設定の引渡し | 344条・345条 | **× 不可** | 345条明文禁止 |

## 混同禁止（再発防止）

- **333条（先取特権）** の判例は **大判大6.7.26**。最判昭32.6.27 は **192条・即時取得** の話（最判昭35.2.11 も即時取得）。
- 「333条の引渡しに占有改定は含まれない」→ **×（誤り）**。令和2年問28（ウ肢）でも出題。
- 「192条の占有を始めたに占有改定は含まれる」→ **×（誤り）**。

## 試験の覚え方

**178・333・譲渡担保は OK、192 と質権だけ NG**

## 占有改定の要件（183条）

**根拠条文（民法183条）**

「代理人が自己の占有物を以後**本人のために占有する意思を表示**したときは、本人は、これによって**占有権を取得**する。」

### 要件の整理（試験用）

| 要件 | 内容 |
|------|------|
| 本人 | 占有権を取得する者（新たな権利者・買主・譲渡担保権者など） |
| 代理人 | 引き続き物を占有する者（売主・設定者など。旧占有者） |
| 占有物 | 代理人が**自己の占有物**として占有している動産 |
| 意思表示 | 「以後**本人のために**占有する」旨の表示（書面不要・口頭可） |
| 効果 | 現実の引渡しなくとも、**占有権が本人に移転**（178条の「引渡し」に含まれる） |

### 典型例

売主Aが買主Bに動産を売却したが、Aが引き続き預かる場合：AとBの間で「所有権はBに移るが、AがBのために占有を継続する」旨の合意（占有改定）→ Bは178条上の引渡しを受け、第三者に対抗できる。

### 183条の要件と「各条での引渡し」の関係

- **183条** = 占有改定**そのもの**の成立要件（上表）
- **178条・333条・192条・345条** = 占有改定がその条文の「引渡し」に**含まれるか**（→ 上の結論早見表）

## 典型事案（譲渡担保×先取特権）

メーカー → カマダ電気（譲渡担保設定者）→ 銀行（債権者）。フードプロセッサー代未払いで銀行が占有改定を受けた場合、**333条上の引渡し**があったとみなされ、メーカーの先取特権は行使できない（**○**）。
