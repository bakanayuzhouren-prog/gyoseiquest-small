# 法人税、所得税、消費税、雇用保険、労災保険

TAC第1回・問49の周辺。既存の図 `rousai-tokubetsu.png` は、特別加入が労働者だけか、の図である。この文は図とは別に置く。

## 法人税

法人税は、法人の各事業年度の所得に課す税である。課税標準は所得の金額であり、売上高そのものではない。法人税法21条。

所得の金額は、その事業年度の益金の額から、損金の額を引いた額である。22条。益金は、販売などで入ってくる収益の側である。損金は、収益を得るために出た費用のうち、法律が所得の計算で引いてよいとするものである。

従業員へ支払った給与は、原則として損金になる。役員へ支払った給与は、次のどれかに当たるものに限って損金になる。34条。

- 定期同額給与。支給時期が1か月以下の一定期間ごとで、その事業年度の各支給時期の額が同額である給与。
- 事前確定届出給与。所定の時期に確定した額を支給する旨を、所定の時期までに税務署長へ届け出た給与。
- 業績連動給与。利益の状況を示す指標などを基礎に算定され、一定の要件を満たす給与。

この3つ以外の役員給与は、原則として損金にならない。退職給与は34条のこの制限の外である。

法人住民税と法人事業税は、法人税とは別の税である。法人税の所得計算に混ぜない。

## 所得税

所得税は、個人の所得に課す税である。収入の性質で10種類に分ける。利子、配当、不動産、事業、給与、退職、山林、譲渡、一時、雑である。

会社員の給与は給与所得である。個人で事業をしている人の事業から出た所得は、事業所得である。給与は、支払う者が源泉徴収する。事業所得は、原則として本人が確定申告する。

公的年金等は雑所得である。一時所得ではない。所得税法35条。一時所得は、利子・配当・不動産・事業・給与・退職・山林・譲渡のどれでもなく、営利を目的とする継続的な行為から生じた所得でもなく、労務その他の役務または資産の譲渡の対価としての性質を有しない、一時の所得である。34条。懸賞の賞金や、生命保険契約に基づく一時金が、一時所得の典型である。公的年金をここに入れない。

給与所得控除は、給与収入の額に応じて変わる。一律ではない。

## 消費税

消費税は、国内において事業者が行った資産の譲渡等と、特定仕入れに課す。4条。納税義務者は事業者である。5条。店が預かり、事業者が納付する。負担が消費者に転嫁される税であるが、法律上の納税義務者は消費者ではない。

収入は、地方交付税法に定めるところによるほか、毎年度、制度として確立された年金、医療および介護の社会保障給付並びに少子化に対処するための施策に要する経費に充てる。1条2項。消費税法の条文は、特定財源という語を使っていない。財務省の特別会計ガイドは、税法で使途が特定されている歳入を特定財源とし、その例に消費税を入れる。明確な定義条文があるわけではない、と同ガイドは書く。年金、医療、介護だけ、ではない。少子化に対処するための施策が入る。地方交付税に回る分を除いた書き方でもない。

標準税率は10パーセント、軽減税率は8パーセントである。2019年10月からこの率である。10パーセントのうち消費税は7.8パーセント、地方消費税は2.2パーセントである。軽減の8パーセントは、6.24パーセントと1.76パーセントである。地方消費税は、消費税とは別の税である。

免税事業者は、基準期間の課税売上高が1000万円以下の事業者である。個人はその年の前々年、事業年度が1年の法人はその前々事業年度である。消費税法9条1項。ただし、次のときは1000万円以下でも免税にならない。

- 適格請求書発行事業者の登録を受けている。
- 特定期間の課税売上高が1000万円を超える。個人の特定期間は、前年の1月1日から6月30日までである。国外事業者以外は、課税売上高に代えて、その期間に支払った給与等の額で判定できる。
- 課税事業者を選択する届出をしている。
- 基準期間がない法人で、事業年度開始の日の資本金または出資の金額が1000万円以上である。

適格請求書（インボイス）の制度は、令和5年10月1日からである。

## 雇用保険

雇用保険は、労働者が失業したとき、または雇用の継続が難しくなったときに給付する公的保険である。管掌するのは政府である。市町村ではない。窓口は公共職業安定所（ハローワーク）である。

保険料の全体は、事業主と労働者の折半ではない。失業等給付と育児休業給付の保険料は、労働者と事業主が折半する。雇用保険二事業の保険料は、事業主だけが負担する。二事業は、雇用安定事業と能力開発事業である。令和8年度の一般の事業は、労働者負担5/1000、事業主負担8.5/1000、合計13.5/1000である。農林水産・清酒製造、建設は率の区分が違う。率は年度で動く。

被保険者になるのは労働者である。事業主自身は、雇用保険の被保険者ではない。

## 労働者災害補償保険

労災保険は、労働者が業務上の事由または通勤によって傷病等を被ったときに保険給付をする制度である。業務災害と通勤災害の両方を含む。通勤だけを外さない。

原則として、労働者を一人でも使用する事業に適用される。保険料は、賃金総額に、事業の種類ごとの労災保険率を掛けて決める。労災保険分は、全額事業主が負担する。労働者は負担しない。雇用保険とここが違う。労働保険料として、雇用保険料と一緒に申告する。

労働者でない人も、一定の要件で任意に入れる。これが特別加入である。

- 中小事業主等は、労働保険事務組合へ事務を委託し、都道府県労働局長の承認を受ける。委託がなくても常に入れる、ではない。
- 令和6年11月1日から、企業等から業務委託を受けるフリーランスの特定フリーランス事業は、業種を問わず特別加入できる。加入の手続は、承認を受けた特別加入団体が行う。
- 消費者だけから委託を受ける人は、特定フリーランス事業の対象ではない。企業等から委託を受ける意向がある場合は入れる。
- 建設の一人親方、個人タクシー、ITフリーランス、芸能関係など、別の特別加入がある事業は、特定フリーランス事業ではなく、その事業の団体で加入する。

## 聞き分け

- 所得に課すのが法人税と所得税。販売に課すのが消費税。
- 法人税の納税義務者は法人。所得税は個人。消費税の納税義務者は事業者。
- 公的年金は雑所得。一時所得にしない。
- 消費税は普通税。目的税ではない。税務大学校の税法入門（令和8年度）は、消費税を普通税の欄に置く。目的税は電源開発促進税、復興特別所得税、森林環境税。使途は1条2項。年金・医療・介護だけで切らない。少子化に対処するための施策が入る。消費税法は特定財源という語を使わない。財務省の特別会計ガイドは、使途が特定された歳入を特定財源とし、消費税をその例に入れる。特定財源であることと、目的税であることは別。
- 雇用保険の保険料は全体を折半しない。労災保険の保険料は労働者が負担しない。
- 雇用保険を管掌するのは政府。市町村ではない。

## 周辺用語

| 用語 | 内容 |
|---|---|
| 益金 | 法人の所得計算で、収益として加える額。 |
| 損金 | 法人の所得計算で、益金から引く額。支出の全部が損金になるわけではない。 |
| 定期同額給与 | 1か月以下の一定期間ごとに、同額を支給する役員給与。要件を満たせば損金になる。 |
| 事前確定届出給与 | 支給時期と額をあらかじめ定め、期限までに届け出た役員給与。 |
| 業績連動給与 | 利益などの指標で算定し、一定の要件を満たす役員給与。 |
| 給与所得 | 雇用契約などで支払われる給与、賞与。源泉徴収の対象。 |
| 事業所得 | 個人が事業から得る所得。原則は確定申告。 |
| 雑所得 | 他の9種類のどれにも入らない所得。公的年金等はここ。 |
| 一時所得 | 継続的な営利でも、労務や資産譲渡の対価でもない、一時の所得。懸賞の賞金など。 |
| 源泉徴収 | 支払う者が、支払うときに所得税を預かって納付する仕組み。 |
| 確定申告 | 本人が、その年の所得と税額を計算して税務署へ申告する手続。 |
| 特定財源 | 特定の歳出に充てることとされている特定の歳入。使途が決まっている財源。財務省の特別会計ガイド。目的税を含む。都市計画税は、都市計画事業等の費用に充てる目的税。地方税法702条。 |
| 一般財源 | 使途が特定されず、どのような経費にも使える財源。地方財政では、地方税、地方譲与税、地方特例交付金、地方交付税。総務省の地方財政白書。 |
| 免税事業者 | 基準期間の課税売上高が1000万円以下で、納税義務が免除される事業者。例外がある。 |
| 適格請求書発行事業者 | インボイスを交付できる事業者。登録すると、1000万円以下でも免税にならない。 |
| 特定期間 | 個人は前年1月1日から6月30日。この期間の課税売上高が1000万円を超えると、基準期間が1000万円以下でも課税事業者になる。 |
| 軽減税率 | 飲食料品などの一部に適用される8パーセント。標準は10パーセント。 |
| 地方消費税 | 消費税とセットで課される地方の税。標準10パーセントのうち2.2パーセント。 |
| 失業等給付 | 求職者給付など、失業した労働者への雇用保険の給付。保険料は労使折半。 |
| 育児休業給付 | 育児休業中の労働者への給付。保険料は労使折半。 |
| 雇用保険二事業 | 雇用安定事業と能力開発事業。保険料は事業主だけ。 |
| 公共職業安定所 | 雇用保険の窓口。ハローワーク。政府の機関であり、市町村ではない。 |
| 業務災害 | 業務上の事由による傷病等。 |
| 通勤災害 | 通勤による傷病等。労災保険の対象に入る。 |
| 特別加入 | 労働者でない人が、承認を受けて労災保険に入る制度。 |
| 労働保険事務組合 | 中小事業主等の労働保険の事務を委託できる団体。 |
| 特定フリーランス事業 | 企業等から業務委託を受けるフリーランスの事業。令和6年11月1日から、業種を問わず特別加入の対象。 |
