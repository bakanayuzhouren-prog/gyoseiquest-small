# 民法総則―胎児・法定代理人・法律行為の分類

## 1. 胎児の権利能力

胎児は、原則としてまだ権利能力を持たない。ただし、次の3つについては、**生きて生まれたことを条件に、胎児であった時点へさかのぼって**権利を取得する。

| 例外 | 根拠条文 | 覚え方 |
| --- | --- | --- |
| 不法行為に基づく損害賠償請求 | 民法721条 | 胎児中に受けた損害を、生まれた後に請求できる |
| 相続 | 民法886条 | 相続開始時に胎児でも、生きて生まれれば相続人となる |
| 遺贈 | 民法965条・886条 | 相続と同じ扱い |

胎児である間は権利能力を取得していないため、胎児に法定代理人を付けて権利を行使させることはできない。

> ひっかけ：胎児がその時点で権利能力を持つのではない。生きて生まれて初めて、例外的な保護が胎児中へさかのぼる。

## 2. 胎児の認知と、認知・養子縁組の年齢基準

父は、**母の承諾**を得れば胎児を認知できる（民法783条1項）。認知は実親子関係を法律上明らかにする制度であり、養子縁組は血縁の有無にかかわらず法律上の親子関係を作る制度である。

認知と養子縁組では、承諾の年齢基準を混同しない。

| 制度 | 本人・関係者の承諾 |
| --- | --- |
| 胎児の認知 | 母の承諾が必要 |
| 未成年の子の認知 | 原則として子や母の承諾は不要 |
| 成年の子の認知 | 成年の子本人の承諾が必要（民法782条） |
| 15歳未満の者の養子縁組 | 法定代理人が本人に代わって縁組の承諾をする（民法797条） |
| 15歳以上の者の養子縁組 | 本人が縁組の意思表示をする |

15歳未満の養子縁組で承諾するのは、常に「母」とは限らず、**法定代理人**である。監護者が別にいる場合などには、その者の同意も問題となる。

> ひっかけ：「15歳」は養子縁組の代諾基準。認知された子の承諾基準ではない。

## 3. 法定代理人

法定代理人は、法律の規定により代理権を与えられる者である。親権者・未成年後見人・成年後見人などがあり、制度に応じて**複数人**または**法人**が選任されることもある。

制限行為能力者を保護する法定代理人の基本的な権限は、次の4つである。

- 代理権
- 同意権
- 取消権
- 追認権

> 表記注意：「同意見」ではなく「同意権」。各権限の有無・範囲は、未成年者、成年被後見人、被保佐人、被補助人で異なる。

## 4. 法律行為の分類

### 当事者の意思表示の数による分類

| 分類 | 意味 | 例 |
| --- | --- | --- |
| 単独行為 | 1人の意思表示で成立する | 遺言、取消し、相殺 |
| 契約 | 対立する複数の意思表示の合致で成立する | 売買、贈与、賃貸借 |
| 合同行為 | 同じ方向を向く複数の意思表示の結合で成立する | 社団法人の設立行為、会社の設立行為 |

## 5. 意思表示・意思の通知・観念の通知

| 分類 | 内容 | 例 |
| --- | --- | --- |
| 意思表示 | 法律効果を生じさせようとする意思を外部に示す | 追認、取消し、契約の申込み、解除、転貸の承諾、遺言 |
| 意思の通知 | 一定の意思を知らせるが、通知された内容どおりの法律効果を直接発生させるものではない | 催告、受領の拒絶 |
| 観念の通知 | 事実や認識を知らせる | 代理権授与の表示、債務の承認、債権譲渡の通知・承諾 |

意思の通知と観念の通知は、ともに意思表示そのものではないが、法律が一定の効果を結び付ける**準法律行為**である。

### 短い復習チャンク

- 胎児の3例外：**損害賠償・相続・遺贈**。
- 胎児認知は**母の承諾**、成年の子の認知は**本人の承諾**。
- 養子縁組の15歳未満は、法定代理人による**代諾**。
- 単独行為は一方向、契約は対立方向、合同行為は同一方向の意思表示。
- 催告は意思の通知、債務の承認と債権譲渡通知は観念の通知。
