# 行政法・常識で切る知識ベース

てらしぃが口頭で足した行政法の「常識で切る」論点の正本。  
`data/knowledge/quiz/行政法/` と `learn/` は同期で上書きされるので、**手編集はここだけ**。

民法側の対: `../minpou-joshiki/`  
受け渡し一覧: `../常識で切る-HANDOFF.md`

## 何をする場所か

1. てらしぃが論点を話す → **このフォルダ**に知識を足す（e-Gov・判例で根拠づけ）。
2. 「〇〇についてまとめて」→ 比較表＋**Codex用画像プロンプト**。
3. Codex が画像 → Cursor がアプリへ。

## 切り方

行政法も入口は常識・公平感。ただし処分性・原告適格などは**条文・判例のラベル**が試験の芯になる。  
先に「誰がかわいそうか／誰が最終決定をしたか／救済は何か」を口に出し、条文名は後付け。

詳細: `00-method.md`

## 触らないもの

- `src/learn.js` / `src/questions.js` の手直し
- Codex なしの画像生成
- 未確認判例の断定
- 模試・有料解説の全文転載
