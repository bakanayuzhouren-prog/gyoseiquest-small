## 1. 法思想・法学の立場

| 論点 | 内容の整理 |
|------|------------|
| 自然法と実定法 | 自然法に対し、人為（制定など）に基づく法律を**実定法**という。 |
| 法実証主義 | 法は**実定法（制定法・慣習法）**に限るという考え方。 |
| 法の支配とコモン・ロー | イギリス的伝統に対応し、**コモン・ロー（判例法）**を前提とする理解もある。 |
| マルクス主義 | **法制度は生産要素・経済構造によって決まる**という見方。 |
| 法治国 | **議会立法**の優位などを含むイメージで整理される。 |
| リバタリアニズム | **経済的自由を最大限に、法規制は最小限**という立場。 |
| 法と経済学 | 経済学的手法で立法等を検討する学問としての**法と経済学**。 |

## 2. 法の成立・法体系・歴史

- **イギリス**：判例の積み重ねによる**コモン・ロー（判例法）**が重要。
- **大陸法**：**民法**が長い歴史を持つイメージで語られることが多い。**ローマ市民法**がローマ法の主要部分として登場する。
- **日本の古代〜近代**：律令制時代には中国を手本とした**成文法**があり、その内容は刑法・行政法などに焦点が当てられる説明がある。**明治期**には留学生が最初に学んだヨーロッパ法学として**オランダ法学**に触れるカードがある。**ボアソナード**来日と旧刑法・旧民法起草の話、戦後の立法（借地借家法、労働組合法、独占禁止法、地方自治法、刑事訴訟法に英国的要素が加わった旨など）が題材になる。

---

## 3. 法の分類

- **実体法**に対し、手続を定める法を**手続法**。
- **一般法**と**特別法**では、原則として**特別法が優先**。
- **慣習法**：慣習として法的効力が認められる法。
- **有効期間のある法律**：原則として期間到来で**失効**。

---

## 4. 公布・施行・適用

- **施行**：公布の直後から施行することもあり得る。
- **施行日未定**：公布日から起算**20日経過した日**から施行するルールが題材になる。
- **刑法の適用**：日本国外の**日本船舶・日本航空機内**での犯罪にも及ぶ旨が出題されやすい。

---

## 5. 裁判・訴訟制度（概観）

- **裁判所と審級**：簡易裁判所・地方裁判所・高等裁判所・最高裁判所。**民事**では簡易裁判所・地方裁判所などが第一審、**上告審は最高裁**。**刑事**では簡裁が第一審のとき高等裁・最高裁が上級審、といった整理がカードに現れる。
- **控訴審**：民事では第一審記録に基づく審理（「経費される」等の誤記に注意）。刑事では**事後審**として記録に基づく審理という題材。
- **上告審**：原則**法律問題**、例外的に事実問題も。
- **上級審の判断**は下級審を**拘束**。
- **判決**：終局的判断など。**口頭弁論**が原則。家事・少年は別枠で「口頭弁論に似た手続」という説明がある。
- **決定・命令**：判決より簡易で、**口頭弁論は不要**という対比。
- **告知**：公開法廷での言い渡し、公告、決定が相当と認められる方法など。
- **簡易裁判所の刑事**：原則として禁固・懲役は科せないが、**例外で3年以下の懲役**を科し得る罪名が列挙される題材がある。
- **民事の特例**：一定事件で**認定司法書士が訴訟代理人**になり得る、**口頭で訴え提起**、**少額訴訟の回数制限**、**支払督促**など。
- **裁判長の職権**：事実・法律上の点で**質問・立証の促し**ができる。
- **準拠法**：国際私法のルールにより認められる準拠法。
- **刑事**：**起訴便宜主義**、**起訴状一本主義**（予断を生じさせる添付・引用の禁止）。
- **非訟**：原則**公開**（公開が相当でない場合は除く）。
- **民事**：**自由心証**（全趣旨・証拠調べの結果を斟酌）。

## 6. 裁判の在り方・比較・紛争解決

- 欧州大陸では**少数意見が権威を損ねる**との考えもあった一方で、**一枚岩としての判例**の示し方が題材に。
- **判例としての拘束**：**多数意見**である必要性などが論点になる。
- **裁判の決定**：**全員一致の多数決**という題材。
- **調停**：当事者間の**和解**を第三者が援助・促進。
- **仲裁**：第三者が紛争について**判断**（裁判に類似する側面）。
- **近代民主主義と裁判**：適正な裁判のための諸原則。
- **刑事裁判**：高度な法的専門性。
- **憲法**：三権分立の下での**裁判官の独立・身分保障**。
- **国民参加**：陪審から**参審制**への変遷が題材。

## 7. 法令の体裁（条文の読み方）

- **条**：原則として**括弧書きの見出し**が付く。
- **項**：条の段分け。
- **号**：条・項の中で順序を列挙。
- **削除・改正**：「〇条を削る」「〇条を次のように改める」「〇条を削除する」などの表現の違いが題材。

---

## 8. 法学用語（要件・効果・事実）

- **法律要件**：法律効果を生じさせる**原因となる事実**（意思表示を含む）。
- **法律効果**：権利義務関係の**変動**。
- **構成要件**：外形的事実で**故意等の主観要素も含む**。
- **立法事実**：社会・経済・政治・科学などの**抽象的な事実**。
- **要件事実**：**具体的な事実**。

---

## 9. 刑法と民法の法源・犯罪論（入口）

- **罪刑法定主義**：罰則の欠如は**犯罪不成立**。
- **民事**：法の欠如があっても**裁判を否定できない**という対比が題材。
- **民法92条のイメージ**：「成文の法律なきときは**習慣**に依り、習慣なきときは**条理**を推考して裁判すべし」（カード文言ベース）。
- **瀧川『犯罪論序説』**：罪刑法定の鉄則、**構成要件該当・違法・有責**の三分説への言及。
- **刑罰論**：応報と社会防衛、累犯・偶発と量刑、執行猶予のイメージなど。

---

## 10. 法人（抜粋）

- **権利能力なき社団**にも**当事者能力**が認められる場合があるという題材。
- **営利法人の例**：合名会社、行政書士法人、弁護士法人、司法書士法人など。
- **非営利法人**：収益事業はできても**収益分配は不可**など。
- **公益社団・公益財団**：不特定多数の利益増進・**公益認定**。
- **NPO法人**：特定・不特定の利益増進、保健医療等の活動、**管轄庁の認定**。

# 第5編 基礎法学：法とは何か[cite: 1]

## 1 社会規範としての法[cite: 1]

### 1. 法と法律[cite: 1]
日本語で「法」というときには、2つの意味で使われています。[cite: 1]
* **法律**：権限のある立法機関によって制定された厳密な意味での「法律」およびこれに準ずる規範（命令など）を指します。[cite: 1]
* **法令**：法律と命令（内閣や省などが作るもの）をあわせた呼称です。[cite: 1]
* **法**：もっと広い範囲の、いわゆる社会生活を規律している規範のことをいうのが一般的です。[cite: 1]

### 2. 法と道徳[cite: 1]
法と道徳は、現代社会では主に以下の点から区別されます。[cite: 1]

| 区分 | 法 | 道徳 |
| :--- | :--- | :--- |
| **対象性** | **外部の行為**を規律する。内心の心理だけでは法的評価の対象になりません。[cite: 1] | **内面の心理**（良心）を規律します。[cite: 1] |
| **強制性** | **国家権力による強制**を伴います。[cite: 1] | 良心の呵責等によって強要される（心理的強制）。[cite: 1] |

### 3. 法規範の特色と構造[cite: 1]
#### (1) 法規範の特色[cite: 1]
* 国家機関（裁判所、警察、行政機関等）による**強制力**を伴うのが特徴です。[cite: 1]
* 逸脱者への不利益（否定的な強制力）だけでなく、遵守者への利益（肯定的な強制力）も存在します。[cite: 1]
* 違反に対して強制力が認められない「自然債務」のような例外も存在します。[cite: 1]

#### (2) 法規範の構造[cite: 1]
* **行為規範**：国民が社会生活を送るうえでの行動の基準。[cite: 1]
    * **命令規範**：一定の作為を命令（「〜しなければならない」）。[cite: 1]
    * **禁止規範**：一定の不作為を命令（「〜してはならない」）。[cite: 1]
* **裁判規範**：裁判において、違反行為に対し制裁を加える際の基準となる規範。[cite: 1]
* **組織規範**：法を制定・適用・執行する組織の構成や権限を定める規範（例：裁判所の構成など）。[cite: 1]

#### (3) 法の役割[cite: 1]
1. 国民の間の**紛争解決の指針**となること。[cite: 1]
2. 国民に**予見可能性**を与えるとともに、生活の安全を守ること。[cite: 1]

## 2 法源・法の分類[cite: 1]

### 1. 法源（裁判の拠り所）[cite: 1]
#### (1) 成文法（制定法）[cite: 1]
* 文書で書き表され、一定の手続と形式で決定された法（憲法、法律、命令、条例、規則等）。[cite: 1]
#### (2) 不文法（非制定法）[cite: 1]
* **慣習法**：社会の慣習が繰り返し行われ、法的確信（社会一般の意識）を得たもの。[cite: 1]
* **判例法**：上級裁判所の判決が積み重なり成立するもの。基礎をなすのは**レイシオ・デシデンダイ（判決理由）**です。[cite: 1]
* **条理**：「ものの道理」。民事事件で適用すべき制定法等がない場合に参照されます。[cite: 1]

### 2. 法の分類[cite: 1]
| 分類 | 意義 | 具体例 |
| :--- | :--- | :--- |
| **公法** | 国家機関相互、または国家と国民の関係を定める | 憲法、行政法、刑法、訴訟法[cite: 1] |
| **私法** | 個人相互の関係を定める | 民法、商法、手形法等[cite: 1] |
| **社会法** | 市民法を実質的平等の観点から修正する法 | 労働法、経済法、社会保障法[cite: 1] |
| **強行法規** | 当事者の意思いかんにかかわらず適用される | 公法、社会法、身分法、物権法[cite: 1] |
| **任意法規** | 当事者が特約をすれば、適用されない | 契約秩序に関する規定[cite: 1] |
| **実体法** | 権利義務の発生、変更、消滅等の内容を定める | 憲法、民法、商法、刑法[cite: 1] |
| **手続法** | 実体法の権利義務を実現する手続を定める | 訴訟法、戸籍法、行政手続法[cite: 1] |
| **実定法** | 特定の社会で実際に効力を有している法 | 制定法、慣習法、判例法[cite: 1] |
| **自然法** | 人間の理性に基く、永久不変の普遍的な法 | -[cite: 1] |

## 3 法秩序の構成[cite: 1]

### 1. 形式的効力の原理[cite: 1]
法令には上下のランクがあり、上位の法令は下位の法令に優先します。[cite: 1]
> **【優先順位：憲法 ＞ 法律 ＞ 政令 ＞ 内閣府令・省令 ＞ 条例】**[cite: 1]

### 2. 新法優先の原則[cite: 1]
* 形式的効力が同じ場合、新しく制定された法令（後法）が旧法に優先します。[cite: 1]
* 基本法を実施するための個別法が基本法に矛盾する場合も、原則として新法優先が妥当します。[cite: 1]

### 3. 特別法優先の原則[cite: 1]
* 一般的な規定（**一般法**）と特例（**特別法**）がある場合、**特別法が優先**して適用されます。[cite: 1]

| 事項について | 一般法 | 特別法 |
| :--- | :--- | :--- |
| **人**について | 民法 | 皇室典範[cite: 1] |
| **場所**について | 借地借家法 | 被災地借地借家特別措置法[cite: 1] |
| **事柄**について | 民法 / 商法 | 商行為、金融商品取引法[cite: 1] |

## 4 法令の効力（P.648 - 649）[cite: 1]

### 1. 法律の効力の始期[cite: 1]
* **成立**：衆参両議院で議決されたとき。[cite: 1]
* **公布**：国民が法令を知ることができる状態に置くこと（**官報**掲載）。[cite: 1]
* **施行**：法令の効力が実際に発動すること。[cite: 1]
    * 別段の定めがない場合、**「公布の日から起算して20日を経過した日」**から施行されます。[cite: 1]

### 2. 効力の及ぶ範囲[cite: 1]
* **属地主義（原則）**：わが国の領域内のすべての人に適用。[cite: 1]
* **旗国主義（例外）**：公海上の日本船舶・航空機内にも日本法を適用。[cite: 1]
* **属人主義**：領土外にいる自国民にも適用。[cite: 1]
* **保護主義**：重大犯罪に対し、場所や国籍を問わず自国法を適用。[cite: 1]

## 5 法の解釈（P.650 - 651）[cite: 1]

### 1. 文理解釈[cite: 1]
法文の文言の意味を言葉に忠実に明らかにする方法。[cite: 1]

### 2. 論理解釈[cite: 1]
目的や体系、沿革を考慮して行う解釈。[cite: 1]
* **拡張解釈**：言葉の意味を広げて解釈。[cite: 1]
* **縮小解釈**：言葉の意味を狭めて解釈。[cite: 1]
* **類推解釈**：規定がない事項に対し、類似の事項の規定を適用。[cite: 1]
* **もちろん解釈**：立法趣旨からみて、当然含まれるべきと解釈。[cite: 1]
* **反対解釈**：規定されていることの反対の面から結果を導く。[cite: 1]
## 6 裁判上の紛争処理

### 1 裁判とは何か
当事者間で争いが起きた場合、国の機関である裁判所が、法律等に基づきこれを適用して解決します。判断形式には「判決」「決定」「命令」があります。

### 2 訴訟の種類
- **民事訴訟**：私人間の争い。
- **刑事訴訟**：犯罪の認定と刑罰の決定。
- **行政事件訴訟**：行政活動に関する紛争。

### 3 三審制と裁判所
3回まで審理を受けられる制度。
- **裁判所の種類**：最高裁判所、高等裁判所、地方裁判所、家庭裁判所、簡易裁判所。

### 4 裁判員制度
2009年開始。特定の重大な刑事事件において、国民（裁判員）と裁判官が共に有罪・無罪や刑の内容を決定します。

## 7 裁判によらない紛争処理（ADR）

### 1 意義
ADR（Alternative Dispute Resolution）：裁判外紛争解決手続。

### 2 解決の主な種類
- **和解**：互いの譲歩による解決。
- **斡旋**：第三者による交渉の仲介。
- **調停**：調停委員会が解決案を提示。
- **仲裁**：第三者（仲裁人）の判断に従うことを事前に合意（仲裁合意）して解決。

| 項目 | 裁判 | ADR |
| :--- | :--- | :--- |
| 本質 | 裁判による権限的解決 | 当事者間の合意に基づく解決 |
| 公開 | 原則公開 | 一般に非公開 |
| メリット | 公正な公権的判断 | 簡易・迅速・低廉 |

## 8 法令用語・法格言等

### 1 法律の形式
- **条・項・号**：基本単位は「条」。改行された段落が「項」。箇条書きが「号」。
- **枝番号**：条文を追加する際は「第○条の2」のようにします。

### 2 接続詞
- **又は / 若しくは**：選択。大きい括りに「又は」を使う。
- **及び / 並びに**：併合。大きい括りに「並びに」を使う。

### 3 語句の使い分け
- **適用 / 準用**：そのまま使う / 読み替えて使う。
- **みなす / 推定する**：反証を許さない / 反証があれば覆る。
- **権限 / 権原**：機関の範囲 / 正当ならしめる原因。
- **科す / 課す**：刑罰 / 負担（税など）。
- **直ちに > 遅滞なく > 速やかに**：即時性の強度の順。

### 4 重要な法格言
- **法実証主義**：「悪法もまた法である」。
- **時効の根拠**：「権利の上に眠る者は、保護されない」。
- **補強証拠**：「自白は証拠の女王である」（※自白のみで有罪にはできない）。
- **罪刑法定主義**：「法律なければ刑罰なし」。
