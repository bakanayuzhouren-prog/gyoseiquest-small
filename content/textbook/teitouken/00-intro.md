# 抵当権の教科書（学習用）

このページは、民法第10章に関する**試験対策用の整理**です。条文の骨格（第二節〜第三節の一部）と、総則（第369条〜）の**要点**から進めます。

## 構成

1. **総則まとめ（369条ほか）** — 抵当権とは何か・目的物・登記・効力の射程の入り口
2. **条文読み（第二節〜第三節）** — **三百七十三条〜三百九十八条**（順位・処分・第三取得者・共同抵当・一部消滅・法定地上権など）
3. **根抵当・詳細講義・演習問題** — 旧 PDF の一括抽出全文は `archive/sheet1-pdf-extract-original.md` に残してあります（再抽出は `npm run extract:teitouken-pdf` → `archive/_extract-sheet1-latest.md`）。

## このアプリへの取り込み

```bash
npm run bundle:teitouken-textbook
```

- 見出し・太字・`[[image:…]]` は深掘り（`MarkdownText`）と同じ規則です。
- 並び順は **`00`〜のファイル名**（総則 `01-souron-…` → 条文読み `02-bunsho-…`）です。
